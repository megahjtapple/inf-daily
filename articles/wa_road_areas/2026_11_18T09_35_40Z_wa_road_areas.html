二、逐地区详解

1. Mill Creek（米尔克里克）

  • 方位：西雅图东北方向，约 10–15 英里。
  • 所属：Mill Creek 市（King County）。
  • 高速公路 / 出口：
    • I-405（南北向，西雅图东侧）— Exit 172（148th Ave NE） 是进入 Mill Creek 主街的主要出口。
    • SR 526（东西向，连接 I-405 与 I-5）— 从 Bothell / Redmond 方向横向进入。
  • 特色：
    • 安静、绿化好的郊区家庭社区，节奏比市区慢。
    • Lake Stick（Stick 湖）是本地地标，有步道和公园。
    • Mill Creek 主街（Main Street）有独立咖啡馆、餐厅和小店。
    • 靠近 Redmond（微软总部所在地），通勤便利。
  • 来源参考：
    • Mill Creek 市政府官网：https://www.millcreekwa.gov
    • I-405 Exit 172 / 148th Ave NE 为华盛顿州 DOT 标准出口编号（WSDOT）：https://www.wsdot.wa.gov

2. Bothell（博塞尔）

  • 方位：西雅图正北方向，约 10–12 英里。
  • 所属：Bothell 市（King County）。
  • 高速公路 / 出口：
    • I-5（南北向，西雅图西侧）— Exit 164（148th Ave NE）、Exit 166（176th Ave NE） 是进入 Bothell 的主要出口。
    • SR 526（东西向）— 连接 I-5 与 I-405，横向贯穿。
  • 特色：
    • 紧邻 华盛顿大学（UW） 北校区，学术氛围浓。
    • Lake Sammamish（萨马米什湖）南端，湖景步道。
    • Bothell 主街（Main Street）有独立餐厅、书店、画廊。
    • 比 Mill Creek 更靠近市区，通勤选择更多（I-5 / I-405 / SR 526）。
  • 来源参考：
    • Bothell 市政府官网：https://www.cityofbothell.us
    • I-5 Exit 164/166 为 WSDOT 标准编号：https://www.wsdot.wa.gov

3. Queen Anne（昆安妮）

  • 方位：西雅图市中心西北，紧邻 Downtown（步行/短驾可达）。
  • 所属：Seattle 市（King County）。
  • 高速公路 / 出口：
    • I-5 — Exit 1（Downtown Seattle） 是最近的出口，出高速后沿 SR 99 / 1st Ave 向北即到。
    • I-90 — Exit 2（Westlake Ave / Denny Way） 从东侧进入。
    • SR 99（Alaskan Way）— 沿海公路，紧邻 Queen Anne 山脚。
  • 特色：
    • 山丘街区，老式维多利亚/爱德华式住宅，坡道多。
    • Elliott Bay（埃利奥特湾）海景，多个观景点（如 Queen Anne Park）。
    • 安静、绿化好，比 Capitol Hill 更偏居住区。
    • 靠近 Downtown，通勤便利但停车较难。
  • 来源参考：
    • Seattle.gov 社区指南：https://www.seattle.gov
    • I-5 Exit 1 / I-90 Exit 2 为 WSDOT 标准编号：https://www.wsdot.wa.gov

4. Capitol Hill（国会山）

  • 方位：西雅图市中心东北，紧邻 Downtown（步行/短驾可达）。
  • 所属：Seattle 市（King County）。
  • 高速公路 / 出口：
    • I-5 — Exit 1（Downtown Seattle） 是最近的出口，出高速后沿 2nd Ave / Pine St 向东即到。
    • I-90 — Exit 2（Westlake Ave / Denny Way） 从东侧进入。
    • SR 99（Alaskan Way）— 沿海公路，紧邻 Downtown 西侧。
  • 特色：
    • 西雅图最知名的** LGBTQ+ 文化区**，Pine St 酒吧街是地标。
    • 独立餐厅、咖啡馆、唱片店、画廊密集。
    • 比 Queen Anne 更热闹、更"夜生活"导向。
    • 靠近 Downtown，通勤便利但停车较难。
  • 来源参考：
    • Seattle.gov 社区指南：https://www.seattle.gov
    • I-5 Exit 1 / I-90 Exit 2 为 WSDOT 标准编号：https://www.wsdot.wa.gov

5. Issaquah（伊萨夸）

  • 方位：西雅图东南方向，约 18–20 英里。
  • 所属：Issaquah 市（King County）。
  • 高速公路 / 出口：
    • I-90（东西向，贯穿 Issaquah 山谷）— Exit 23（SR 18）、Exit 24（SE 40th St / 16th Ave SE） 是主要出口。
    • SR 18（南北向）— 连接 I-90 与 Sammamish / Bellevue 方向。
  • 特色：
    • 山谷小镇，被 "Issaquah Alps"（伊萨夸阿尔卑斯山）环绕，自然风景好。
    • Issaquah Lake（伊萨夸湖）是本地地标，有步道和公园。
    • 主街（Main Street）有独立餐厅、书店、画廊，节奏慢。
    • 比 Seattle 市区更安静、更偏"小镇"氛围，适合周末休闲。
  • 来源参考：
    • Issaquah 市政府官网：https://www.issaquahwa.gov
    • Wikipedia（Issaquah 被 I-90 贯穿）：https://en.wikipedia.org/wiki/Issaquah,_Washington
    • WSDOT I-90–SR 18 立交改造项目：https://www.wsdot.wa.gov
