华盛顿州（华州）各地区特色与方位 / 高速公路出口指南

说明：本指南覆盖西雅图市区、东岸（Eastside）、北岸（Northshore）、南岸（South Seattle / Tacoma）、以及周边知名城镇。每个地区列出：特色出名点、方位、附近高速公路、附近出口编号。

重要提示：华盛顿州的高速公路出口编号（exit number）是全州连续编号，不是每段路重新从 1 开始。下表中的出口编号为常用参考值，实际请以导航软件 / 路牌为准（个别出口在改线后编号可能微调）。

主要高速公路速记：

  • I-5：贯穿全州南北的主干道（西雅图—塔科马—奥林匹亚—斯波坎方向）
  • I-90：东西向，穿过西雅图市区，向东通往埃弗雷特 / 斯波坎
  • I-405：东岸（Eastside）南北向主干道，沿华盛顿湖东岸
  • I-205：北岸（Northshore）东西向，连接西雅图与埃弗雷特
  • SR-520 / SR-526：过湖隧道 / 桥梁，连接西雅图与东岸
  • SR-99：西雅图市区南北向主干道（非州际，但车流量大）

一、西雅图市区（Seattle Downtown & Neighborhoods）

1. 市中心 / 派克市场（Downtown / Pike Place Market）

  • 特色出名点：派克市场（Pike Place Market）、太空针塔（Space Needle）、西雅图中心（Seattle Center）、码头区（Pier 66 / 91，邮轮出发地）、联合车站（King Street Station）。
  • 方位：西雅图核心，华盛顿湖（Lake Washington）西岸、普吉特海湾（Puget Sound）东岸之间。
  • 附近高速公路：I-5（市中心段）、I-90、SR-99。
  • 附近出口：
    • I-5 Exit 167（Pike St / 派克市场方向，市中心南端）
    • I-5 Exit 168（Westlake Ave / 市中心）
    • I-90 Exit 1（Denny Trk / 市中心北端）

2. Queen Anne（女王安妮区）

  • 特色出名点：西雅图地标 太空针塔（Space Needle）、Seattle Center、Chihuly 玻璃艺术博物馆、音乐盒博物馆；山坡住宅区，可俯瞰市区与海湾。
  • 方位：市中心正北，紧邻市中心北侧的山丘。
  • 附近高速公路：I-5、I-90、SR-99。
  • 附近出口：
    • I-90 Exit 1（Denny Trk）→ 沿 Denny / Fairview 上山即达
    • I-5 Exit 168（Westlake Ave）
    • SR-99 Exit 2（Pine St）

3. Capitol Hill（国会山）

  • 特色出名点：西雅图最热闹的街区之一——Broadway 大道酒吧餐厅、独立书店、LGBTQ+ 文化地标、音乐现场（The Crocodile）、精品咖啡与买手店。
  • 方位：市中心东北，Queen Anne 的东南侧。
  • 附近高速公路：I-5、I-90、SR-99。
  • 附近出口：
    • I-5 Exit 168（Westlake Ave）→ 沿 Westlake / Broadway 向东
    • I-90 Exit 2（Pine St）
    • SR-99 Exit 3（Pine St）

4. South Lake Union（南联合湖）

  • 特色出名点：亚马逊（Amazon）总部所在地、微软部分办公区、科技园区、现代公寓与餐厅。
  • 方位：市中心东北偏北，Queen Anne 与 Capitol Hill 之间。
  • 附近高速公路：I-5、I-90、SR-99。
  • 附近出口：
    • I-5 Exit 168（Westlake Ave）
    • I-90 Exit 2（Pine St）

5. Ballard（巴勒德）

  • 特色出名点：Ballard Locks（船闸）、海鲜餐厅（如 The Pink Door）、啤酒厂（Ballast Point / Elysian 旧址）、周末农夫市场、老工业风街区。
  • 方位：市中心西北，普吉特海湾北端。
  • 附近高速公路：I-5、I-90、SR-520（过湖方向）。
  • 附近出口：
    • I-5 Exit 170（Wallingford Ave N）
    • I-90 Exit 3（Pine St）→ 沿 Pine 向西
    • SR-520 Exit 1（Ballard / 北端）

6. Fremont（弗里蒙特）

  • 特色出名点：Fremont Bridge（"自杀桥"）、Fremont 大雕像（Big Green Man）、独立咖啡馆与古董店、周末市场。
  • 方位：市中心正北偏西，Ballard 南侧。
  • 附近高速公路：I-5、I-90。
  • 附近出口：
    • I-5 Exit 170（Wallingford Ave N）
    • I-90 Exit 3（Pine St）

7. West Seattle（西雅图西区 / 海湖）

  • 特色出名点：Alki Beach、Corona Heights Park（观日落）、独立小店与餐厅、相对安静的居住区。
  • 方位：市中心西南，需过桥（West Seattle Bridge / SR-99 隧道）到达。
  • 附近高速公路：SR-99（隧道）、I-5（南端）。
  • 附近出口：
    • SR-99 Exit 1（Alaskan Way / 市中心西端）→ 过桥
    • I-5 Exit 167（Pike St）

8. Beacon Hill（信标山）

  • 特色出名点：多元文化社区、Beacon Food Forest（城市食物森林）、亚洲餐厅聚集区、相对平价。
  • 方位：市中心正南，紧邻市中心南侧。
  • 附近高速公路：I-5、SR-99。
  • 附近出口：
    • I-5 Exit 167（Pike St）
    • SR-99 Exit 1（Alaskan Way）

9. Columbia City / Rainier Valley（哥伦比亚城 / 雷尼尔谷）

  • 特色出名点：Rainier Beach、多元文化社区、平价餐厅、社区活动。
  • 方位：市中心南偏东。
  • 附近高速公路：I-5、SR-99。
  • 附近出口：
    • I-5 Exit 167（Pike St）→ 沿 SR-99 向南
    • SR-99 Exit 4（Rainier Ave S）

10. University District（大学区）

  • 特色出名点：华盛顿大学（UW）校园、U Village 餐厅酒吧、学术氛围。
  • 方位：市中心东北偏东，Capitol Hill 东侧。
  • 附近高速公路：I-5、I-90。
  • 附近出口：
    • I-5 Exit 168（Westlake Ave）→ 沿 15th Ave E 向东
    • I-90 Exit 2（Pine St）
