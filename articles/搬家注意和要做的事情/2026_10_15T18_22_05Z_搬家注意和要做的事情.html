1. 搬家前准备与断舍离

长途跨州搬家的费用按重量 / 体积计算，提前精简物品是省钱最有效的一步。

# 事项 说明
1.1 ✅ 极简断舍离 把不常用的物品转卖（eBay / Facebook Marketplace / OfferUp）、捐赠（Goodwill / Salvation Army）或丢弃。每减 100 磅，长途运费可省数十到上百美元。
1.2 📦 物品分类打包 按房间分箱并贴标签；易碎品单独包；准备一个「随身箱」（证件、药品、换洗衣物、充电器、少量现金）。
1.3 💡 选择运输方式 见下方第 2 节对比：自驾卡车 / 移动货柜（PODS、ReloCube）/ 专业跨州搬家公司。
1.4 ⚠️ 核算隐形成本 长途油费、沿途食宿、车辆托运、新州行政规费（车牌、驾照、保险）、临时住宿押金等。
1.5 📅 确定搬家日期 避开周末与月末（搬家公司最贵）；夏季是搬家旺季，价格最高。
1.6 🏠 新居确认 确认华州新房入住日期、停车位 / 电梯 / 卸货区是否可用，提前通知房东或物业。
1.7 📄 准备文件 身份证、SSN（社保号）、出生证明、护照、驾照、车辆登记证（title）、保险单、医疗记录、宠物疫苗本。

3. 沿途行车与路线规划

# 事项 说明
3.1 📊 规划行车天数 旧金山/洛杉矶 → 西雅图约 1,000–1,200 英里，纯驾驶 13–18 小时。建议分 2–3 天开完，避免疲劳驾驶。
3.2 🛣️ 路线选择 经典走 I-5 北上（经俄勒冈州）；备选 I-84 / I-90 经爱达荷州（更绕但部分路段路况好）。
3.3 🔎 查看天气与路况 俄勒冈州与华州交界的山路（如 Cascade 山脉）冬季/初春易积雪结冰，备好防滑链；出发前查 WSDOT / ODOT 路况。
3.4 ⛽ 加油与休息 每 2–3 小时进服务区休息；山区加油站少，油量低于半箱就加。
3.5 📌 妥善安置宠物/贵重品 证件、首饰、电脑、现金等重要物品随身携带，切勿留在托运的车或货柜中。
3.6 🐾 宠物运输 自驾时宠物用航空箱固定；长途托运需符合 USDA / 航空公司规定。
3.7 📱 导航与离线地图 山区信号弱，提前下载离线地图（Google Maps / Apple Maps）。

4. 落地华州后的法定手续（关键！）

⚠️ 核心时限：搬入华盛顿州后 30 天内必须完成驾照换发与车辆登记。以下为综合整理，具体表格与费用以 WA DOL 官网为准。

# 事项 时限 说明
4.1 🗓 更新驾照 30 天内 到华州 DOL（Department of Licensing） 将加州驾照更换为华州驾照。需带：有效加州驾照、SSN/身份证明、居住证明（如租约、水电账单）。
4.2 📅 注册车辆与换车牌 30 天内 到 DOL 办理车辆过户登记并更换华州车牌。需带：车辆 title（登记证）、保险证明、加州排放/检验记录（如适用）。
4.3 💡 变更汽车保险 尽快 联系保险公司将车险从加州转为华州——两州保费评估标准、气候理赔风险不同，保费可能变化。
4.4 🪪 REAL ID 注意 换照时一并办 若需 REAL ID（登机用），换发华州驾照时勾选 REAL ID 并带齐额外文件。
4.5 🗳 更新选民登记 尽快 将选民登记地址从加州改为华州，避免收到错误选票或失效。
4.6 🏥 医疗/医保地址变更 尽快 通知保险公司、医生诊所更新账单与就诊地址（详见第 5 节）。

5. 税务与生活重组

5.1 税务（重点：告别加州州税）

# 事项 说明
5.1 📊 告别加州州所得税 加州有高额州所得税（最高约 13.3%）；华盛顿州没有个人州所得税，能省下一笔开支。
5.2 ⚠️ Part-Year Resident（年度居民判定） 离境当年需留意税务身份：搬出前在加州的收入仍按加州居民计税，搬出后按非居民处理。建议咨询 CPA / 税务师，正确填写加州与华州的分段报税。
5.3 💰 资本利得 / 大额交易 若在搬家前后有大额资产出售（房产、股票、公司），税务身份判定影响巨大，务必提前规划。
5.4 🧾 销售税差异 华州有销售税（B&O tax 等），加州也有；购物与消费时注意两州税率不同。

# 事项 说明
5.5 💡 设立新账户 / 转账 更改银行、信用卡、医疗保险及订阅服务的账单地址。
