Mill Creek 未来一周 · 适合交朋友的群体活动清单

生成时间： 2026-10-29（UTC） 出发地： Mill Creek Town Center（华盛顿州，Kirkland 东侧） 目标人群： 小组 / 一大群人聚集、能聊天交流、适合认识新朋友的活动 筛选规则： ① 排除 LGBTQ+ 相关活动；② 优先特别地区活动 + 季节性（一年一次）活动；③ 优先开车 1.5 小时内可达；④ 需提前买票的活动已标注「开售时间 / 建议提前多久 / 购票渠道」 数据来源： Seattle Refined《Fall into Fun: Your Ultimate PNW Events Guide for October 2026》(2026-10-01) 及各活动官网（见每项 Source Reference）

⚠️ 阅读前的重要说明（诚实标注）

  1. 日期窗口： 今天是 2026-10-29（周四）。严格意义上「未来一周」= 10/29–11/4。但 Seattle Refined 的十月活动指南里，多数大型节日（Oktoberfest、巧克力节、咖啡节、GeekGirlCon 等）在 10/25 前已结束。因此本清单分两部分：
    • A. 本周仍可参加的活动（10/29–11/4 仍在进行，可直接报名/购票）——这是真正「未来一周」能去的。
    • B. 十月已落幕、但明年同一时间会再来的季节性活动——作为「聊天话题 + 明年规划」素材保留，并明确标注「今年已结束」。
  2. 购票信息： 指南本身只给了活动日期和官网链接，没有给出每张票的精确开售日期。凡我标注「建议提前多久买票」的地方，是基于该活动类型（热门节日/演出通常提前 2–6 周售罄）的经验判断，不是官方数据——请以各官网实时信息为准。
  3. 距离： 所有 A 类活动从 Mill Creek Town Center 出发均在 1.5 小时车程内（Seattle / Bellevue / Redmond / Puyallup / Tacoma / Snohomish 一带）。

🎯 A 类：本周（10/29–11/4）仍可参加的活动

1. Carnevolar XIV Ascension（马戏 / 杂技之夜）⭐ 首推

  • 话题简介： 一年一度的大型马戏/杂技演出，10/29–31 连演三晚，是本周最「特别」的群体活动——看表演、聊节目、拍照，天然适合一大群人一起。
  • 详细内容： Emerald City Trapeze Arts 主办，融合空中飞人、杂技、灯光秀，氛围热闹、老少皆宜。三晚连演意味着朋友可以分头去不同场次。季节限定（一年一次）。
  • 购票提示： 热门演出，建议提前 2–4 周在官网购票；临近周末可能涨价或售罄。
  • Source Reference: https://emeraldcitytrapeze.com/carnevolar-xiv-ascension/

2. BOO! Seattle（万圣节 EDM 舞会）

  • 话题简介： 万圣节周末的大型电子音乐舞会，年轻人聚集、气氛嗨，是认识新朋友最快的场合之一。
  • 详细内容： WAMU Theater 主办，10/30–31 两晚，EDM + 万圣节装扮 + 舞蹈。季节限定（每年万圣节）。适合爱蹦迪、想快速破冰的群体。
  • 购票提示： 热门舞会，建议提前 3–6 周购票；现场票通常更贵且可能售罄。
  • Source Reference: https://seattle.boo-halloween.com

3. After Hours Halloween（西雅图水族馆夜场）

  • 话题简介： 水族馆万圣节夜场，10/29 当晚开放，边看海洋生物边聊天，氛围轻松、适合不想太嗨的群体。
  • 详细内容： Seattle Aquarium 主办，夜间特别场次，有主题装饰和互动。季节限定（每年一次）。比舞会安静，适合「想聊天但不想蹦迪」的朋友。
  • 购票提示： 夜场票有限量，建议提前 1–2 周在官网购票。
  • Source Reference: https://www.seattleaquarium.org/events/after-hours-halloween/

4. Dia de Muertos Celebration（亡灵节庆典）

  • 话题简介： 墨西哥亡灵节社区庆典，10/30 在 Shoreline，文化体验 + 美食 + 音乐，适合想体验不同文化的群体。
  • 详细内容： Spartan Recreational Center 主办，有传统装饰、音乐、食物。季节限定（每年 10 月底）。免费或低价，门槛低、易参与。
  • 购票提示： 多为免费/预约制，建议提前在官网确认是否需要预约。
  • Source Reference: https://www.shorelinewa.gov/government/departments/parks-recreation-cultural-services/events-arts-and-culture/special-events

5. Seattle Catrinas Festival（卡特里娜节）

  • 话题简介： 亡灵节主题的卡特里娜（Catrina）庆典，10/31–11/1，装扮 + 艺术 + 文化，视觉冲击强、适合拍照社交。
  • 详细内容： Town Hall 主办，融合墨西哥传统与现代艺术。季节限定（每年一次）。
  • 购票提示： 建议提前 2–4 周购票。
  • Source Reference: https://www.seattlecatrinasfestival.com/

6. Tacoma City Ballet: Dracula（芭蕾舞剧《德古拉》）

  • 话题简介： 城市芭蕾舞团演出，10/31–11/1 在 Tacoma Pantages Theater，适合喜欢艺术、想「优雅社交」的群体。
  • 详细内容： 以吸血鬼德古拉为题材的芭蕾，音乐 + 舞蹈 + 戏剧。季节限定（每年巡演）。
  • 购票提示： 演出票建议提前 3–6 周购票；好座位会先售罄。
  • Source Reference: https://www.tacomacitytheaters.org/events/detail/balletdracula

7. Washington State Toy Show（华盛顿州玩具展）

  • 话题简介： 大型玩具/收藏展，10/31–11/1 在 Puyallup 州博览会中心，适合有孩子或喜欢收藏的群体。
  • 详细内容： 数百个摊位、复古玩具、模型、手办。季节限定（每年一次）。
  • 购票提示： 建议提前 1–2 周购票；周末人多。
  • Source Reference: https://www.watoyshow.com/

8. Fall Coin Show（秋季钱币展）

  • 话题简介： 钱币收藏展，10/30–11/1 在 Tukwila，适合对收藏/投资感兴趣的群体，可边逛边聊。
  • 详细内容： PNNA（太平洋西北钱币协会）主办，有交易摊位和讲座。季节限定（每年秋季）。免费入场。
  • 购票提示： 免费，无需购票。
  • Source Reference: https://www.pnna.org/wp/events/fall/

9. Halloween Party Cruise（万圣节派对游船）

  • 话题简介： 万圣节主题游船派对，10/31 从 Seattle 码头出发，边游 Puget Sound 边派对，社交氛围极佳。
  • 详细内容： Waterways Cruises 主办，有音乐、装扮、饮品。季节限定（每年一次）。
  • 购票提示： 热门游船，建议提前 4–8 周购票；座位有限。
  • Source Reference: https://waterwayscruises.com/halloween-party-cruise/

10. Alter Ego: Halloween at W Bellevue（万圣节派对）

  • 话题简介： W Bellevue 酒店万圣节派对，10/31，距离 Mill Creek 最近（~25 min），适合不想跑远的群体。
  • 详细内容： 酒店内主题派对，有音乐、装扮、饮品。季节限定（每年一次）。
  • 购票提示： 建议提前 2–4 周购票。
  • Source Reference: https://www.eventbrite.com/e/alter-ego-halloween-at-w-bellevue-tickets-2002309230810

11. Fashionably Undead: Outer Space（MoPOP 展览）

  • 话题简介： MoPOP 万圣节主题展览，10/31，太空 + 时尚 + 恐怖元素，适合喜欢创意艺术的群体。
  • 详细内容： MoPOP（流行文化博物馆）主办，沉浸式展览。季节限定（每年一次）。
  • 购票提示： 建议提前 1–2 周购票。
  • Source Reference: https://www.mopop.org/events

12. Poe Unexpected（爱伦·坡主题即兴喜剧）

  • 话题简介： 以爱伦·坡作品为灵感的即兴喜剧，10/30–31 有场次，轻松搞笑、适合破冰。
  • 详细内容： Unexpected Productions 主办，即兴表演 + 观众互动。可反复看（10 月多场）。
  • 购票提示： 建议提前 1–2 周购票。
  • Source Reference: https://www.eventbrite.com/e/poe-unexpected-edgar-allan-poe-improvised-tickets-1982202036651

13. Collide O Scope（沉浸式体验）

  • 话题简介： 沉浸式互动体验，10/30–31，适合喜欢新奇体验的群体。
  • 详细内容： Seattle 本地主办，互动装置 + 故事线。季节限定（每年一次）。
  • 购票提示： 建议提前 2–4 周购票。
  • Source Reference: https://collideoscope.squarespace.com/

14. Run for Beer（啤酒跑）

  • 话题简介： 万圣节主题 5K 跑步 + 终点啤酒，10/31 在 Woodinville Black Raven 精酿厂，运动 + 社交。
  • 详细内容： Brewery Running Series 主办，跑完喝啤酒。季节限定（每年一次）。

  • Source Reference: https://www.eventbrite.com/e/5k-halloween-beer-run-x-black-raven-2026-wa-brewery-running-series-tickets-1986667901172

15. Trick or Treat 5k & 10k（万圣节跑步）

  • 话题简介： Green Lake 万圣节主题跑步，10/31，适合爱运动的群体。

16. Haunted Forest of Maple Valley / Haunted Woods（鬼屋森林）

  • 详细内容： Maple Valley / Buckley 本地主办，夜间步行路线 + 惊吓点。季节限定（每年秋季）。

🏠 B 类：全年可去的室内群体活动（随时可约，适合「这周就想聚」）

这些不是「季节限定」，但最适合一大群人聊天交流、认识新朋友，且距离 Mill Creek 近。可作为「本周就约」的首选。

18. Seattle Meowtropolitan（撸猫馆）

  • 话题简介： 西雅图知名撸猫馆，可预约时段带一群朋友去撸猫、聊天，氛围轻松、破冰神器。
  • 详细内容： 有猫咪互动区 + 咖啡区，适合不想太嗨的群体。全年开放。
  • 购票提示： 预约制，建议提前 1–2 周在官网预约时段。
  • Source Reference: https://www.seameow.com/visit

19. TopGolf / Axe Throwing / Escape Room（室内娱乐）

  • 话题简介： TopGolf（高尔夫娱乐）、Axe Throwing（斧头投掷）、Escape Room（密室逃脱）——都是「一群人一起玩、边玩边聊」的经典选择。
  • 详细内容： Bellevue / Seattle 多家门店，适合 4–12 人。全年开放。
  • 购票提示： 预约制，建议提前 3–7 天预约；周末热门时段需更早。
  • Source Reference: https://visitseattle.org/things-to-do/sightseeing/top-25-attractions

20. Color Me Mine（陶艺 DIY）

  • 话题简介： 陶艺彩绘工作室，一群人一起画杯子/花瓶，边做边聊，成品可带走。
  • 详细内容： Bellevue / Kirkland 有门店，适合 4–10 人。全年开放。
  • 购票提示： 预约制，建议提前 3–7 天预约。
  • Source Reference: https://visitseattle.org/things-to-do/sightseeing/top-25-attractions

21. Round1 / 卡丁车 / VR 体验馆（日式娱乐中心）

  • 话题简介： Round1（保龄球 + 街机 + KTV）、卡丁车、VR 体验馆——一站式娱乐，适合年轻人。
  • 详细内容： Seattle / Bellevue 多家门店，适合 4–12 人。全年开放。
  • 购票提示： 预约制，建议提前 3–7 天预约。
  • Source Reference: https://visitseattle.org/things-to-do/sightseeing/top-25-attractions

📅 C 类：十月已落幕、明年同一时间会再来的季节性活动（聊天话题 + 明年规划）

这些活动今年已结束，但都是「一年一次」的季节性大事件，适合作为聊天话题，并提前规划明年。

22. Oktoberfest Northwest（巴伐利亚啤酒节）

  • 话题简介： 华盛顿州最大啤酒节，10/9–11 在 Puyallup 州博览会中心，啤酒 + 美食 + 音乐。

24. Seattle Coffee Festival（西雅图咖啡节）
