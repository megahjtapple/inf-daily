1. Roth IRA 是什么、怎么省税（核心机制）

热度/类别： 🔥🔥🔥🔥🔥 / 概念

话题简介： Roth IRA 是一种「先交税、后免税」的退休账户。你用已经交过所得税的钱存进去，账户内的增长免税，退休后只要满足条件取出，本金和收益都免联邦所得税。这正是它省税的核心。

详细内容：

  • 省税逻辑（与传统 IRA 相反）： 传统 IRA 是「现在减税、退休时交税」；Roth IRA 反过来——「现在交税、退休时免税」。你存入的是税后钱，所以 IRS 之后不再对你的增长征税。
  • 举例： 25 岁起每年存 $7,500，假设年化 7%（分散股票组合的长期历史均值），到 65 岁可能超过 100 万美元，且每一美元的增长都免税。
  • 两个前提条件：
    1. 必须有劳动所得（工资、薪水、小费、自雇收入）；投资收入、租金等被动收入一般不算。
    2. 受 IRS 的**收入上限（MAGI）**限制，超过一定门槛可缴金额会被削减甚至归零（见第 3 条）。
  • 没有 RMD（强制最低取款）： 传统 IRA 到 73/75 岁必须开始取款且都算应税收入；Roth IRA 在你生前没有任何强制取款要求，钱可以无限期免税复利增长，并可免税传给继承人。

2. 取出「本金」vs「投资收益」的限制（最关键区别）

热度/类别： 🔥🔥🔥🔥🔥 / 规则

话题简介： 这是 Roth IRA 最独特、也最容易被误解的地方——你存的本金（contributions）和账户赚到的收益（earnings）适用完全不同的取出规则。本金几乎随时可取，收益则受「合格取款」条件约束。

详细内容：

（A）取出本金（Contributions）——非常灵活

  • 你可以在任何时间、任何原因取出你当初存入的本金，不交税、不罚。因为你存进去时已经交过税了。
  • 举例： 今年存了 $7,500，之后急需用 $3,000，一般可以取出这 $3,000 本金而不触发任何税或罚金。

（B）取出投资收益（Earnings）——受「合格取款」约束

  • 收益要免税 + 免罚取出，必须同时满足两个条件：
    1. 5 年规则： 从你第一次向 Roth IRA 缴款的纳税年度开始算起，满 5 个完整税年（注意：是「账户年龄」，不是单笔钱的年龄）。
    2. 合格原因之一： 年满 59½ 岁；或死亡；或永久完全残疾；或首次购房（最多 $10,000 终身额度）。
  • 不满足条件取出收益 = 「非合格取款（nonqualified distribution）」： 收益部分要交联邦所得税 + 通常 10% 提前取款罚金（除非符合教育、首套房等豁免，豁免可免罚金但不免所得税）。
  • 取出顺序（IRS 默认）： 先出本金 → 再出转换进来的本金 → 最后才出收益。所以即使账户里全是收益，你取出的钱也优先算「本金」，这对你有利。

3. 2026 年缴费限额与收入上限（MAGI 阶段退出）

热度/类别： 🔥🔥🔥🔥 / 限额

话题简介： Roth IRA 每年能存多少、你能不能存，由两个数字决定：年度缴费上限和收入上限（MAGI）。2026 年的具体门槛如下。

详细内容：

  • 年度缴费上限（2026）：
    • 基础额度：$7,500
    • 50 岁及以上：可额外加缴 $1,100（catch-up），合计 $8,600
    • ⚠️ 这个上限是所有 IRA 共享的——传统 IRA + Roth IRA 加起来不能超过 $7,500（或 $8,600）。不是每个账户各 $7,500。
  • 收入上限（MAGI，2026）：
    • 单身 / 独立报税： MAGI < $153,000 可全额缴；$153,000–$168,000 之间按比例部分缴；≥ $168,000 不能直接缴。
    • 夫妻联合报税： MAGI < $242,000 可全额缴；$242,000–$252,000 之间部分缴；≥ $252,000 不能直接缴。
  • 重要细节：
    • MAGI 上限只限制当年新缴款。如果你以前已经开了 Roth IRA，账户可以一直保留、继续投资，只是高收入年份不能再往里加钱。
    • 配偶各自有独立的缴费额度；不工作的配偶可以用工作配偶的劳动所得来缴（spousal IRA）。

4. Roth IRA 和 401(k) 的关系

热度/类别： 🔥🔥🔥🔥 / 关系

话题简介： Roth IRA 和 401(k) 不是二选一，而是可以（且通常应该）同时使用。它们是两个独立的账户、两套独立的额度，但都服务于退休储蓄。理解它们的分工是关键。

详细内容：

  • 本质区别：
    • 401(k)：由雇主提供，通过工资扣款；有公司 match（配缴）；额度更高（2026 年员工自缴上限约 $24,500，50+ 加 catch-up）；投资选项由公司限定。
    • Roth IRA：你自己开（在券商处），不依赖雇主；额度低（$7,500/$8,600）；有 MAGI 收入上限；投资选择更自由、灵活度更高。
  • 能否同时用？ 能，而且推荐。它们额度独立——401(k) 缴满不影响你能不能往 Roth IRA 里存 $7,500（只要你有劳动所得且 MAGI 达标）。
  • 推荐的缴费顺序（经典策略）：
    1. 先缴 401(k) 到「拿满公司 match」为止——match 是 100% 的即时回报，等于白捡的钱，不拿就是亏钱。
    2. 再填满 Roth IRA（$7,500/$8,600）——享受免税增长 + 灵活取款 + 无 RMD。
    3. 如果还有余钱且公司 match 已拿满，再回到 401(k) 继续加缴到上限。
  • Roth 401(k) 选项： 很多公司的 401(k) 提供「Roth 401(k)」选项（税后缴入、退休时免税取出），它没有 MAGI 收入上限——这是高收入者绕过 Roth IRA 收入限制的重要通道。
  • 一句话总结： 401(k) 是「雇主给的、额度大、有 match」的主战场；Roth IRA 是「自己开的、灵活、免税增长」的补充。两者配合，而不是互相替代。

5. 怎么确认自己已拿满公司 401(k) match

热度/类别： 🔥🔥🔥🔥 / 实操

话题简介： 很多人不知道自己其实没拿满公司的 401(k) match，等于每年白白丢掉一笔「免费的钱」。确认方法很简单，但需要主动去查。

详细内容：

  • 第一步：搞清楚你公司的 match 规则。 不同公司规则不同，常见几种：
    • 50% 比例配缴： 你缴工资的 X%，公司配 50%×X，通常封顶在你缴到工资的 6%（即公司最多给 3%）。
    • 100% 全额配缴： 你缴多少公司配多少，通常封顶在工资的 4%–6%。
    • Safe Harbor（安全港）计划： 公司至少配 3% 固定 + 最高 2% 比例配缴（合计最多 5%），且不需要满足工作资历就能立即 vest。
  • 第二步：找到你的「match 上限」。 具体数字写在：
    • 公司的 401(k) 计划说明书 / SPD（Summary Plan Document）
    • HR 的 401(k) 门户页面
    • 券商（Fidelity/Vanguard/Principal 等）账户里的「plan details」
    • 或直接问 HR：「我们的 match 公式是什么？封顶在工资的百分之几？」
  • 第三步：核对你的实际缴款比例。 登录 401(k) 账户，看你的**员工自缴比例（employee contribution %）**是否 ≥ 公司 match 的封顶比例。
    • 举例： 公司规则是「100% match，封顶工资的 6%」。如果你只缴了 3%，那你只拿到 3% 的 match，白白丢了另外 3%。要拿满，你得把自缴比例调到至少 6%。
  • 第四步：确认 vesting（归属）进度。 有些公司的 match 有 vesting 期（比如「20/20/20/20/20」5 年线性归属）。即使你缴满了，如果中途离职，未 vest 的部分会丢。查一下你的 vesting schedule。
  • 快速自检清单：
    • [ ] 我知道公司的 match 公式和封顶比例
    • [ ] 我的自缴比例 ≥ 封顶比例（已拿满）
    • [ ] 我了解 vesting 进度，离职不会丢钱

Source References:

  • IRS — Roth IRAs
  • 注：match 具体规则因公司而异，以上为通用框架；你的确切数字以公司 SPD / HR 为准。

6. 怎么在 Roth IRA 里投资（账户≠投资）

热度/类别： 🔥🔥🔥 / 实操

话题简介： 开一个 Roth IRA 只是开了个「空盒子」——钱放进去不会自动增长。你必须主动选择投资标的，这才是真正赚钱的部分。

详细内容：

  • 可选的投资类型（取决于你的券商）：
    • 指数基金 / ETF： 最推荐的入门方式。低成本、分散化、长期跑赢大多数主动基金。例如：
      • 全市场股票指数（如 VTI / SPY / QQQ）
      • 目标日期基金（Target Date Fund，自动随年龄调整股债比例）
      • 债券基金（保守型）
    • 个股： 风险更高，适合有经验的人做卫星配置。
    • 货币基金 / 现金： 低风险、低收益，适合短期停泊。
  • 选择策略（按风险偏好）：
    • 激进型（年轻、长期）： 80–100% 股票指数基金，追求长期增长。
    • 平衡型： 60% 股票 + 40% 债券。
    • 保守型： 更多债券 / 货币基金，优先保本。
  • 关键原则：
    • 低成本（low expense ratio）： 选费率 < 0.2% 的指数基金，长期复利差异巨大。
    • 分散化： 不要把所有钱押在一只股票上。
    • 长期持有： Roth IRA 的优势是「免税复利」，频繁交易会削弱这个优势。
    • 定期定额（DCA）： 每月固定金额投入，避免择时风险。

7. 省税进阶：Backdoor Roth / Roth 401(k)

热度/类别： 🔥🔥🔥 / 策略

话题简介： 如果你的 MAGI 超过了 Roth IRA 的收入上限（2026 年单身 $168,000 / 夫妻 $252,000），你仍然有办法享受「Roth 式」的免税增长。

详细内容：

  • Backdoor Roth IRA（后门 Roth）：
    • 做法： 先向一个传统 IRA 缴一笔不可抵扣的钱（nondeductible contribution），然后**立即转换（convert）**到 Roth IRA。
    • 为什么有效： 传统 IRA 的缴费没有 MAGI 上限，所以高收入者也能缴；转换时因为这笔钱本来就没抵扣过税，所以转换本身不产生额外税负（只要账户里没有其他应税余额）。
    • 注意： 如果你还有其他传统 IRA / 401(k) rollover 余额，转换时会触发「pro-rata rule」，部分转换金额要交税。操作前建议咨询税务顾问。
  • Roth 401(k)：
    • 如果你的公司提供 Roth 401(k) 选项，你可以直接税后缴入 401(k)，退休时免税取出。
    • 优势： 没有 MAGI 收入上限，额度比 Roth IRA 高得多（2026 年约 $24,500+）。
    • 劣势： 取款灵活性不如 Roth IRA（受 401(k) 规则约束），且没有「本金随时可取」的灵活度。
  • Roth Conversion（传统 IRA → Roth 转换）：
    • 如果你有一个传统 IRA（比如从旧公司 rollover 过来的），可以在某个低收入的年份把它转换成 Roth IRA，主动选择在那一年交税，之后这笔钱就永久免税了。
    • 策略价值： 在收入低的年份（比如退休过渡期、失业年）做转换，税率更低，省下的税更多。
