1. Roth IRA 是什么、怎么投资

热度/类别： 基础概念 · 🔥🔥🔥🔥🔥

话题简介： Roth IRA（罗斯个人退休账户）是一种「先交税、后免税增长」的退休账户。你用的是已经交过所得税的钱，账户里的投资收益可以免税增长，符合条件取出时收益也免税。

详细内容：

  • 投资标的： 和传统 IRA / 普通券商账户一样，可买股票、债券、共同基金（mutual funds）、ETF 等。具体能买什么取决于你开户的券商/金融机构。
  • 开户流程（Fidelity 官方三步）：
    1. 选一家券商或投资公司（比较费用和可投资产品）；
    2. 注资（最常见是从银行账户 ACH/电汇转入当年合格贡献额）；
    3. 把钱投进具体证券。
  • 关键前提： 必须有「应税收入（earned income）」才能贡献；且 MAGI（调整后总收入）不能超过 IRS 上限（见第 7 条）。
  • 无 RMD（强制最低取款）： 只要你是原始账户持有人（非继承人），Roth IRA 没有强制最低取款，可以一直放着继续增长——这是它相对传统 IRA / 401(k) 的一大优势。

2. 怎么省税（Roth IRA 的税务优势）

热度/类别： 省税 · 🔥🔥🔥🔥🔥

话题简介： Roth IRA 的「省税」不是现在少交税，而是把税「锁定」在未来——用今天的税后钱换未来完全免税的取款。

详细内容：

  • 贡献不可抵扣： Roth IRA 的贡献额不能从当年应税收入中扣除（这是它和传统 IRA 最大的区别）。
  • 增长免税： 账户内投资收益免税累积，不用每年为「未实现收益」交税。
  • 合格取款免税： 满足条件后，本金 + 收益都可免税、免罚金取出。
  • 什么时候 Roth 更划算：
    • 你预期退休后税率会更高（或至少不更低）；
    • 你想锁定「未来确定不用交税」的确定性，规避未来税率上涨风险；
    • 你想保留一部分「随时可取」的应急资金（本金可无罚金取出）。
  • 对比传统 IRA： 传统 IRA 是「现在抵扣、退休时交税」；Roth 是「现在不抵扣、退休时免税」。如果你现在处于低税率阶段，Roth 通常更优。

3. 取「投资收益」的限制（5 年规则 + 59½）

热度/类别： 取钱限制 · 🔥🔥🔥🔥🔥

话题简介： Roth IRA 里「赚到的钱（earnings）」取出比本金严格得多，核心是 5 年规则 和 59½ 岁 两道门槛。

详细内容：

  • 合格取款（qualified distribution）需同时满足：
    1. 账户从「首次贡献所在税年的年初」起已存在 至少 5 个完整税年；
    2. 你已年满 59½ 岁（或属于例外情形）。
  • 不满足 = 非合格取款（nonqualified distribution）： 取出的「收益部分」可能同时被征 所得税 + 10% 罚金。
  • 5 年规则的起算点很关键： 从你第一次往 Roth IRA 里贡献的那个税年的年初开始算，不是从某笔具体贡献日算。
  • 例外（可免罚金，但收益部分仍可能交税）：
    • 首次购房：最多 $10,000；
    • 永久且完全残疾；
    • 合格的教育费用。
  • 注意： 这些例外让你「免罚金」，但不一定「免税」——收益部分在多数情况下仍需按普通收入交税。

4. 取「本金（贡献额）」的限制（几乎无限制）

热度/类别： 取钱限制 · 🔥🔥🔥🔥🔥

话题简介： Roth IRA 最灵活的一点：你**自己投进去的本金（contributions）**可以随时、免税、免罚金取出，哪怕还没退休。

详细内容：

  • 本金随时可取： 因为贡献时已经交过税了，所以取出「贡献额」本身永远免税、免罚金，不受 5 年规则或 59½ 限制。
  • 取出顺序（IRS 默认）： 账户先出「贡献额」，再出「收益」。所以即使你提前取钱，只要没超过累计贡献额，通常不会触发税/罚金。
  • 策略价值： 很多人把 Roth IRA 当作「半应急基金」——平时放着投资，急用钱时取出本金不损失税务待遇。
  • 重要边界： 一旦取出金额超过你的累计贡献额，多出来的部分就算「收益」，要受第 3 条的 5 年规则 + 59½ 约束。

5. Roth IRA vs 401(k) 的关系与区别

热度/类别： 账户关系 · 🔥🔥🔥🔥

话题简介： 两者都是退休储蓄工具，但机制不同：401(k) 由雇主提供、可拿公司匹配；Roth IRA 是个人自己开的、更灵活。它们可以并存，且额度分开算。

详细内容：

  • 额度独立： 401(k) 有它自己的年度贡献上限（2026 年员工侧 $24,500，50+ 另有 catch-up），Roth IRA 有它自己的上限（2026 年 $7,500，50+ 加 $1,100）。两者互不占用额度。
  • 收入限制不同： Roth IRA 受 MAGI 上限约束（高收入者不能直接贡献）；401(k) 传统账户没有 MAGI 上限（任何人都能按工资比例扣）。
  • Roth 401(k) 选项： 很多雇主提供「Roth 401(k)」——用税后钱进 401(k)，享受 Roth 的免税增长，且不受 MAGI 限制。这是高收入者拿到 Roth 待遇的常见路径。
  • 公司匹配： 只有 401(k) 有雇主匹配（free money）；Roth IRA 没有匹配。所以「先拿满 401(k) 匹配、再投 Roth IRA」是经典顺序。
  • RMD： 传统 401(k) 到 73 岁起强制取款；Roth IRA 无 RMD（原始持有人）。
  • 投资选择： 401(k) 只能从雇主提供的基金菜单里选；Roth IRA 可在券商买几乎任何证券，选择面更广。

6. 怎么确认自己已拿满公司 401(k) 匹配

热度/类别： 实操 · 🔥🔥🔥🔥🔥

话题简介： 公司匹配（employer match）是「白送的钱」，没拿满等于丢钱。关键是搞清楚你公司的匹配公式，然后把个人贡献比例调到「刚好拿满」。

详细内容：

  • 第一步：查清匹配公式。 常见两种：
    • 比例匹配（dollar-for-dollar）： 你投 X%，公司配到某个上限（如「配到你工资的 50%」或「1:1 配到 6%」）。
    • 公式匹配（formula match）： 如「工资的 50% × 你贡献比例，最高配到工资的 3%」。
  • 第二步：找到「拿满点（full match threshold）」。 多数公司把匹配上限设在员工贡献工资的 4%–6%。例如「1:1 配到 6%」意味着你至少投 6% 工资才能拿满；再往上投，公司不再加钱。
  • 第三步：核对你的实际贡献比例。 登录 401(k) 门户或看工资单（pay stub），确认你的 deferral % ≥ 拿满点。
  • 第四步：验证匹配真的到账。 在账户对账单里找「employer match / company contribution」这一行，确认每期都有进账、且金额符合公式。
  • 常见坑：
    • 公司匹配有vesting（归属期）——离职太早可能拿不全；
    • 有些公司匹配是「deferred match」，按季度/年度结算，不是每月；
    • 换工作后匹配规则会变，要重新核对。
  • 信息来源： 匹配公式写在公司的 401(k) Plan Document / SPD（Summary Plan Description） 里，或问 HR / 401(k) 服务商（如 Fidelity、Vanguard）的客户支持。

Source References:

  • Kiplinger — Average 401(k) Match: Do You Work for a Generous Company?
  • CNBC — How much you should put in your 401(k)?
  • 注：具体匹配比例因公司而异，本文未列出你公司的实际数字——请以你的 Plan Document / HR 为准（待核实）。

7. 2026 年贡献额度与收入上限（MAGI）

热度/类别： 数字参考 · 🔥🔥🔥🔥

话题简介： Roth IRA 能投多少，受两个限制：年度贡献上限 + MAGI 收入上限。

详细内容：

  • 2026 年度贡献上限（Fidelity）：
    • 基础：$7,500；
    • 50 岁及以上：额外 $1,100（合计 $8,600）。
  • MAGI 收入上限（2026，Fidelity）：
    • 单身： MAGI < $153,000 可全额；$153,000–$168,000 部分贡献；≥ $168,000 不能直接贡献。
    • 夫妻联合申报： MAGI < $242,000 可全额；$242,000–$252,000 部分贡献；≥ $252,000 不能直接贡献。
  • 额度跨账户共享： IRA 贡献上限是「所有 IRA 合计」——传统 IRA + Roth IRA 加起来不能超过年度上限。若 Roth 因收入被限，可用传统 IRA 补足差额。
  • 配偶独立额度： 夫妻各自有独立贡献额度；无工作配偶可用工作配偶的收入来贡献（spousal IRA）。

8. 高收入者怎么办：Backdoor Roth / Roth 401(k)

热度/类别： 进阶策略 · 🔥🔥🔥

话题简介： MAGI 超过上限、不能直接贡献 Roth IRA 的人，仍有两条路拿到 Roth 的免税增长待遇。

详细内容：

  • Roth 401(k)： 如果雇主提供 Roth 401(k) 选项，可用税后钱进 401(k)，享受 Roth 待遇且不受 MAGI 限制。这是高收入者最直接的替代方案。
  • Backdoor Roth IRA（后门罗斯）：
    1. 往传统 IRA 做一笔「不可抵扣贡献」（nondeductible contribution）；
    2. 立即把它转换（convert）成 Roth IRA。
    • 因为贡献额本身已交过税，转换时通常不产生额外税（但要注意 pro-rata 规则——若你还有其他传统 IRA 余额，转换可能部分应税）。
  • 注意： Backdoor Roth 涉及转换的税务细节较复杂，建议操作前咨询 CPA。

Source References:

  • Fidelity — What is a Roth IRA and how does it work?（"What if I earn too much?" 章节）
  • Fidelity — Backdoor Roth IRA

附：一句话决策框架

  1. 先拿满 401(k) 公司匹配（白送的钱，优先级最高）。
  2. 再投 Roth IRA（若 MAGI 在上限内）——锁定未来免税 + 保留本金灵活性。
  3. 高收入者走 Roth 401(k) 或 Backdoor Roth。
  4. 取钱时： 本金随时可取；收益要等「5 年 + 59½」。
