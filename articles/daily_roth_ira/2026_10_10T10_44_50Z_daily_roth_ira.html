Roth IRA 投资、省税与取钱规则详解

生成日期： 2026-10-10（UTC） 主题： 如何用 Roth IRA 投资 / 如何省税 / 取出「投资收益」与「本金」的限制 / Roth IRA 与 401(k) 的关系 / 如何确认自己已拿满公司 401(k) match 适用地区： 美国联邦税法（IRA 规则全国统一，不分州） 说明： 本文为科普整理，非税务/投资建议。具体决策请咨询持牌 CPA 或财务顾问。所有关键结论均附来源链接。

一、Roth IRA 是什么？核心逻辑一句话

Roth IRA 是一种「先交税、后免税」的退休账户：

  • 你存入的是已经交过所得税的钱（after-tax），所以存入时不能抵税。
  • 账户内的投资收益（earnings/growth）免税增长。
  • 满足条件后取出的本金和收益都免联邦所得税、免罚金。

对比传统 IRA / 401(k)（「先免税、后交税」）：Roth 把税负从「取出时」挪到了「存入前」。

来源： IRS — Roth IRAs（https://www.irs.gov/retirement-plans/roth-iras）；Fidelity — What is a Roth IRA（https://www.fidelity.com/learning-center/smart-money/what-is-a-roth-ira）

二、怎么用 Roth IRA 投资？

2.1 关键认知：Roth IRA 是「账户」，不是「投资品」

Roth IRA 本身不产生收益，它只是装投资的容器。开户后你必须主动选择把资金投到哪里，否则钱会躺在现金/结算账户里不增值。

来源： Fidelity — What is a Roth IRA（https://www.fidelity.com/learning-center/smart-money/what-is-a-roth-ira）

2.2 普通券商 Roth IRA 里能买什么

  • 股票（stocks）、债券（bonds）
  • ETF、共同基金（mutual funds）
  • 目标日期基金（target-date fund）——随年龄自动调整股债比例，适合新手
  • CD（定期存款）、货币市场基金

具体可买的品种取决于你在哪家券商开户。

来源： Fidelity — What is a Roth IRA（https://www.fidelity.com/learning-center/smart-money/what-is-a-roth-ira）

2.3 想投另类资产（房产/私募/贵金属/加密）

普通券商 Roth 通常不允许这些。需要开 Self-Directed IRA（自定向 IRA），由合格托管人持有。注意：税务待遇完全相同（收益仍免税），只是投资范围更广。

来源： IRA.com — Roth IRA: The Complete Guide for 2026（https://ira.com/roth）

2.4 开户五步（实操）

  1. 选券商/顾问（多数大券商开户无最低余额要求）。
  2. 确认有**应税收入（earned income）**且 MAGI 在限额内。
  3. 准备 SSN、政府 ID、扣款银行账户。
  4. 电子转账注资（也可支票、从雇主计划 rollover、或从他机构转入）。
  5. 选择投资标的（股票/ETF/基金/目标日期基金等）。

来源： Fidelity — What is a Roth IRA（https://www.fidelity.com/learning-center/smart-money/what-is-a-roth-ira）

三、怎么省税？Roth IRA 的税务优势

3.1 核心省税点

维度 Roth IRA 传统 IRA / 401(k)
存入时 不抵税（用税后钱） 可抵税（税前钱，降低当年应税收入）
账户内增长 免税增长 递延纳税（tax-deferred）
取出时 合格取出免联邦所得税、免罚金 按普通收入交税
RMD（强制最低取出） 无（原持有人可一直不取） 73 岁起必须开始取，否则罚

3.2 什么时候 Roth 更划算

  • 现在税率低、预期退休后税率更高：Roth 锁定「未来免税」，避免以后被高税率抽走。
  • 想要确定性：Roth 合格取出时不用猜未来税率。
  • 想留遗产：配偶/非配偶继承人在账户满 5 年后取出收益仍免税（非配偶一般须 10 年内取完）。

来源： Fidelity — What is a Roth IRA（https://www.fidelity.com/learning-center/smart-money/what-is-a-roth-ira）

3.3 收入太高怎么办（两条路）

  1. Roth 401(k)：如果雇主提供 Roth 401(k) 选项，可绕过 Roth IRA 的收入上限，享受同样的免税增长。
  2. Backdoor Roth IRA：先往传统 IRA 存「不可抵税」的钱，再转换成 Roth IRA——高收入者常用。

来源： Fidelity — What is a Roth IRA（https://www.fidelity.com/learning-center/smart-money/what-is-a-roth-ira）

四、取钱规则：本金 vs 投资收益（最核心）

4.1 一句话总结

本金（contributions）随时可取，免税免罚金；投资收益（earnings）要满足条件才能免税免罚金。

4.2 本金（Contributions）——最灵活

  • 因为存入时已经交过税，任何时候取出自己的本金都不交税、不罚。
  • 哪怕你 30 岁、账户才开 1 年，也能把本金取出来应急。
  • 这是 Roth IRA 相对传统 IRA/401(k) 最大的灵活性优势。

来源： Fidelity — What is a Roth IRA（https://www.fidelity.com/learning-center/smart-money/what-is-a-roth-ira）

4.3 投资收益（Earnings）——要满足「合格取出」

要免税免罚金取出收益，必须同时满足两个条件：

  1. 5 年规则：从你第一次贡献所在税年的年初起，至少过了 5 个完整税年。
  2. 以下任一情形：
    • 年满 59½ 岁；或
    • 永久且完全残疾；或
    • 首次购房（最多 $10,000 终身额度）；或
    • 本人/配偶/子女/父母的合格教育费用。

⚠️ 注意： 5 年规则是按账户算的，不是按每一笔钱算的。即使你 60 岁，如果账户才开 3 年，取出收益仍可能被视为「非合格取出」，要交税或罚金（或两者）。

来源： Fidelity — What is a Roth IRA（https://www.fidelity.com/learning-center/smart-money/what-is-a-roth-ira）；IRS — Roth IRAs（https://www.irs.gov/retirement-plans/roth-iras）

4.4 取出顺序（FIFO 原则）

Roth IRA 默认先出本金、后出收益。所以即使你还没满足 5 年规则，只要取出的金额不超过你的本金总额，通常仍免税免罚金。

来源： IRS — Roth IRAs（https://www.irs.gov/retirement-plans/roth-iras）

4.5 非合格取出的后果

如果取出的是收益且未满足条件：

  • 收益部分按普通收入交税。
  • 若你未满 59½ 岁且不属于例外情形，还要加 10% 提前取出罚金。

来源： Fidelity — What is a Roth IRA（https://www.fidelity.com/learning-center/smart-money/what-is-a-roth-ira）

五、Roth IRA 与 401(k) 的关系

5.1 它们是两个独立的账户

维度 Roth IRA 401(k)（传统） Roth 401(k)
谁开 你自己（通过券商） 雇主提供 雇主提供
存入的钱 税后 税前 税后
取出时 合格取出免税 按普通收入交税 合格取出免税
年度上限 $7,500（2026） $23,500（2026，个人） $23,500（2026，个人）
收入限制 有（MAGI 上限） 无 无
RMD 无 73 岁起有 73 岁起有
雇主 match 无 有（关键！） 有（关键！）

5.2 核心关系：互补，不是替代

  • 401(k) 的优势：上限高、有雇主 match（白拿的钱）、可税前存入降低当年税。
  • Roth IRA 的优势：无收入限制（Roth 401(k)）、无 RMD、取出更灵活、可投另类资产。
  • 最佳策略：两个都用。先拿满 401(k) match，再把剩余的钱放进 Roth IRA。

来源： Fidelity — What is a Roth IRA（https://www.fidelity.com/learning-center/smart-money/what-is-a-roth-ira）；CNBC — 401(k) and IRA contribution limits for 2026（https://www.cnbc.com）

5.3 收入太高存不了 Roth IRA？

用 Roth 401(k)（如果雇主提供）或 Backdoor Roth IRA 绕过收入上限。

来源： Fidelity — What is a Roth IRA（https://www.fidelity.com/learning-center/smart-money/what-is-a-roth-ira）

六、怎么确认自己已拿满公司 401(k) match？

6.1 第一步：搞清楚公司的 match 规则

match 规则因公司而异，常见形式：

  • 50% match up to 6%：你存工资的 6%，公司再补 3%（即 6% × 50%）。
  • 100% match up to 4%：你存 4%，公司补 4%。
  • 100% match up to 5%：你存 5%，公司补 5%。
  • Dollar-for-dollar up to X%：你存多少，公司补多少，直到 X%。

去哪里查：

  1. 员工手册 / 401(k) plan document（HR 系统里通常有 PDF）。
  2. HR 或 Benefits 部门直接问。
  3. 401(k) 服务商网站（Fidelity/Vanguard/Principal 等）的「Plan Details」页面。

来源： Investopedia — 401(k) Contribution Rates（https://www.investopedia.com）；NerdWallet — 401(k) over-contribution guide（https://www.nerdwallet.com）

6.2 第二步：算出你需要存多少

公式： 你的贡献比例 ≥ match 规则里的「上限百分比」，就能拿满。

举例：

  • 公司规则：50% match up to 6%。
  • 你月薪 $5,000。
  • 你要存：$5,000 × 6% = $300/月。
  • 公司补：$300 × 50% = $150/月。
  • 你每月实际进 401(k) 的总额：$450。

如果你只存了 4%（$200），公司只补 $100——你白白损失了 $50 的 match。

来源： Investopedia — 401(k) Contribution Rates（https://www.investopedia.com）

6.3 第三步：验证你确实拿到了

  1. 看每月工资单（pay stub）：应有一行「401(k) employer contribution」或类似字样。
  2. 登录 401(k) 账户：Fidelity/Vanguard 等网站能看到「Employer Match」明细。
  3. 年度对账：年底看总贡献额，确认 match 部分已到账。

⚠️ 常见坑：

  • 有些公司 match 是季度发放而非每月——别以为没看到就是没给。
  • 有些公司要求你**在计划里主动勾选「opt-in」**才享受 match。
  • 换工作后，新公司的 match 规则可能完全不同——入职第一周就问 HR。

来源： NerdWallet — 401(k) over-contribution guide（https://www.nerdwallet.com）；24/7 Wall St. — Suze Orman's Strategy: Skip the 401(k) After the Match（https://www.247wallst.com）

6.4 实操清单

  • [ ] 找到公司 401(k) plan document，确认 match 规则。
  • [ ] 算出拿满 match 需要的贡献比例。
  • [ ] 在 401(k) 系统里把贡献比例设到那个数（或更高）。
  • [ ] 每月看工资单，确认 match 到账。
  • [ ] 年底对账，确认全年 match 总额符合预期。

七、常见误区速查

误区 真相
「Roth IRA 存的钱随时都能取」 本金可以，收益要满足 5 年 + 年龄/例外条件
「Roth IRA 和 401(k) 二选一」 两个都用，先拿满 match 再存 Roth
「收入太高就不能用 Roth 了」 可以用 Roth 401(k) 或 Backdoor Roth
「match 是自动给的」 有些公司要主动 opt-in，且规则因公司而异
「5 年规则是按每笔钱算的」 是按账户算的，从第一次贡献所在税年的年初起算
「Roth IRA 有 RMD」 没有（原持有人），可以一直不取
