一、Roth IRA 是什么

Roth IRA（罗斯个人退休账户）是一种税后退休账户，核心特点：

特征 Roth IRA 传统 IRA (Traditional)
存入时 税后钱（不能抵税） 税前钱（可抵税）
账户内增长 免税 免税
取出收益 合格取款免税免罚 取出时按普通收入纳税
强制最低取款 (RMD) 无（原持有人） 73 岁起强制
收入上限 有（MAGI 限制） 无（但抵税资格受限）

一句话：先用钱交税，之后账户里赚的钱和取出的钱都不用再交税。

来源：IRS「Roth IRAs」官方页 + Fidelity Learn「What is a Roth IRA」。

二、怎么用 Roth IRA 投资

1. 开户

  • 选择一家券商 / 投资公司（Fidelity、Vanguard、Schwab、Charles Schwab、Interactive Brokers 等）。
  • 在线开户，通常需要 SSN、地址、银行账户信息。
  • 账户必须在设立时就指定为 Roth IRA（IRS 规定：账户或年金必须在设立时指定为 Roth）。

2. 注资（Contribute）

  • 最常见方式：从银行账户通过 ACH / 电汇转入现金。
  • 2026 年贡献上限：
    • 基础：$7,500
    • 50 岁及以上：额外 $1,100（catch-up），合计 $8,600
  • ⚠️ 所有 IRA（Roth + 传统）共享同一个上限——不是每个账户各 $7,500，而是所有 IRA 加起来 $7,500。

3. 投资什么

Roth IRA 里可以投券商提供的几乎所有证券：

  • 股票（个股）
  • 债券
  • 共同基金 (Mutual Funds)
  • ETF（交易所交易基金） ← 最常用、费率最低
  • 目标日期基金 (Target Date Fund) ← 懒人一键配置

4. 常见投资策略（由简到繁）

策略 说明 适合谁
目标日期基金 一只基金自动调整股债比例，随年龄降低风险 完全不想折腾的人
3 基金组合 美国股票 ETF + 国际股票 ETF + 债券 ETF，自己定比例 想控制成本、有一定知识
指数化 + 定期再平衡 全投宽基指数（如 VTI/VXUS/BND），每年调一次比例 长期投资者
个股 + 行业 ETF 主动选股，风险高 有经验、愿意花时间研究

关键原则： Roth IRA 是长期免税增长账户，最适合放波动大、长期向上的资产（股票/ETF），因为收益免税，复利效应最大化。债券等低收益资产放传统账户反而更划算（省税价值更高）。

5. 收入限制（MAGI）—— 2026 年

身份 全额贡献 部分贡献 不能贡献
单身 MAGI < $153,000 $153,000 – $168,000 ≥ $168,000
夫妻联合申报 MAGI < $242,000 $242,000 – $252,000 ≥ $252,000

⚠️ 收入限制只针对新贡献。已开的账户可以继续持有和投资，只是不能在新的一年再往里加钱。

6. 收入太高怎么办？

  • Roth 401(k)：如果公司提供 Roth 401(k) 选项，没有收入上限。
  • Backdoor Roth IRA（后门 Roth）：先往传统 IRA 存非抵税贡献，再转换成 Roth IRA。高收入者的常用策略。

来源：Fidelity Learn「What is a Roth IRA」2026-04-29 版。

三、怎么省税（核心机制）

Roth IRA 的省税逻辑是**「先交税，后免税」**，具体体现在：

1. 收益免税增长

账户内所有投资收益（股息、利息、资本利得）完全免税。传统 IRA 里这些收益取出时要交税，Roth 不用。

2. 合格取款完全免税

满足两个条件后，取出的本金 + 收益都免税免罚：

  • ✅ 年满 59½ 岁
  • ✅ 账户从首次贡献所在税年的年初起已满 5 年（5-Year Rule）

3. 无 RMD（强制最低取款）

传统 IRA / 401(k) 在 73 岁起必须每年取钱，不取要罚。Roth IRA 没有 RMD（原持有人），可以一直放着继续免税增长，甚至传给下一代。

4. 省税策略要点

策略 说明
低税率时多存 Roth 如果你现在收入低、未来预期高，Roth 更划算（锁定低税率）
把高波动资产放 Roth 股票/ETF 增长快，免税收益价值大；债券放传统账户更省税
用 Backdoor Roth 突破收入上限 高收入者通过「传统 IRA → 转换 Roth」实现同样的免税效果
Roth 401(k) 组合 公司 401(k) 选 Roth 选项 + 个人 Roth IRA，双重免税
遗产规划 Roth IRA 传给配偶/继承人，5 年后取出仍免税，是强大的财富传承工具

来源：Fidelity Learn「What is a Roth IRA」+ IRS「Roth IRAs」。

四、取「投资收益」的限制

这是 Roth IRA 最复杂的部分。收益（Earnings）的取款受 5-Year Rule 和 合格/非合格取款 规则约束：

1. 5-Year Rule（五年规则）

  • 从你首次向任何 Roth IRA 贡献所在税年的年初开始计算 5 年。
  • 即使你 59½ 岁了，如果账户不满 5 年，取出的收益部分仍可能被视为非合格取款，要交税 + 罚。

2. 合格取款 (Qualified Distribution)

同时满足以下两个条件，收益取出完全免税免罚：

  • ✅ 年满 59½ 岁（或符合其他例外）
  • ✅ 账户已满 5 年

3. 非合格取款 (Non-Qualified Distribution)

不满足上述条件时取出的收益：

  • 要交普通所得税
  • 可能还要交 10% 提前取款罚金（或两者都交）

4. 例外情况（可免罚，但仍可能交税）

以下情况可以免 10% 罚金（但收益部分仍可能要交税）：

  • 🏠 首次购房：最多 $10,000（终身限额）
  • ♿ 永久且完全残疾
  • 🎓 合格教育费用（学费、书本费等）

5. 取款顺序规则

Roth IRA 取款时，先出本金，后出收益。这意味着：

  • 你取出的钱中，本金部分永远免税免罚（因为存的时候已经交过税了）
  • 收益部分才受 5-Year Rule 和年龄限制约束

来源：Fidelity Learn「What is a Roth IRA」+ IRS Pub 590-B。

五、取「本金」的限制

这是 Roth IRA 最大的优势之一：

✅ 本金可以随时取出，免税免罚

  • 任何时间（哪怕刚开户第二天）
  • 任何年龄（哪怕 25 岁）
  • 不需要满足 5-Year Rule
  • 不需要 59½ 岁
  • 不交税、不罚款

为什么可以？

因为你存入本金时已经交过所得税了。政府不能对同一笔钱收两次税。所以本金的取出是「拿回自己的钱」，没有任何限制。

⚠️ 注意事项

  • 你只能取出你实际贡献过的本金总额（不含收益）。
  • 如果你做过 Roth Conversion（转换），转换进来的钱有自己独立的 5 年计时器，规则更复杂。
  • 取款顺序是「先本金后收益」，所以即使账户里有收益，你先取出的也是本金。

实际意义

Roth IRA 的本金可以当作应急储蓄使用——这是传统 IRA / 401(k) 做不到的。很多人把 Roth IRA 当作「第二应急基金」。

来源：Fidelity Learn「What is a Roth IRA」+ IRS Pub 590-B。

六、Roth IRA 与 401(k) 的关系

1. 本质区别

维度 Roth IRA 401(k)
谁提供 你自己开（通过券商） 雇主提供（公司计划）
收入上限 有（MAGI 限制） 无
贡献上限 (2026) $7,500（50+ 加 $1,100） $23,500（50+ 加 $8,000）
雇主匹配 ❌ 无 ✅ 有（这是最大优势）
取款灵活性 高（本金随时取） 低（59½ 前取要罚）
RMD 无 73 岁起强制
投资选择 券商提供的所有证券 公司计划提供的有限基金列表
贷款 ❌ 不能借 ✅ 部分计划允许

2. 它们如何配合？

最佳策略通常是「两个都用」：

第一步：401(k) 存到拿满雇主匹配（免费的钱，不拿白不拿）
第二步：Roth IRA 存满 $7,500（免税增长 + 灵活取款）
第三步：如果还有余钱 → 继续加 401(k) 或传统 IRA

3. Roth 401(k) vs Roth IRA

  • Roth 401(k)：雇主计划里的 Roth 选项，没有收入上限，但取款规则更严格（59½ 前取要罚）。
  • Roth IRA：自己开的，有收入上限，但本金随时可取。
  • 两者可以同时存在，贡献上限各自独立。

4. 收入太高不能直接存 Roth IRA？

  • 用 Roth 401(k)（无收入上限）
  • 或用 Backdoor Roth IRA（传统 IRA → 转换 Roth）

来源：Fidelity Learn「What is a Roth IRA」+ IRS「401(k) plans」。

七、怎么确认自己已经拿满了公司 401(k) 匹配

这是很多人白白丢钱的地方。雇主匹配（Employer Match）是免费的钱，不拿就没了。

1. 先搞清楚公司的匹配公式

常见的匹配公式有几种：

公式类型 例子 说明
50% 匹配，上限 6% 你存 6% 工资 → 公司配 3% 最常见
100% 匹配，上限 4% 你存 4% 工资 → 公司配 4% 也很常见
100% 匹配，上限 5% 你存 5% 工资 → 公司配 5%
Safe Harbor 公司直接给 3%（不管你是否存）+ 额外匹配 联邦税法要求

2. 怎么算自己该存多少？

公式：你的贡献 % × 你的工资 = 你的贡献额；公司匹配 % × 你的工资 = 公司给的

举例：

  • 你年薪 $100,000
  • 公司政策：50% 匹配，上限 6%
  • 你要拿满匹配 → 需要存 6% × $100,000 = $6,000
  • 公司给你配 3% × $100,000 = $3,000（免费的钱！）

如果你只存了 4%：

  • 你存了 $4,000
  • 公司只配 2% = $2,000
  • 你丢了 $1,000 的免费匹配！

3. 怎么确认自己拿满了？

方法一：看工资单 (Pay Stub)

  • 找「401(k) Employee Contribution」和「401(k) Employer Match」两行
  • 确认雇主匹配金额 = 公司政策规定的上限
  • 如果匹配金额 < 上限 → 你还没存够

方法二：登录 401(k) 账户（Fidelity NetBenefits / Vanguard / Schwab 等）

  • 查看「Contribution History」或「Match Detail」
  • 对比你的贡献 % 和公司匹配 %
  • 确认匹配是否达到上限

方法三：问 HR / 财务部门

  • 直接问：「我们的 401(k) match 公式是什么？我存多少才能拿满？」
  • 这是最可靠的方式

方法四：看公司 401(k) 计划文件 (Summary Plan Description, SPD)

  • 入职时应该给过你，或 HR 系统里能下载
  • 里面会写明匹配公式、上限、vesting schedule（归属期）

4. ⚠️ 注意 Vesting Schedule（归属期）

  • 雇主匹配的钱不一定立刻完全属于你
  • 很多公司有 Vesting Schedule（如 3 年 100% 归属，或每年 25% 递增）
  • 如果你中途离职，未归属的匹配部分会被公司收回
  • 查清楚你的 vesting schedule！

5. 实操清单 ✅

  • [ ] 确认公司匹配公式（50%/6%？100%/4%？）
  • [ ] 计算拿满匹配需要的贡献 %
  • [ ] 在 401(k) 系统里把贡献 % 调到那个数字
  • [ ] 看工资单确认雇主匹配金额 = 上限
  • [ ] 查 vesting schedule，了解归属期
  • [ ] 每年工资调整后重新计算（匹配通常是工资的百分比）
