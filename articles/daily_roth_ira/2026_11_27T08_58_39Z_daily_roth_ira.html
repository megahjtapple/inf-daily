Roth IRA 与 401K：投资、省税与取款规则

生成时间：2026-11-27（UTC） 覆盖范围：Roth IRA 怎么投资、怎么省税、取利润/取本金的限制；Roth IRA 与 401K 的关系；如何确认已拿满公司 401K 匹配（match） 来源说明：核心规则来自 IRS 官方页面与 Fidelity 学习中心（2026-04-29 更新），401K 匹配机制参考 Otto 指南（2026-04-01）。具体数值以当年 IRS 公告为准。 诚实声明：本文不构成税务或投资建议；涉及个人决策请咨询持牌财务顾问/税务专业人士。

一、怎么使用 Roth IRA 进行投资

Roth IRA 是一种个人退休账户（Individual Retirement Account），由你个人开设，不是公司福利。核心特点是「先交税、后增值、取款免税」。

1. 基本机制

  • 资金来源：用**缴过税的现金（after-tax dollars）**存入。存入时不享受税前抵扣，但换来未来取款免税。
  • 投资方式：可投股票、债券、共同基金、ETF 等，具体品种取决于你开户的券商/金融机构。投资风险由你自己承担。
  • 收入门槛（MAGI）：能否直接存入 Roth IRA 取决于你的**调整后总收入（MAGI）**和申报状态。2026 年：
    • 单身：MAGI < $153,000 可全额存；$153,000–$168,000 部分存；≥ $168,000 不能直接存。
    • 夫妻联合申报：< $242,000 全额；$242,000–$252,000 部分；≥ $252,000 不能直接存。
    • 收入超限的替代方案：Roth 401(k)（无收入上限）或 backdoor Roth IRA（先存传统 IRA 再转入 Roth）。

2. 2026 年贡献上限

  • 每年可贡献 $7,500；50 岁及以上可追加 $1,100（合计 $8,600）。
  • Roth IRA 与传统 IRA 共用同一上限：两个账户加起来不能超过年度总额，不能各自都存满。
  • 配偶有独立上限；无收入的配偶可用工作配偶的收入来贡献。

3. 怎么省税（Roth IRA 的税收优势）

  • 增值免税：投资增长在账户内免资本利得税。
  • 合格取款免税：达到 59½ 岁且账户满 5 年后，取出本金和利润都不缴所得税。
  • 无 RMD（强制最低取款）：Roth IRA 不受强制最低取款限制（原始持有人），可以一直持有、继续增值；传统 IRA/401K 到 73 岁必须开始取款。
  • 遗产传承免税：传给配偶/继承人时，只要账户满 5 年，通常可免税取出（非配偶继承人一般需在 10 年内取完）。
  • 适合人群：当前税率较低、或希望锁定「未来确定免税」的人。

4. 取钱限制（本金 vs 利润）

取出对象 规则
本金（你自己存入的钱） 随时可取，不缴税、不罚款——这是 Roth IRA 最大的灵活性
利润（增值部分） 需满足「59½ 岁 + 账户满 5 年」才免税；否则视为非合格取款，可能缴税 + 10% 罚款
  • 5 年规则：从你首笔贡献所在税年的年初起算，不是从开始取款起算。即使已满 59½，若账户不满 5 年，取出的利润仍可能缴税/罚款。
  • 10% 罚款的常见例外（可免罚但未必免税）：
    • 首次购房（一次性上限通常 $10,000）
    • 永久且完全残疾
    • 符合规定的教育费用
    • 重大医疗费用等特定情况

关键区别：传统 IRA/401K 在 59½ 岁前提前取款，本金和利润都可能被罚款；而 Roth IRA 的本金永远可以无税无罚取出。

二、Roth IRA 与 401K 的关系

两者是互补而非替代的退休储蓄工具，可以同时持有。

项目 Roth IRA 401K（含 Roth 401K）
来源 个人自开 公司福利计划
缴税方式 缴过税（after-tax），取款免税 传统 401K 税前（pre-tax）；Roth 401K 缴过税
2026 年员工贡献上限 $7,500（50+ 追加 $1,100） 约 $24,500（50+ 追加更高，具体以 IRS 当年公告为准）
雇主匹配 无 有——这是 401K 最大优势
收入上限 有（MAGI 限制直接存入） 无（Roth 401K 不受 MAGI 限制）
投资灵活性 宽，几乎所有品种 受计划文件限制，选择较窄
取款限制 本金随时可取；利润 59½+5 年免税 59½ 岁前一般罚 10% + 税（有例外）
RMD 无（原始持有人） 有（73 岁起强制取款）

关系要点：

  • 401K 优先拿满匹配：因为雇主匹配是「免费的钱」，应先把 401K 存到能拿满 match 的水平。
  • Roth IRA 补足：拿满 match 后，若还有储蓄能力，再考虑 Roth IRA（享受免税增值 + 无 RMD）。
  • 收入太高不能直接存 Roth IRA？ 可用 Roth 401K 或 backdoor Roth IRA 实现同样的免税效果。
  • 注意：即使你选 Roth 401K，雇主匹配部分默认仍进入传统（pre-tax）账户，取款时这部分要缴税。

三、怎么确定自己已经拿满了公司能给的所有 401K 匹配？

雇主匹配是「有条件的奖金」——你必须先存够一定比例，公司才给。没拿满 = 主动放弃一部分工资。

1. 先搞清楚你公司的匹配公式

常见四种结构（以 $60,000 年薪为例）：

公式类型 例子 最大匹配
一对一（dollar-for-dollar） 100% 匹配，上限工资的 4% $2,400/年
部分匹配（最常见） 50% 匹配，上限工资的 6% $1,800/年
分层（tiered） 前 3% 匹配 100%，再 2% 匹配 50% $2,400/年
拉伸（stretch） 25% 匹配，上限工资的 12% $1,800/年

计算公式：雇主匹配 =（你的贡献比例 × 匹配率）× 你的工资

2. 确认拿满 match 的三步（30 分钟内可完成）

  1. 查你计划的匹配公式：在员工福利门户（benefits portal）或计划摘要（plan summary / SPD）里找到「match formula」。
  2. 看你今年已贡献多少：对照匹配公式，算出要拿满 match 需要存工资的百分之几。
  3. 调整你的贡献比例：把 401K 存款比例调到「拿满 match」所需的水平（例如 50% 匹配上限 6%，你就至少存 6%）。

3. 关键提醒

  • 雇主匹配不计入你的个人贡献上限：你的 $24,500 上限只管你自己存的部分，match 是额外叠加的。
  • Vesting（归属）规则：雇主匹配的钱可能不是立刻完全属于你。很多公司有 vesting schedule——离职太早会失去部分或全部 match。自己存的部分永远 100% 属于你。离职前务必查 vesting 状态。
  • 没拿满的代价：少存 1% 可能就少拿几百到上千美元/年的匹配，20 年复利下来可能损失数万美元。

四、行动清单（按优先级）

  1. ✅ 查公司 401K 匹配公式 → 把存款比例调到拿满 match 的水平（最高优先级，免费的钱）。
  2. ✅ 确认 vesting 状态，避免离职损失 match。
  3. ✅ 拿满 match 后，若还有储蓄能力且 MAGI 在上限内 → 存 Roth IRA（$7,500/年）。
  4. ✅ 收入超限不能直接存 Roth IRA → 考虑 Roth 401K 或 backdoor Roth IRA。
  5. ✅ 记住 Roth IRA 本金随时可取、利润需 59½+5 年免税，灵活应对应急需求。
