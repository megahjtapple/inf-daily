一、Roth IRA 是什么，怎么投资

1.1 基本定义

Roth IRA（罗斯个人退休账户）是一种用税后钱（after-tax dollars）存入的个人退休账户。核心特点是：

  • 存入时不减税（不能像传统 IRA / 传统 401(k) 那样在存入当年抵扣所得税）。
  • 账户内投资收益免税增长（tax-free growth）。
  • 符合条件取出时，本金和收益都免税、免罚（qualified distribution）。

来源：IRS「Roth IRAs」页面；Investopedia「Roth IRA: What It Is and How to Open One」。

1.2 怎么投资（可投什么）

Roth IRA 本身只是一个"容器"，你必须在里面配置具体资产。常见可投品种：

类别 说明
指数基金 / ETF 最主流、费用低、分散度高，适合大多数人（如标普500、全市场指数）
共同基金（Mutual Funds） 主动或被动管理型
个股（Stocks） 风险较高，需自行研究
债券 / CD / 货币市场基金 偏稳健、低波动
加密货币 法律上允许，但多数托管机构限制；且传统 IRA 里加密收益会被当短期普通收入征税，Roth 里若合规取出可免税（来源：Investopedia 引述 Ed Slott）
自定向 Roth IRA（SDIRA） 通过专门托管人可投黄金、房地产、合伙权益等另类资产

禁止投资： 人寿保险、收藏品、S 型公司（S-corp）股票、非美国财政部铸造的硬币。

来源：Investopedia「Allowable Investments in a Roth IRA」。

1.3 怎么开户 / 选平台

  • 必须开在 IRS 批准的机构：银行、券商、联邦保险信用合作社等。
  • 常见低费用平台（Investopedia 对比表）：Fidelity（$0 起投，股票/ETF 交易 $0）、Vanguard（$0 起投，股票/ETF $0）、E*Trade、Interactive Brokers、Wealthfront（自动投资，$500 起）。
  • 选平台时重点看：交易费用、最低开户额、是否有账户不活跃费、投资品种丰富度。

来源：Investopedia「Opening a Roth IRA」及「Compare the Best Roth IRA Accounts」。

1.4 2026 年存入限额与收入资格

年度存入上限（2026）：

  • 50 岁以下：$7,500
  • 50 岁及以上（含 catch-up）：$8,600

注意：这个上限是所有 IRA（Roth + 传统）合计的，不是每个账户单独算。

收入资格（MAGI，2026）：

报税身份 全额可存 部分可存（phase-out）
单身 / 户主 MAGI < $153,000 $153,000 – $168,000
已婚联合报税 MAGI < $242,000 $242,000 – $252,000
已婚分开报税（当年与配偶同住） $0 < $10,000

来源：Investopedia「Who's Eligible for a Roth IRA?」2026 表格；NerdWallet「2026 Roth IRA Contribution and Income Limits」。

关键前提： 必须有**应税收入（earned income）**才能存入，且存入额不能超过当年应税收入。被动收入（房租、利息、股息、养老金）不能用来存 Roth IRA。

二、怎么省税（核心机制）

Roth IRA 的"省税"逻辑是把税负从"取出时"挪到"存入前"，具体有以下几点：

2.1 投资收益免税增长 + 免税取出

  • 账户内所有资本利得、股息、利息逐年免税复利（不像普通应税账户每年要交资本利得税）。
  • 满足条件取出时，本金 + 收益全部免联邦所得税。
  • 华盛顿州没有州所得税，所以 Roth IRA 取出的钱在 WA 州也完全免税（传统 IRA/401(k) 取出时虽免联邦税，但同样免 WA 州税——WA 无州所得税）。

来源：Fidelity「What is a Roth IRA and how does it work?」；IRS。

2.2 没有 RMD（强制最低取出）

  • Roth IRA 终身不需要强制取出（no required minimum distributions during your lifetime），而传统 IRA / 401(k) 到 73 岁起必须每年取最低额度。
  • 好处：可以让钱继续免税复利，或作为遗产免税传给继承人。

来源：Investopedia「Key Takeaways」；Fidelity。

2.3 适合谁（省税最优场景）

  • 预期退休后税率更高的人（如年轻人、收入上升期）——Roth 更划算，因为锁定的是"现在较低的税率"。
  • 想留遗产免税的人。
  • 想灵活提前动用本金的人（见第四部分）。

来源：Investopedia「Is It Better to Invest in a Roth IRA or a 401(k)?」。

2.4 省税策略要点（实操）

  1. 先拿满 401(k) match（免费钱），再存 Roth IRA——match 是 100% 回报，优先级最高。
  2. 用低费用指数基金/ETF，降低长期拖累收益的费用。
  3. 尽早开始，让免税复利最大化（时间 > 择时）。
  4. 高收入者若超过 Roth 收入上限，可考虑"后门 Roth（Backdoor Roth）"：先存传统 IRA（不抵扣），再转入 Roth IRA（需咨询 CPA，避免"pro-rata rule"复杂化）。

来源：Fidelity「How to maximize tax-advantaged savings」；Investopedia。

三、取出"投资收益"的限制

这是 Roth IRA 最容易被误解的地方。本金和收益的取出规则完全不同。

3.1 什么是"合格取出（Qualified Distribution）"

要免税免罚取出收益，必须同时满足两个条件：

  1. 账户已开满 5 年（five-year rule，从你首次存入第一个 Roth IRA 那年算起）；并且
  2. 满足以下任一情形：
    • 年龄 ≥ 59½；
    • 用于购买/建造/重建首套房（终身限额 $10,000）；
    • 持有人残疾；
    • 持有人去世后由受益人取出。

来源：Investopedia「Withdrawals: Qualified Distributions」；IRS Publication 590-B。

3.2 五年期规则（Five-Year Rule）详解

情形 是否满足 5 年 收益的税务后果
≥ 59½ 岁 ✅ 满足 免税免罚
< 59½ 岁 ✅ 满足 收益要交税 + 10% 罚金（除非残疾/首套房等例外）
≥ 59½ 岁 ❌ 未满足 收益要交税，但免 10% 罚金
< 59½ 岁 ❌ 未满足 收益要交税 + 10% 罚金（首套房等例外可免罚金但不免税）

来源：Investopedia「The Five-Year Rule」。

3.3 可免罚金的例外情形（非合格取出，但免 10% 罚金）

即使不满足 59½ + 5 年，以下用途可免 10% 罚金（但收益仍可能要交税）：

  • 未报销的医疗费用（超过 AGI 的 7.5% 部分）；
  • 失业后支付医疗保险费；
  • 合格的高等教育费用（学费、书本、设备，须当年使用）；
  • 生育或收养（1 年内，限额 $5,000）。

来源：Investopedia「Withdrawals: Non-Qualified Distributions」。

3.4 FIFO 原则（先进先出）

Roth IRA 取出时按 FIFO（先进先出） 顺序：先取本金，再取收益。也就是说，在你把所有本金都取完之前，不会碰到任何收益——所以提前动用 Roth IRA 时，通常可以先无税无罚地拿回本金。

来源：Investopedia「Important」段落。

四、取出"本金"的限制

4.1 核心结论：本金几乎随时可取

  • 你可以随时取出自己存入的本金（contributions），无论年龄、无论账户开了多久，都免税、免 10% 罚金。
  • 这是 Roth IRA 相对传统 IRA / 401(k) 最大的灵活性优势。

来源：Investopedia「Key Takeaways」第 2 条；Fidelity。

4.2 唯一注意点

  • 你只能取出累计已存入的本金总额（不含收益）。例如你历年共存入 $30,000，那么最多可无税无罚取出 $30,000 本金。
  • 若当年存入 $5,000 并产生 $500 收益，你可以无税无罚取出 $5,000 本金，但那 $500 收益会被当作应税收入。

来源：Investopedia「Non-Qualified Distributions」段落。

4.3 对比：传统 IRA / 401(k) 取本金

  • 传统账户在 59½ 岁前取出（含本金）要交所得税 + 10% 罚金（有少数例外）。
  • 所以 Roth IRA 的"本金随时可取"是它作为应急/灵活资金池的独特价值。

来源：Investopedia「Roth IRA vs. Traditional IRA」。

五、Roth IRA 与 401(k) 的关系

5.1 两者是互补的，不是二选一

维度 Roth IRA 401(k)（传统） Roth 401(k)
存入时减税 ❌ 不减税（税后钱） ✅ 税前存入，当年抵税 ❌ 不减税
取出时 ✅ 合格取出免税 ❌ 取出交所得税 ✅ 合格取出免税
公司 match ❌ 无 ✅ 有（免费钱） ✅ 有
年度限额（2026） $7,500（50+ $8,600） $24,500（50+ 可加 $8,000 catch-up） $24,500
收入上限 ✅ 有（MAGI 限制） ❌ 无 ❌ 无
投资选择 多、灵活 较少（公司菜单） 较少
RMD（强制取出） ❌ 终身无 ✅ 73 岁起有 ✅ 有（可转 Roth IRA 消除）
提前取本金 ✅ 随时免税免罚 ❌ 59½ 前取要税+罚金 ❌ 同传统 401(k)

来源：Investopedia「Is It Better to Invest in a Roth IRA or a 401(k)?」；Fidelity「401(k) contribution limits for 2026」。

5.2 关键关系要点

  1. 限额独立：Roth IRA 的 $7,500 和 401(k) 的 $24,500 是分开计算的，可以同时存满——这是最大化退休储蓄的关键。
  2. match 只在 401(k)：公司 match 只发生在 401(k)，Roth IRA 没有 match。所以先拿满 401(k) match，再考虑 Roth IRA。
  3. 高收入者：若超过 Roth IRA 收入上限，仍可存 401(k)（无收入限制），或走"后门 Roth"。
  4. Roth 401(k) → Roth IRA 转换：可把 Roth 401(k) 转入 Roth IRA，从而消除 RMD（73 岁起不必强制取出）。
  5. 传统 401(k) → Roth IRA 转换（Roth Conversion）：需就转换金额交当年所得税，但之后在 Roth IRA 里免税增长、无 RMD。

来源：Investopedia「Roth IRA vs. Traditional IRA」；Fidelity。

5.3 推荐的"存钱顺序"（通用框架）

  1. 第一步： 401(k) 存到拿满公司 match 为止（免费钱，100% 回报）。
  2. 第二步： 存满 Roth IRA $7,500（或 $8,600）。
  3. 第三步： 若还有余力且预期退休后税率更高，继续加 401(k)（传统或 Roth 401(k)）直到 $24,500。
  4. 第四步： 考虑 HSA、应税账户等。

来源：Fidelity「How to maximize tax-advantaged savings」；Investopedia。

六、怎么确认自己已经拿满公司 401(k) match

这是最容易"白白丢钱"的地方。公司 match 是免费的钱，没拿满等于放弃回报。

6.1 先搞清楚你公司的 match 规则

不同公司 match 方式不同，常见三种：

Match 类型 规则示例 说明
1:1 全额匹配（Dollar-for-dollar） 你存工资的 5%，公司也配 5% 最慷慨；通常有上限（如最多配到工资的 5%）
50¢ on the dollar（半额匹配） 你存 6%，公司配 3% 需存更多才能拿满同等 match
Safe Harbor（安全港） 固定配 3% + 你存的部分配 50%（上限 4%） 联邦税法规定的最低标准

来源：Kiplinger「Average 401(k) Match」；IRS「401(k) plans」。

6.2 怎么确认自己拿满了（实操步骤）

第 1 步：查你的 match 公式

  • 看 员工手册 / HR 的 401(k) 计划文件（Summary Plan Description, SPD）。
  • 或登录 401(k) 账户门户（Fidelity NetBenefits、Empower、ADP、Principal 等），里面通常有 match 说明。
  • 或直接问 HR / 薪酬部门："我们的 401(k) match 公式是什么？上限是多少？"

第 2 步：算出"拿满 match 需要存多少"

  • 例 1（1:1，上限 5%）：你年薪 $80,000，公司 1:1 匹配、上限工资的 5% → 你需存 5%（$4,000） 才能拿满 match（公司再配 $4,000）。
  • 例 2（50¢ on the dollar，上限 6%）：公司配你存入额的 50%，上限工资的 6% → 你需存 12% 才能拿满 6% 的 match。
  • 例 3（Safe Harbor）：固定 3% + 你存的 50%（上限 4%）→ 你需存 8% 才能拿满 4% 的可变部分（加上固定 3%，共 7%）。

第 3 步：核对你的实际存入比例

  • 登录 401(k) 门户，看你的 deferral rate（递延比例） 是否 ≥ 上面算出的"拿满所需比例"。
  • 若低于该比例 → 你在丢免费钱，应调高到拿满 match 的水平。

第 4 步：核对实际到账的 match 金额

  • 在账户里看 "Employer Match / Employer Contribution" 这一栏，确认公司确实按公式配了钱。
  • 若比例够但 match 没到账 → 找 HR 处理（可能是入职未满一年、vesting 未成熟等）。

6.3 注意：Vesting（归属期）

  • 很多公司对 match 有 vesting schedule（如 3 年或 6 年逐步归属）。
  • 若你在 vesting 完成前离职，未归属的 match 会被公司收回。
  • 查 SPD 里的 vesting 条款，确认你的 match 已 100% 归属。

来源：Kiplinger「Average 401(k) Match」；IRS「401(k) plans」。

6.4 快速自检清单

  • [ ] 我知道公司的 match 公式（1:1 / 50¢ / Safe Harbor）和上限？
  • [ ] 我算出了"拿满 match 需要存工资的百分之几"？
  • [ ] 我的 401(k) 递延比例 ≥ 该百分比？
  • [ ] 账户里能看到公司实际配了 match 金额？
  • [ ] 我的 match 已 100% vesting（归属）？
