1. Roth IRA 怎么省税（核心机制）

热度/类别： 🔥🔥🔥🔥🔥 / 省税机制

话题简介： Roth IRA 的省税逻辑是「先交税、后免税」——用已经交过所得税的钱投入，投资增值免税，符合条件取出收益也免税。

详细内容：

  • 税后投入（no deduction）： 你投入 Roth IRA 的钱是「after-tax dollars」（已缴税的钱），因此当年不能像传统 IRA 那样抵扣所得税。来源：IRS 明确写 "You cannot deduct contributions to a Roth IRA."
  • 免税增长（tax-free growth）： 账户内的投资收益在持有期间免税累积。
  • 免税取出（qualified distribution）： 满足两个条件后，取出「收益」也完全免税免罚：
    1. 你已满 59½ 岁；
    2. 账户自「首次贡献所在税年的开始」起已持有 至少 5 年。
  • 省税的本质： 相当于把「未来不确定的税率」锁定为「0」。如果你预期退休后税率会更高（或想规避税率上涨风险），Roth 比传统 IRA 更划算。
  • 无 RMD（强制最低取款）： Roth IRA 不受 Required Minimum Distributions 约束（原始账户持有人），可以一直放着免税增值，甚至传给继承人——这是它相对 401(k)/传统 IRA 的一大省税优势。

2. 取「本金」vs 取「收益」的限制（最关键的区别）

热度/类别： 🔥🔥🔥🔥🔥 / 取款限制

话题简介： Roth IRA 的取钱规则要分两层看——你投入的「本金（contributions）」和账户赚到的「收益（earnings）」，两者的税务待遇完全不同。

详细内容：

2.1 取出「本金」（Contributions）

  • 随时可取、免税、免罚。 因为你投入时已经交过税了，所以无论何时、是否退休，取出自己投入的本金都不需要再交税或付罚金。
  • 这意味着 Roth IRA 可以兼作「应急资金池」——你希望永远用不上，但真急用时能无成本取回本金。

2.2 取出「收益」（Earnings）

  • 受「5 年规则 + 59½ 岁」双重限制。 只有同时满足：(a) 已满 59½ 岁；(b) 账户自首次贡献所在税年起满 5 年——取出的收益才免税免罚（qualified distribution）。
  • 不满足条件 = nonqualified distribution（非合格取款）： 取出的「收益」部分可能要交所得税，还可能被加收 10% 提前取款罚金（两者可能同时适用）。
  • 例外（可免罚但未必免税）： 以下情况即使未满 59½ 岁也可免罚取出：
    • 首次购房（qualified first home purchase），上限 $10,000；
    • 永久且完全残疾（permanent and total disability）；
    • 合格的教育费用（qualified educational expenses）。

⚠️ 重要提醒： 取钱顺序上，IRS/Fidelity 的规则是「先出本金、后出收益」的口径来判定税务。即使账户里本金和收益混在一起，你取出的金额中属于「本金」的部分永远免税免罚；只有超出本金、落到「收益」的部分才受 5 年规则约束。

3. Roth IRA 与 401(k) 的关系

热度/类别： 🔥🔥🔥🔥🔥 / 账户关系

话题简介： 两者是「互补」而非「互斥」——贡献限额完全独立，税收待遇相反，组合使用能最大化税务灵活性。

详细内容：

  • 贡献限额相互独立： 有 401(k) 不影响你往 Roth IRA 存钱的资格；两个账户各有自己的年度上限，参与一个不会减少另一个的额度。
  • 关键差异——收入门槛：
    • 401(k)：没有收入上限（任何人都能按限额投）。
    • Roth IRA：有 MAGI（调整后总收入）门槛，超过一定收入就不能直接投（见第 5 节）。
  • 税收待遇相反（这正是组合的意义）：
    • 401(k) / 传统 IRA： 现在抵扣税（省今天的税），退休后取出时按普通收入交税。
    • Roth IRA： 现在不抵扣，退休后取出免税。
  • 税收多元化（tax diversification）的好处： 同时持有两类账户，可以在退休后精确控制应税收入——比如在高收入年份从 Roth 取钱，避免把自己推进更高的税率档。
  • 401(k) 贡献能「拉低」你的 MAGI： 因为 401(k) 是税前扣除，会降低你的 AGI/MAGI。如果你刚好卡在 Roth IRA 收入门槛附近，多投一点 401(k) 可能把你的 MAGI 拉回门槛以下，从而重新获得全额/部分 Roth IRA 贡献资格。
  • 无 RMD 压力： 73 岁起传统 401(k) 强制取款（可能推高税单），而 Roth IRA 不受 RMD 约束，可一直免税增值。

4. 怎么确认自己已经拿满公司能给的 401(k) match

热度/类别： 🔥🔥🔥🔥🔥 / 实操核查

话题简介： 公司 match（雇主配比）相当于「白送的钱」，是任何账户都给不了的即时回报。确认拿满的方法是把「你的贡献比例」和「公司的 match 公式」对齐。

详细内容：

  1. 查清公司的 match 公式（最关键一步）。 常见形式：
    • 50% 配比，上限 6%： 你每投 1%，公司配 0.5%，最多配到你工资的 6%（即你需投满 6% 才拿满）。
    • 100% 配比，上限 3% 或 4%： 你投 1% 公司配 1%，最多配到 3%/4%。
    • 公式通常写在员工手册 / HR 的 401(k) plan document（计划文件）里。 找 HR 要「plan summary」或直接问："What is our employer match formula and the maximum match percentage?"
  2. 查你当前的贡献比例。 登录 payroll（薪资系统）/ 401(k) 账户后台，看你现在设的是工资的百分之几。
  3. 对齐判断：
    • 如果你的贡献比例 ≥ 公司 match 的上限百分比 → 你已经拿满 match ✅
    • 如果 < 上限 → 你正在「丢钱」，应把贡献比例提到上限（或更高）才能拿满。
  4. 核对实际到账。 在 401(k) 账户里看「employer contributions / match」这一栏，确认每期确实有公司配的钱进来；如果比例够但没到账，找 HR/plan administrator 排查。
  5. 注意 vesting（归属期）。 公司 match 的钱可能有归属期（vesting schedule）——你离职时未必能全部带走。查清你的 vested balance（已归属余额）和 vesting schedule，避免误以为「match 全归我」。

💡 实操口诀： 「先拿满公司 match（即时 50%–100% 回报），再把剩余的钱投 Roth IRA 做免税增长」——这是多数人的最优顺序。

Source References:

  • The Motley Fool — Can I Contribute to Both a 401(k) and a Roth IRA?（"Maximizing employer match first" 段落）
  • Fidelity — What is a Roth IRA and how does it work?

⚠️ 诚实声明： 具体 match 公式因公司而异，以上「50%/6%」「100%/3–4%」是行业常见示例，你的真实公式必须以你自己公司的 plan document / HR 提供的文件为准。vesting 规则同样因公司而异。

5. 2026 年 Roth IRA 贡献限额与收入（MAGI）门槛

热度/类别： 🔥🔥🔥🔥 / 限额规则

话题简介： 能投多少、能不能投，由「年度贡献上限」和「你的 MAGI + 报税身份」共同决定。

详细内容：

  • 年度贡献上限（2026）：
    • 50 岁以下：$7,500
    • 50 岁及以上：可额外加投 $1,100 catch-up（合计 $8,600）
    • ⚠️ 注意：Fidelity 与 Motley Fool 对 2026 基础限额的表述略有出入（Fidelity 写 $7,500，Motley Fool 表格写 $8,000）。以 IRS 当年官方公告为准——这是「待核实」项。
  • 收入（MAGI）门槛（2026）：
    • 单身 / 户主 / 分居（未与配偶同住）： MAGI < $153,000 可全额投；$153,000–$168,000 部分投；≥ $168,000 不能直接投。
    • 已婚联合申报（MFS 未同住）： MAGI < $242,000 全额；$242,000–$252,000 部分；≥ $252,000 不能直接投。
    • 已婚分居且与配偶同住： 不能直接投（$0）。
  • 限额是「所有 IRA 共享」的： 传统 IRA + Roth IRA 合计不超过年度上限，不是每个账户各算一份。
  • 收入门槛只限制「新贡献」： 过去已开的 Roth IRA 账户可继续持有和投资余额，只是当年 MAGI 超标时不能再新增贡献。

6. 高收入者的替代方案：Backdoor Roth / Roth 401(k)

热度/类别： 🔥🔥🔥 / 进阶策略

话题简介： MAGI 超过门槛、不能直接投 Roth IRA 的人，仍有两条路拿到同样的「免税增长」待遇。

详细内容：

  • Roth 401(k)： 如果公司提供 Roth 401(k) 选项（或你是自雇者），可以走这条路——享受 Roth 的免税增长，且没有收入限制。
  • Backdoor Roth IRA： 先往传统 IRA 做「不可抵扣贡献（nondeductible contribution）」，再把这些钱转换成 Roth IRA。
    • ⚠️ pro rata（按比例）规则陷阱： 如果你还有其他含税前贡献的 IRA 账户，转换时会被按比例征税，使 backdoor 失效。解决办法：把税前 IRA 资金先 roll over 进 401(k)，再做 backdoor 转换。
  • Mega-Backdoor Roth： 部分公司允许通过 401(k) 做更大的 after-tax 贡献并转换（「Mega-Backdoor」），适合高收入者放大 Roth 额度。

7. 投资方式与长期持有优势

热度/类别： 🔥🔥🔥 / 投资方式

话题简介： Roth IRA 里能投什么、怎么投，以及它「无 RMD、可传代」的长期优势。

详细内容：

  • 可投资范围： 股票、债券、共同基金（mutual funds）、ETF 等——具体取决于你在哪家券商/金融机构开户，以及该机构提供的产品。
  • 开户三步： (1) 选一家券商/投资公司；(2) 注资（银行转账 / ACH / wire）；(3) 把资金投进你选定的证券。
  • 长期持有优势：
    • 无 RMD： 可以一直放着免税增值，不必在 73 岁被迫取出。
    • 传代/遗产规划： 配偶继承人在账户满 5 年后仍可享受免税增长与取出；多数非配偶继承人需在 10 年内清空，但只要账户满 5 年，收益和取出仍可免税。
  • 投资风格建议（一般性）： 年轻、离退休远 → 可偏股票/成长型；临近退休 → 逐步加入债券降低波动。具体配置应结合你的风险承受度与时间跨度，咨询专业人士。
