一、Roth IRA 是什么、怎么投资

1.1 核心概念

Roth IRA（罗斯个人退休账户）是一种税后退休储蓄账户：

  • 存入时： 用已经交过税的钱（after-tax dollars）存入，不能抵税。
  • 增值时： 账户内的投资收益免税增长（tax-free growth）。
  • 取出时： 满足条件后，本金和收益都免税、免罚取出。

这与 Traditional IRA / 401(k) 正好相反——后者是"税前存入、取出时交税"。Roth 把税负从"取出端"挪到了"存入端"。

来源：IRS《Roth IRAs》(irs.gov/retirement-plans/roth-iras)、Fidelity《What is a Roth IRA and how does it work?》

1.2 怎么投资（实操步骤）

第 1 步：开户。 在券商处开立 Roth IRA，常见选择：

  • Fidelity / Schwab / Vanguard — 佣金低、基金选择全
  • M1 Finance / Webull / Robinhood — 界面简单，适合小额
  • 注意：Roth IRA 是"账户类型"，不是"产品"。任何券商都能开，区别在于费率、基金种类和工具。

第 2 步：选投资标的。 Roth IRA 里可以买的东西和普通应税账户（taxable brokerage）几乎一样：

  • 指数基金 / ETF（最推荐新手）：如 VTI（全美股）、VOO（标普500）、VT+VXUS（全球）
  • 目标日期基金（Target Date Fund）：自动随年龄调整股债比例，"设一次就不用管"
  • 个股：可以买，但风险集中，不建议占大头
  • 债券基金 / CD：保守型配置

来源：U.S. News《7 Best Funds to Hold in a Roth IRA》、Fidelity《Roth IRA》

第 3 步：定期定额投入（Dollar-Cost Averaging）。 设定每月自动转账，避免择时。

第 4 步：再平衡（Rebalance）。 每年检查一次股债比例，偏离目标 ±5% 就调回来。

1.3 投资 Roth IRA 的"资产位置"策略（Asset Location）

一个进阶技巧：把"税务效率低"的高收益资产放进 Roth IRA。

  • Roth IRA 里赚的钱取出免税 → 适合放高增长、高分红、会产生较多应税事件的资产（如个股、REITs、高股息基金）。
  • Traditional IRA / 401(k) 里取出要交税 → 适合放**债券、Muni bonds（市政债）**等低收益、低应税事件的资产。

这样能最大化整体税后收益。

来源：Fidelity《How to maximize tax-advantaged savings》

二、怎么省税（税务优势与策略）

2.1 Roth IRA 的三大税务优势

优势 说明
取出免税 满足条件后，本金+收益全部免税取出（这是核心卖点）
无 RMD（强制最低取出） 活着的账户持有人不需要在 73 岁后强制取钱，可以继续免税增值、留给孩子
本金随时可取 存入的本金（contributions）任何时候取出都免税免罚，相当于"应急金"

来源：Fidelity《What is a Roth IRA and how does it work?》、IRS《Roth IRAs》

2.2 省税策略清单

  1. 先填满 401(k) match，再填 Roth IRA。 公司 match 是"免费的钱"，优先级最高（见第五节）。
  2. 收入低/预期未来税率更高时，优先 Roth。 现在用高税率的钱存，未来免税取出，锁定"低税率存入"。
  3. 收入太高不能直接开 Roth？用 Backdoor Roth。 先往 Traditional IRA 存一笔不可抵税的钱，再转（convert）成 Roth IRA，绕开收入上限。

    来源：Chase《What is a backdoor Roth IRA?》、Fidelity《backdoor Roth IRA》

  4. 把高收益资产放进 Roth（Asset Location）。 见 1.3。
  5. 用 Roth 的"本金随时可取"做应急。 遇到急用钱，先取本金（免税免罚），不动投资收益，避免触发税和罚。
  6. Roth 无 RMD，适合传承。 留给配偶/子女，5 年规则满足后收益也免税。

2.3 收入上限（MAGI）——决定你能不能直接开 Roth

Roth IRA 的新存入受 MAGI（调整后总收入）限制：

身份 2026 全额存入 部分存入区间 不可存入
单身 MAGI < $153,000 $153,000 – $168,000 ≥ $168,000
夫妻联合申报 MAGI < $242,000 $242,000 – $252,000 ≥ $252,000
  • 这些上限只限制"新存入"。以前开的账户可以继续持有、继续增值，只是当年不能再存。
  • IRA 总额上限是跨账户共享的：Traditional IRA + Roth IRA 加起来每年最多 $7,500（50 岁以上 +$1,100）。

来源：Fidelity《What is a Roth IRA and how does it work?》(2026-04-29)、IRS《Roth IRAs》

三、取出限制：本金 vs 投资收益

这是 Roth IRA 最容易被误解的地方。本金和收益的取出规则完全不同：

3.1 取出"本金"（Contributions）——几乎无限制

  • 任何时候都能取，免税、免罚。 即使你 20 岁存的钱，50 岁急用也能拿回来。
  • 原因：本金是你已经交过税的钱，政府不能再收一次。
  • 这是 Roth IRA 最大的灵活性——它天然可以当"应急金"。

来源：Fidelity《What is a Roth IRA and how does it work?》

3.2 取出"投资收益"（Earnings）——受"5 年规则 + 59½ 岁"双重限制

要免税免罚取出收益，必须同时满足两个条件：

  1. 账户已开满 5 年（从你第一次存入的那个税年的年初开始算，不是从某笔钱存入那天算）。
  2. 你已满 59½ 岁，或属于以下例外之一。

不满足时的后果： 取出收益属于"非合格分配"（nonqualified distribution），收益部分要交所得税 + 10% 提前取款罚金（本金仍免税免罚）。

3.3 可以"免罚但可能仍需交税"的例外（即使未满 59½）

  • 首次购房： 最多 $10,000（终身累计上限）
  • 永久且完全残疾
  • 合格的教育费用
  • 其他：某些医疗自付额、已故账户持有人等

来源：Fidelity《What is a Roth IRA and how does it work?》、NerdWallet《The Roth IRA 5-Year Rule: What to Know》、24/7 Wall St.《The 5-Year Roth Clock》

3.4 取出顺序（重要！）

Roth IRA 取钱时，默认先出本金，再出收益。所以：

  • 你取 $5,000，如果本金还有 $10,000 → 全部按"本金"处理，免税免罚。
  • 只有当本金取完、开始动收益时，才触发 5 年规则 / 59½ 岁的检查。

来源：Fidelity《What is a Roth IRA and how does it work?》

3.5 一句话总结

取出对象 免税？ 免罚？ 条件
本金 ✅ 永远 ✅ 永远 无
收益（合格） ✅ ✅ 满 5 年 且 满 59½ 岁（或例外）
收益（非合格） ❌ 要交税 ❌ 10% 罚金 未满 5 年 或 未满 59½ 岁（无例外）

四、Roth IRA 与 401(k) 的关系

4.1 核心区别

维度 Roth IRA 401(k)
谁提供 你自己开（券商） 雇主提供
存入时税务 税后（不抵税） 通常税前（抵税），或 Roth 401(k) 税后
取出时税务 合格取出免税 传统 401(k) 取出交税；Roth 401(k) 合格取出免税
收入上限 有（MAGI 限制） 无
公司 match ❌ 没有 ✅ 有（这是 401(k) 最大优势）
RMD 无（账户持有人活着时） 传统 401(k) 73 岁起强制；Roth 401(k) 生前无，死后受益人需取
本金随时可取 ✅ 可以 ❌ 不行（提前取有税+罚）
年度上限 $7,500（50+ 加 $1,100） 2026 个人 $24,500（50+ 加 catch-up）

来源：Fidelity《What is a Roth IRA and how does it work?》、IRS《401(k) plans》、CNBC《401(k) and IRA contribution limits for 2026》

4.2 它们如何配合（推荐顺序）

  1. 第一步：往 401(k) 存到"拿满公司 match"为止。 这是免费的钱，不拿等于放弃收入。
  2. 第二步：如果还有预算，填满 Roth IRA（$7,500）。 享受免税取出 + 无 RMD + 本金灵活。
  3. 第三步：如果还有预算，继续往 401(k) 存到上限。 传统 401(k) 能抵税，适合高收入者降低当年应税所得。
  4. 收入太高不能直接开 Roth？ 用 Backdoor Roth（见 2.2）。

来源：Kiplinger《Already Maxed Out Your 401(k) in 2026? Here's What to Do Next》、Fidelity《How to maximize tax-advantaged savings》

4.3 为什么两者都要有？

  • 401(k) 给你"公司 match + 高上限 + 抵税"。
  • Roth IRA 给你"免税取出 + 无 RMD + 本金灵活 + 传承优势"。
  • 两者税务处理不同，组合起来能覆盖"现在省税"和"未来省税"两种需求，是退休规划的标准配置。

五、怎么确认自己已经拿满了公司 401(k) match

这是很多人每年白白丢钱的地方。match 是雇主"免费"给你的钱，但只有你存够一定比例才给。

5.1 先搞清楚你的公司 match 公式

常见三种：

  • 按比例匹配（Dollar-for-dollar）： 你存工资的 3%，公司也存 3%；你存 6%，公司存 6%。
  • 封顶匹配（Capped）： 比如"你存 5%，公司最多补 3%"——你存再多，公司也只给 3%。
  • 分级匹配（Tiered）： 比如"你存 1–4%，公司补 50%；你存 5–6%，公司补 100%"。

去哪查：

  • 你的 401(k) 计划说明书（Plan Document / SPD）——HR 或 401(k) 服务商网站（Fidelity NetBenefits、ADP、Vanguard 等）能下载。
  • HR 的福利手册 / 入职材料。
  • 直接问 HR："我们的 match 公式是什么？封顶是多少？"

来源：Kiplinger《Average 401(k) Match: Do You Work for a Generous Company?》、Fidelity《What is a 401(k)?》

5.2 怎么算"拿满了"

步骤：

  1. 找到 match 公式里的"你至少要存工资的 X%"。
  2. 把你的 401(k) 存款比例设到 ≥ X%（通常建议直接设到封顶值，比如 6%）。
  3. 每年涨薪后重新检查——因为 match 是按工资百分比算的，涨薪后同样的美元数可能不够了。

举例：

  • 公司公式："你存工资的 5%，公司补 5%"（封顶 5%）。
  • 你月薪 $8,000 → 你要存 $400/月（5%）才能拿满 $400/月的 match。
  • 如果你只存 3%（$240），公司也只补 3%（$240），你每月白白丢掉 $160。

来源：CNBC《My 401(k) fully vests this month》、BetterUp《What 401(k) Employer Match Is and How It Works》

5.3 怎么验证"我真的拿满了"（实操核对）

  1. 登录 401(k) 账户（Fidelity NetBenefits / ADP / Vanguard 等）。
  2. 查看每月的对账单（statement），找两行：
    • Employee Contribution（你存的）
    • Employer Match（公司补的）
  3. 核对比例： 如果公司公式是"1:1 封顶 5%"，你的 Employee 和 Employer 两行应该相等（都到 5%）。如果 Employer 明显低于 Employee，说明你存超了但公司没多给（正常，因为封顶了）；如果 Employer 远低于预期，说明你没存够。
  4. 年度核对： 每年 1 月看上一年的总 match，对照公式算"理论最大值"，两者应一致。

来源：Fidelity NetBenefits、ADP mykplan（账户对账单）

5.4 别忽略"归属期"（Vesting）

  • 你存的本金：100% 归你，随时可取（受 401(k) 提前取款规则限制）。
  • 公司 match 的钱：可能不立即归你！很多公司有 vesting schedule（如"干满 3 年才 100% 归属"或"每年 20% 线性归属"）。
  • 风险： 如果你在公司 match 还没完全归属前离职，未归属的那部分会被公司收回。

来源：CNBC《That 'free' money in your 401(k) may not belong to you just yet》、24/7 Wall St.《The 401(k) Vesting Cliff That Cost One Worker $74,000》

怎么查 vesting：

  • 同样在 401(k) 计划说明书（SPD）里找 "Vesting" 章节。
  • 或对账单上通常有 Vested Balance vs Unvested Balance 两行。

5.5 一句话检查清单

  • [ ] 我知道公司的 match 公式（比例 + 封顶）。
  • [ ] 我的 401(k) 存款比例 ≥ 拿满 match 所需的最低比例。
  • [ ] 我每年涨薪后重新核对了比例。
  • [ ] 我对账单上 Employer Match 行符合公式预期。
  • [ ] 我知道公司的 vesting schedule，没在归属前离职丢掉钱。
