一、Roth IRA 怎么投资、怎么省税

1. Roth IRA 的本质：先交税，后免税

热度/类别： 省税机制 / 核心原理

话题简介： Roth IRA 是一种「税后账户」——你存入的是已经交过所得税的钱，因此账户内的投资收益可以免税增长，符合条件取出时收益也免税。

详细内容：

  • 存入的是税后美元（after-tax dollars），投资可投股票、债券、共同基金、ETF 等，具体取决于券商提供的产品。
  • 省税的核心逻辑：「现在不抵扣，将来不交税」。传统 IRA/401(k) 是「现在抵扣、取出时交税」；Roth 正好相反——锁定未来免税的确定性。
  • 适合人群：如果你预期退休后税率会更高（或想规避未来税率上涨风险），Roth 更划算。
  • Source References:

    • IRS — Roth IRAs

2. 投资方式：开户 → 注资 → 选标的

热度/类别： 实操 / 投资

话题简介： 开户流程简单，关键是选对券商和配置。

详细内容：

  1. 选券商/投资机构：Fidelity、Vanguard、Schwab 等都可开 Roth IRA，比较费用和可投产品。
  2. 注资（Fund）：最常见是从银行账户 ACH/电汇转入年度贡献额；也可从其他退休账户 rollover（注意转换可能立即产生税）。
  3. 投资：把钱投入券商提供的证券。常见稳健做法是低成本的指数基金/ETF 组合，按年龄和风险偏好配置股债比例。

3. 省税的三大优势（相对传统账户）

热度/类别： 省税机制 / 对比

话题简介： Roth 相比传统 IRA/401(k) 有三个独特省税点。

详细内容：

  • 免税退休收入：锁定未来取出的免税确定性，规避退休后税率上升风险。
  • 无 RMD（强制最低取出）：传统账户到 73 岁后必须每年强制取出（不取有罚），Roth IRA 没有此要求——可终身持有、继续增值。
  • 财富传承：配偶继承人享受同样的免税待遇；非配偶继承人通常需在 10 年内清空，但只要账户满 5 年，收益仍可免税取出。
  • Source References:
    • Fidelity — Roth IRA vs. traditional IRA

二、取出「投资收益」的限制 vs 取出「本金」的限制

这是 Roth IRA 最关键、也最容易被误解的部分。核心区别：本金（你的贡献）随时可取；收益（earnings）受规则约束。

4. 取出本金：随时、免税、免罚

热度/类别： 取出限制 / 本金

话题简介： 因为存入的是税后钱，你的「贡献本金」可以随时取出，不交税也不罚。

详细内容：

  • Roth IRA 让你在任何时间取出自己的贡献（contributions），无税、无罚金，哪怕还没到退休。
  • 这是 Roth 相对传统 IRA 的最大灵活性——传统账户 59½ 岁前提前取出通常要交税 + 10% 罚金。
  • 注意顺序规则（ordering rules）：取出时默认先算作「本金」，再算作「收益」。所以即使账户有收益，你取出的钱也优先被视为主本金，从而免税免罚。
  • Source References:
    • Fidelity — Roth IRA withdrawal rules

5. 取出收益：受「5年规则 + 59½岁」双重约束

热度/类别： 取出限制 / 收益（earnings）

话题简介： 投资收益的免税取出，必须同时满足两个条件。

详细内容：

  • 条件一（年龄）：年满 59½ 岁。
  • 条件二（5年规则）：从你第一次向 Roth 账户贡献的那个税年的年初起，至少经过 5 个完整年份。即使已 59½ 岁，若不满 5 年，取出收益仍属「非合格分配（nonqualified distribution）」，可能交税和/或罚金。
  • 两个条件必须同时满足，收益才能完全免税免罚。
  • Source References:
    • Fidelity — Roth IRA 5-year rule

6. 例外：某些情况下可提前免罚（但仍可能交税）

热度/类别： 取出限制 / 例外

话题简介： 5年规则有例外，允许「免罚金」但通常不「免税」。

详细内容：

  • 首次购房：最多 $10,000 可免罚。
  • 永久且完全残疾。
  • 合格的教育费用。
  • 这些例外让你免罚金，但取出的收益部分仍可能需交税（除非同时满足5年规则）。

三、Roth IRA 与 401(k) 的关系

8. 两套独立额度，可叠加使用

热度/类别： 账户关系 / 核心

话题简介： Roth IRA 和 401(k) 是两个独立的退休账户体系，各自的年度上限互不影响，可以同时用满。

详细内容：

  • Roth IRA：个人开设（在券商处），2026 年上限 $7,500（50+ 加 $1,100）。
  • 401(k)：通过雇主开设，从工资预扣，额度远高于 IRA（个人缴存上限另计，公司匹配不计入个人上限）。
  • 关键：IRA 的额度只约束「所有 IRA 类型合计」（传统 IRA + Roth IRA 共享 $7,500），401(k) 的额度是另一套，两者相加才是你一年能存的退休总额。

9. Roth 401(k)：把 Roth 逻辑搬进 401(k)

热度/类别： 账户关系 / Roth 401k

话题简介： 很多公司提供「Roth 401(k)」选项，让你用税后钱存 401(k)，享受类似 Roth IRA 的免税取出。

详细内容：

  • Roth 401(k) 没有收入上限——这是它相对 Roth IRA 的最大优势（Roth IRA 有 MAGI 限制）。
  • 如果你收入太高、被禁止直接存 Roth IRA，但公司又提供 Roth 401(k)，就能绕开收入限制拿到同样的免税增长。
  • 注意：即使你选 Roth 401(k)，公司匹配部分默认仍进入传统（税前）账户，取出时交税——所以你的 401(k) 可能同时存在两种税务处理。

10. Backdoor Roth：高收入者的「后门」

热度/类别： 账户关系 / 策略

话题简介： 收入超过 Roth IRA 上限的人，可用「backdoor Roth」间接实现 Roth 待遇。

详细内容：

  • 步骤：先向传统 IRA 存入不可抵扣（nondeductible）的钱 → 再把它转换（convert）成 Roth IRA。
  • 这样绕开了 MAGI 收入限制，拿到同样的免税增长。
  • 操作较复杂，转换可能立即产生税，建议咨询税务专业人士。

四、怎么确认自己已经拿满了公司能给的 401(k) 匹配？

11. 先搞懂：匹配公式有四种常见类型

热度/类别： 401k 匹配 / 原理

话题简介： 公司匹配不是「固定金额」，而是按你的缴存比例算的。常见四种公式。

详细内容：

  • 一对一（Dollar-for-dollar）：如「匹配你缴存的 100%，最高到工资的 4%」。你存 4%，公司也加 4%。
  • 部分匹配（最常见）：如「匹配你缴存的 50%，最高到工资的 6%」。你存 6%，公司加 3%。
  • 阶梯式（Tiered）：如「前 3% 匹配 100%，接下来 2% 匹配 50%」——存满 5% 才拿满。
  • 拉伸式（Stretch）：如「匹配 25%，最高到工资的 12%」——总额相同，但要存更多才能拿满。

计算公式： 公司匹配 = (你的缴存比例 × 匹配率) × 你的工资

公式类型 示例 $60k 工资下最大匹配/年
一对一 100% 匹配到 4% $2,400
部分匹配 50% 匹配到 6% $1,800
阶梯式 前3% 100% + 下2% 50% $2,400
拉伸式 25% 匹配到 12% $1,800

12. 确认拿满匹配的三步实操（30分钟内可完成）

热度/类别： 401k 匹配 / 实操

话题简介： 三步确认自己是否拿满了所有公司愿意给的匹配。

详细内容：

  1. 查清匹配公式：找 HR、员工手册或 401(k) 计划文件，确认公司具体是哪种公式（匹配率 + 上限百分比）。
  2. 对照自己的缴存比例：登录 payroll/401(k) 设置，看自己当前缴存工资的百分之几。
  3. 调整到位：如果你的缴存比例低于拿满匹配所需的阈值，今天就调高到那个阈值。例如公司「50% 匹配到 6%」，你就至少存 6% 才能拿满。
  • 核心原则：匹配是「有条件的奖金」——你不存，公司就不给；你存得不够，就只拿到部分。不拿满匹配 = 主动放弃一部分工资。
  • Source References:
    • Otto — How Does 401k Employer Matching Work?

13. 两个容易踩的坑：额度归属 + Vesting（归属期）

热度/类别： 401k 匹配 / 风险

话题简介： 确认拿满匹配时，还要留意两个常被忽略的点。

详细内容：

  • 公司匹配不计入你的个人上限：你个人的 401(k) 缴存上限（如 $23,000）只约束「你自己的钱」；公司匹配是额外叠加的，计入更高的合计上限（如 $69,000）。所以你可以存满个人上限、同时拿满公司匹配。
  • Vesting（归属期）：公司匹配的钱不一定马上完全属于你。很多公司有 vesting schedule——离职太早会丢掉部分或全部公司匹配。你自己的贡献永远 100% 属于你，但公司部分按 vesting 规则走。离职前务必查清自己的 vesting 状态，差几个月离职可能损失数千美元。

五、2026 年关键额度速查（供参考）

14. Roth IRA 额度与收入限制（2026）

热度/类别： 额度 / 资格

话题简介： 2026 年 Roth IRA 的年度上限和 MAGI 收入门槛。

详细内容：

  • 年度上限：$7,500；50 岁及以上可额外加 $1,100（即最高 $8,600）。
  • MAGI 收入限制（2026）：
    • 单身：MAGI < $153,000 可全额存；$153,000–$168,000 部分存；≥ $168,000 不能直接存。
    • 夫妻联合申报：MAGI < $242,000 全额；$242,000–$252,000 部分；≥ $252,000 不能直接存。
  • 注意：收入限制只针对「新贡献」——已开的账户可继续持有和投资，只是当年不能再存。
  • 配偶独立额度：夫妻双方各有独立额度；不工作的配偶可用工作配偶的收入来贡献（Spousal IRA）。
