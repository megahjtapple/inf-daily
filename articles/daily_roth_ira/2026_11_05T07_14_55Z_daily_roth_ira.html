一、Roth IRA 是什么，怎么投资

1.1 基本定义

Roth IRA（罗斯个人退休账户）是一种用税后钱（after-tax dollars）存入的个人退休账户。核心特点是：

  • 存入时不减税（不能像传统 IRA / 传统 401(k) 那样在存入当年抵扣所得税）。
  • 账户内投资收益免税增长（tax-free growth）。
  • 符合条件取出时，本金和收益都免税、免罚（qualified distribution）。

来源：IRS「Roth IRAs」页面；Fidelity「What is a Roth IRA and how does it work?」。

1.2 怎么投资（可投什么）

Roth IRA 本身只是一个"容器"，你必须在里面配置具体资产。Fidelity 明确列出的常见可投品种：

类别 说明
股票（Stocks） 风险较高，需自行研究
债券（Bonds） 偏稳健、低波动
共同基金（Mutual Funds） 主动或被动管理型
ETF（交易所交易基金） 最主流、费用低、分散度高，适合大多数人

Fidelity 还建议可以设置定期定额投资（recurring investments），在年度限额内自动扣款，省去手动维护。

来源：Fidelity「What is a Roth IRA and how does it work?」— "How to open a Roth IRA" 一节。

1.3 怎么开户 / 选平台

Fidelity 给出的开户步骤：

  1. 确认资格：能否存入、能存多少，由你的收入（MAGI）决定。
  2. 开账户：券商、银行、在线金融机构都提供 Roth IRA；重点比较费用和投资品种。
  3. 注资：绑定银行账户做首次存入；部分平台支持手机上传支票或工资直存。
  4. 开始投资：在年度限额内配置股票、债券、共同基金、ETF 等。

来源：Fidelity「What is a Roth IRA and how does it work?」— "How to open a Roth IRA" 一节。

1.4 2026 年存入限额与收入资格

  • 年度存入上限：所有 Roth IRA + 传统 IRA 合计适用同一上限（IRS 规定）。
  • 2026 年年度上限：$7,500；年龄 50 岁及以上可额外加存 $1,100（catch-up）。
  • 2026 年收入资格（MAGI）：
    • 单身（single）：MAGI < $153,000 可全额存入；$153,000–$168,000 之间为部分存入（phase-out）；≥ $168,000 不能直接存入。
    • 已婚联合报税（married filing jointly）：MAGI < $242,000 可全额存入；$242,000–$252,000 之间为部分存入；≥ $252,000 不能直接存入。
  • 注意：收入限制只针对"当年新存入"。如果过去已经开过 Roth IRA，账户可以一直保留并继续投资余额，只是当年 MAGI 超标时不能再新增存入。

来源：Fidelity「What is a Roth IRA and how does it work?」— "Roth IRA contribution limits / income limits" 一节；IRS「Roth IRAs」页面（收入限制链接）。

1.5 收入太高存不进去怎么办

Fidelity 给出两条替代路径：

  • Roth 401(k)：如果雇主提供 Roth 401(k) 选项，或你是自雇者（self-employed Roth 401(k)），可以享受同样的免税增长，且没有收入限制。
  • Backdoor Roth IRA（后门罗斯）：先向传统 IRA 存入"不可抵扣"的钱，再转换成 Roth IRA，从而绕过收入上限。

来源：Fidelity「What is a Roth IRA and how does it work?」— "What if I earn too much?" 一节。

二、怎么省税（核心机制）

Roth IRA 的省税逻辑是"先交税、后免税"，与传统 IRA / 401(k) 的"先免税、后交税"正好相反。具体省税点：

2.1 投资收益免税增长

  • 账户内的资本利得、股息、利息在钱留在 Roth IRA 里时都不征税。
  • 对比应税账户（taxable account）：普通账户卖出盈利要交资本利得税，股息/利息即使再投资也要交税。Roth IRA 因为不用先掏税钱，长期复利下来通常能留下更多。

2.2 符合条件取出时本金 + 收益全免

  • 满足"合格分配（qualified distribution）"条件后，本金和收益都免税、免罚。
  • 这是 Roth IRA 最大的省税价值：把未来不确定的税率风险提前锁定为"零"。

2.3 没有 RMD（强制最低取出）

  • 传统 IRA / 401(k) 在达到一定年龄后，政府强制你每年取出最低金额（RMD），不取会被罚税。
  • Roth IRA 没有 RMD（前提是你本人是原始账户持有人，而非继承人）。这意味着你可以一直投资、继续免税增长，把财富传给下一代时仍可享受免税待遇。

2.4 适合谁

Fidelity 的判断标准：如果你当前税率较低、或预期退休后税率会更高，Roth IRA 更划算——相当于用现在的低税率锁定未来的免税收入。

来源：Fidelity「What is a Roth IRA and how does it work?」— "Roth IRA versus traditional IRA" 一节。

三、取出"投资收益"的限制

这是 Roth IRA 规则里最容易踩坑的部分。本金可以随时取，但收益（earnings）受"5 年规则 + 年龄/资格"双重约束。

3.1 合格分配（qualified distribution）的两个条件

要取出收益且免税免罚，必须同时满足：

  1. 账户已成立满 5 年（从你第一次存入 Roth IRA 的那个税年的年初算起）。
  2. 满足以下任一资格：
    • 年满 59½ 岁；
    • 因永久且完全残疾（permanent and total disability）；
    • 用于合格的首次购房（qualified first home purchase，上限 $10,000）；
    • 本人去世（由受益人取出）。

来源：Fidelity「What is a Roth IRA and how does it work?」— "Roth IRA withdrawal rules" 一节。

3.2 5 年规则（5-year rule）

  • 关键：即使你已经年满 59½，如果账户成立不满 5 年就取出收益，仍属于"非合格分配（nonqualified distribution）"，可能同时被征税和罚款。
  • 5 年的起算点：第一次存入 Roth IRA 的税年的年初，而不是你实际打款的那一天。

3.3 例外情况（可免罚，但未必免税）

Fidelity 列出几种可以免罚（penalty-free）取出收益的情形，但注意这些通常只免罚、不免所得税：

  • 首次购房：上限 $10,000；
  • 永久且完全残疾；
  • 合格的教育费用。

来源：Fidelity「What is a Roth IRA and how does it work?」— "Roth IRA withdrawal rules" 一节。

3.4 取出顺序（先本金后收益）

  • Roth IRA 的分配默认先出本金、再出收益。
  • 这意味着即使账户不满 5 年，你取出的部分如果全部是本金，通常仍免税免罚；只有当取出额超过本金、开始触及收益时，才触发 5 年规则 / 资格判断。

说明：此"先本金后收益"的分配顺序为 Roth IRA 的标准税务处理惯例（IRS Pub. 590-B），Fidelity 页面未逐字展开，建议以 IRS Publication 590-B 为准。

四、取出"本金"的限制

4.1 核心规则：本金随时可取

  • Roth IRA 的本金（你存入的税后钱）可以随时取出，免税、免罚——即使还没到退休年龄、账户不满 5 年也一样。
  • 这是 Roth IRA 相比传统 IRA / 401(k) 最大的灵活性优势：传统账户在 59½ 岁前取钱通常要交税 + 10% 罚款，而 Roth IRA 的本金没有这个限制。

来源：Fidelity「What is a Roth IRA and how does it work?」— "Roth IRA withdrawal rules" 一节（"you can withdraw your contributions at any time without taxes or penalties, even before retirement"）。

4.2 实务建议

  • 因为本金可以随时取，很多人把 Roth IRA 当作应急备用金的一部分——但要注意：一旦取出本金，就失去了这部分钱的免税增长机会。
  • 如果账户里既有本金又有收益，且你只想取本金，需确认取出额不超过累计本金总额（否则开始触及收益，触发 5 年规则）。

说明：以上为基于 Fidelity 规则的实务推论，具体以 IRS Publication 590-B 为准。

五、Roth IRA 与 401(k) 的关系

5.1 两者是"互补"而非"二选一"

  • Roth IRA：个人开设，收入有限制（MAGI），年度上限 $7,500（2026）。
  • 401(k)：由雇主提供，通常没有收入限制（但有更高的年度上限），可拿公司 match。
  • 两者可以同时持有、同时存入，互不冲突。Roth IRA 的 $7,500 上限是"所有 IRA 合计"，与 401(k) 的上限分开计算。

5.2 Roth 401(k)：401(k) 里的 Roth 选项

  • 很多雇主提供 Roth 401(k) 选项——用税后钱存入 401(k)，享受和 Roth IRA 一样的免税增长 + 免税取出。
  • 关键区别：Roth 401(k) 没有收入限制，所以高收入者可以用它替代 Roth IRA（Fidelity 明确建议）。
  • 注意：Roth 401(k) 在退休后有 RMD（不像 Roth IRA 那样免 RMD），且取出规则略有不同。

来源：Fidelity「What is a Roth IRA and how does it work?」— "What if I earn too much?" 一节；Fidelity「Roth 401k vs. 401k」（NerdWallet 对比）。

5.3 策略建议（Fidelity 视角）

场景 建议
收入不高、想省税 优先 Roth IRA（免税增长 + 无 RMD）
收入高、Roth IRA 存不进去 用 Roth 401(k) 或 Backdoor Roth IRA
雇主有 match 先拿满 401(k) match（这是免费的钱），再考虑 Roth IRA

六、怎么确认自己已经拿满公司 401(k) match

6.1 先搞清楚公司的 match 规则

不同公司的 match 公式不同，常见两种：

类型 例子
按比例匹配（dollar-for-dollar） 你存工资的 5%，公司也存 5%（1:1）
封顶匹配（capped match） 你存 6%，公司最多匹配 3%（即 50% × 6%）

关键：match 通常有一个"你至少要存多少"的门槛。比如公司规定"你存 5%，我 match 5%"，那你只存 3% 就只能拿到 3% 的 match，白白损失 2%。

来源：Kiplinger「Average 401(k) Match: Do You Work for a Generous Company?」；BetterUp「What 401(k) Employer Match Is and How It Works」。

6.2 怎么查自己公司的 match 规则

  1. 看员工手册 / HR 政策：通常有"401(k) Plan Document"或"Summary Plan Description (SPD)"，里面写明 match 公式。
  2. 问 HR 或 401(k) 服务商（如 Fidelity、Vanguard、Empower）：直接打电话问"我们的 match 公式是什么？我至少要存多少才能拿满？"
  3. 看工资单（pay stub）：对比"你存的金额"和"公司存的金额"，反推 match 比例。

6.3 怎么算自己是否拿满了

步骤：

  1. 确认 match 公式：比如"1:1 up to 5%"（你存 5%，公司最多 match 5%）。
  2. 计算你的存入比例：看你工资单上"401(k) employee contribution"占工资的比例。
  3. 对比：如果你的存入比例 ≥ match 上限，你就拿满了；如果低于，就还有损失。

举例：

  • 公司规则：1:1 up to 5%（你存 5%，公司 match 5%）。
  • 你实际存了 4% → 公司只 match 4% → 你损失了 1% 的免费钱。
  • 你实际存了 6% → 公司 match 5%（封顶）→ 你拿满了，多存的 1% 是你自己的钱。

来源：Kiplinger「Average 401(k) Match」；Investopedia「401(k) Contribution Rates: How Does Your Retirement Savings Rate Compare to Others?」。

6.4 常见误区

  • 误区 1："我存得越多，公司 match 越多" → 错。match 有上限，超过上限的部分公司不再匹配。
  • 误区 2："公司 match 是额外的，不影响我的工资" → 对，但 match 是从你的税前工资里扣的（传统 401(k)），所以会影响当期到手工资。
  • 误区 3："我存 10% 就能拿 10% 的 match" → 错。match 有封顶，通常 3%–6% 之间。

来源：BetterUp「What 401(k) Employer Match Is and How It Works」；NerdWallet「Worried about an over-contributed to a 401(k) in 2026?」。
