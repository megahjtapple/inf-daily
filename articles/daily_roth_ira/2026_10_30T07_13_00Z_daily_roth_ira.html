一、Roth IRA 是什么

Roth IRA（罗斯个人退休账户）是一种税后退休账户，核心特点：

特征 Roth IRA 传统 IRA (Traditional)
存入时 税后钱（不能抵税） 税前钱（可抵税）
账户内增长 免税 免税
取出收益 合格取款免税免罚 取出时按普通收入纳税
强制最低取款 (RMD) 无（原持有人） 73 岁起强制
收入上限 有（MAGI 限制） 无（但抵税资格受限）

一句话：先用钱交税，之后账户里赚的钱和取出的钱都不用再交税。

来源：IRS「Roth IRAs」官方页 + Fidelity Learn「What is a Roth IRA」。

二、怎么用 Roth IRA 投资

1. 开户

  • 选择一家券商 / 投资公司（Fidelity、Vanguard、Charles Schwab、Interactive Brokers 等）。
  • 在线开户，通常需要 SSN、地址、银行账户信息。
  • 账户必须在设立时就指定为 Roth IRA（IRS 规定：账户或年金必须在设立时指定为 Roth）。

2. 注资（Contribute）

  • 最常见方式：从银行账户通过 ACH / 电汇转入现金。
  • 2026 年贡献上限：
    • 基础：$7,500
    • 50 岁及以上：额外 $1,100（catch-up），合计 $8,600
  • ⚠️ 所有 IRA（Roth + 传统）共享同一个上限——不是每个账户各 $7,500，而是所有 IRA 加起来 $7,500。

3. 投资什么

Roth IRA 里可以投券商提供的几乎所有证券：

  • 股票（个股）
  • 债券
  • 共同基金 (Mutual Funds)
  • ETF（交易所交易基金）
  • 部分券商还支持期权、REITs 等

4. 常见投资策略（按风险从低到高）

策略 说明 适合人群
目标日期基金 (Target Date Fund) 一只基金自动随年龄调整股债比例 不想折腾的懒人
指数基金 / ETF 组合 如 VTI（全美股票）+ BND（债券），或「三基金组合」 想低成本、长期持有
个股 + 再平衡 自选股票，定期调整比例 有经验、愿意研究

💡 Roth IRA 的省税优势最适合「高增长资产」：因为收益免税取出，把最可能大涨的部分（如股票）放进 Roth IRA，长期省税效果最大。这是常见的税务优化思路（属于一般性教育信息，非投资建议）。

5. 收入资格（MAGI 限制，2026）

Roth IRA 有收入上限，超过就不能全额或不能贡献：

报税身份 可全额贡献 部分贡献（逐步减少） 完全不能贡献
单身 (Single) MAGI < $153,000 $153,000 – $168,000 ≥ $168,000
夫妻合报 (MFJ) MAGI < $242,000 $242,000 – $252,000 ≥ $252,000

来源：Fidelity Learn「What is a Roth IRA」（2026 数字）。

三、怎么省税（核心机制）

Roth IRA 的省税逻辑是**「先交税，后免税」**，与传统的「先免税，后交税」相反：

  1. 存入时不抵税——你用的是已经交过所得税的钱。
  2. 账户内增长完全免税——利息、股息、资本利得都不交税。
  3. 合格取款（Qualified Distribution）完全免税免罚——本金和收益都不用再交税。

省税的关键点

  • 复利免税滚存：钱在账户里越久，免税的复利效应越大。Roth IRA 是「让收益免税增长时间最长」的工具。
  • 没有 RMD（强制最低取款）：原持有人可以一辈子不取，继续免税增长；传统 IRA / 401(k) 则 73 岁起必须每年取一部分并交税。
  • 灵活性强：本金随时可取（见第五节），相当于一个「免税的应急金 + 退休账户」二合一。

⚠️ 省税的前提是合格取款。如果提前取出「收益」，可能既交税又罚（见第四节）。

四、取「投资收益」的限制

这是 Roth IRA 最容易被误解的地方。本金和收益的取款规则完全不同。

核心：5 年规则 (5-Year Rule)

  • 从你第一次向 Roth IRA 贡献的那个税年的开始起算，必须满 5 年。
  • 注意：5 年是从「第一个贡献的税年初」算，不是从某笔具体存款日算。
  • 即使你已年满 59½，如果账户不满 5 年，取出「收益」仍可能不免税。

合格取款 (Qualified Distribution) 的两个条件（必须同时满足）

  1. 账户已满 5 年；并且
  2. 满足以下任一情形：
    • 年满 59½
    • 永久且完全残疾
    • 首次购房（终身上限 $10,000）
    • 账户持有人去世

提前取出「收益」的后果（非合格取款）

情形 税务后果
不满 59½ 且不满 5 年 收益部分：交所得税 + 10% 提前取款罚金
有例外情形（残疾、首套房 ≤$10,000、合格教育支出等） 可能免 10% 罚金，但仍要交所得税

💡 取款顺序规则：IRS 规定 Roth IRA 取款时先视为取出「本金」，再视为取出「收益」。所以即使你提前取钱，只要没超过你累计贡献的本金总额，通常都不交税不罚（见下一节）。

来源：Fidelity Learn + IRS Publication 590-B（Distributions from IRAs）。

五、取「本金」的限制

这是 Roth IRA 最大的灵活性优势：

  • ✅ 你贡献的本金（Contributions）可以随时取出，免税、免罚，没有任何年龄或年限限制。
  • 原因：本金是你用「已经交过税的钱」存的，IRS 不会让你为同一笔钱交两次税。
  • 因为取款顺序是「先本金后收益」，所以只要你的取款金额 ≤ 累计贡献的本金，就基本安全。

举例

你累计贡献本金 账户总价值 取出 $5,000 结果
$20,000 $30,000 $5,000 全部视为取本金 → 免税免罚
$3,000 $30,000 $5,000 $3,000 是本金（安全）+ $2,000 是收益（可能交税/罚）

⚠️ 注意：「随时可取本金」指的是你实际贡献的那部分。账户里的「收益」仍受 5 年规则和 59½ 规则约束。

来源：Fidelity Learn「What is a Roth IRA」。

六、Roth IRA 与 401(k) 的关系

两者是互补的退休储蓄工具，不是二选一：

维度 Roth IRA 401(k)（含 Roth 401k）
开设方 个人在券商开 通过雇主
收入上限 有（MAGI 限制） 无（Roth 401k 同样无收入限制）
公司匹配 (Match) 无 有（这是 401k 最大优势）
强制最低取款 RMD 无（原持有人） 有（73 岁起）
取款灵活性 本金随时可取 受限（通常 59½ 或离职/贷款）
2026 个人贡献上限 $7,500（50+ 为 $8,600） 更高（约 $24,500，另加 catch-up）

关键关系点

  1. 401(k) 有公司匹配，Roth IRA 没有 → 所以「先拿满 401k 匹配」永远是第一优先级（白送的钱）。
  2. 高收入者：超过 Roth IRA 收入上限的人，可以用 Roth 401(k)（通过雇主）获得类似的免税增长，且没有收入限制。
  3. Backdoor Roth IRA：高收入者可以先向传统 IRA 做「不可抵税贡献」，再转换成 Roth IRA，从而绕过 Roth IRA 的收入上限。
  4. RMD 差异：Roth IRA 原持有人无 RMD，可以一直免税滚存；401(k) 则必须从 73 岁起每年取款并交税。

💡 常见配置顺序（一般性教育信息，非投资建议）： ① 先存到拿满公司 401(k) 匹配 → ② 再填满 Roth IRA（$7,500）→ ③ 还有余钱再回 401(k) 继续存。

来源：Fidelity Learn + IRS「Roth IRAs」+ NerdWallet「Roth 401k vs. 401k」。

七、怎么确认自己已经拿满了公司 401(k) 匹配

这是很多人「白白丢钱」的地方。确认步骤：

1. 先搞清楚公司的匹配规则

  • 常见形式：按比例匹配（如「你存工资的 5%，公司再配 5%」）或 按金额上限匹配（如「最多配 $X」）。
  • 有些公司是 100% 匹配到某个比例，有些是 50% 匹配到更高比例。
  • 📍 在哪里查： 员工手册 / HR 的 401(k) 计划说明 (Plan Document) / 401(k) 服务商网站（Fidelity、Vanguard、Empire、Recordkeeper 等）/ 直接问 HR。

2. 算出「拿满匹配需要存多少」

  • 例：公司规则是「100% 匹配你工资的 5%」→ 你必须至少存 工资的 5% 才能拿满。
  • 例：公司规则是「50% 匹配到 6%」→ 你必须存 6% 才能拿满（公司配 3%）。

3. 核对你的实际存款比例

  • 登录 401(k) 账户或看工资单 (pay stub)，确认你设置的「员工贡献百分比 (employee contribution %)」≥ 拿满匹配所需的百分比。
  • ⚠️ 常见错误：很多人只存了 3%，但公司匹配到 5% → 白白丢了 2% 的「免费钱」。

4. 核对账户里是否真的进了匹配款

  • 在 401(k) 账户的交易明细里，通常能分开看到：
    • Employee Contribution（你自己存的）
    • Employer Match / Employer Contribution（公司配的）
  • 如果你存了足够比例，但「Employer Match」那一栏是 0 → 说明有问题，立刻找 HR。

5. 注意「归属期 (Vesting)」

  • 公司匹配的钱可能不是一次性完全属于你的，而是按年限逐步「归属 (vest)」——比如「3 年 cliff vesting」或「每年 20% 渐进」。
  • ⚠️ 风险：如果没归属就离职，未归属的公司匹配部分会被公司收回。这是真实案例中有人损失数万美元的原因（见来源）。

✅ 一句话自检清单

  1. [ ] 我知道公司的匹配规则（比例 + 上限）
  2. [ ] 我的员工贡献 % ≥ 拿满匹配所需的 %
  3. [ ] 账户里确实有「Employer Match」进账
  4. [ ] 我了解归属期 (vesting)，知道离职会损失多少
