一、综合活动发现平台（找活动 / 售票）

1. Meetup

  • 话题简介： 全球最知名的兴趣小组活动平台，按城市 + 兴趣主题组织线下聚会，是"约出去玩"的标杆应用。
  • 详细内容： Meetup 允许用户创建或加入基于共同兴趣的小组（跑步、摄影、编程、语言交换、桌游等），每个小组定期举办线下活动并显示时间、地点、费用与人数。可按城市、主题、日期筛选，支持 RSVP 报名、查看组织者与过往活动评价。适合想系统性结识同好、参加固定社群的人。免费加入，部分活动收费。
  • Source Reference： https://www.meetup.com/

2. Facebook Events & Groups

  • 话题简介： 依托 Facebook 庞大用户群的活动与群组功能，是本地活动发现的最大流量入口之一。
  • 详细内容： Facebook 的"活动（Events）"可发现本地公开活动并一键报名；"群组（Groups）"则聚集同好（如某城市的徒步群、美食群）。优势是用户基数大、本地化强、免费；劣势是信息噪音多、需登录 Facebook 账号。适合已有 Facebook 社交圈、想快速找到身边活动的人。
  • Source Reference： https://www.facebook.com/events/

3. Eventbrite

  • 话题简介： 专业的活动发现与售票平台，覆盖从免费社区活动到大型演出、工作坊的广泛品类。
  • 详细内容： Eventbrite 聚合了数百万场活动，可按城市、类别（音乐、科技、美食、运动、教育等）、日期与价格筛选，支持在线购票与电子票入场。既有免费社区活动也有付费专业活动，适合想"发现 + 购票"一站式完成的用户。
  • Source Reference： https://www.eventbrite.com/

4. Time Out（本地活动指南）

  • 话题简介： 全球多城市的"最佳活动 / 体验"指南平台，提供编辑精选的本地玩乐推荐。
  • 详细内容： Time Out 为伦敦、纽约、洛杉矶等数百个城市提供"Best Things To Do"榜单与每日活动日历，内容经编辑筛选，质量较高。适合不想自己翻找、希望直接获得"今天去哪玩"建议的用户。部分城市有 App。
  • Source Reference： https://www.timeout.com/

5. SeatGeek

  • 话题简介： 演出 / 体育赛事 / 现场活动的票务与发现平台，覆盖演唱会、体育比赛、喜剧等。
  • 详细内容： SeatGeek 聚合了全美及多国的演出与赛事票源，提供价格比较、座位图与"Deal Score"性价比评分。适合想约人看演唱会、球赛等现场活动的人。按票收费，无订阅费。
  • Source Reference： https://seatgeek.com/

6. StubHub

  • 话题简介： 大型二手票务市场，覆盖演唱会、体育、戏剧、喜剧等各类现场活动。
  • 详细内容： StubHub 是北美最大的 C2C 票务平台之一，票源丰富、价格浮动大，适合找热门演出 / 赛事的票。买家保障（Buyer Guarantee）提供退款保护。按票收费。
  • Source Reference： https://www.stubhub.com/

7. Vivid Seats

  • 话题简介： 票务发现与交易平台，强调"实时价格"与"即时入场"体验。
  • 详细内容： Vivid Seats 覆盖演唱会、体育、戏剧等，提供实时价格更新与电子票即时交付，适合临时决定去看演出的人。按票收费。
  • Source Reference： https://www.vividseats.com/

二、交友 / 结识新朋友（非恋爱导向）

8. Bumble BFF

  • 话题简介： Bumble 的"交朋友"模式，专为非恋爱的友谊匹配设计，是"friendship app"热潮的代表。
  • 详细内容： 在 Bumble 中切换到 BFF 模式后，可基于位置与兴趣匹配附近想交朋友的人，聊天后约线下见面。界面友好、有性别/身份筛选，适合搬到新城市、想快速建立本地朋友圈的人。免费基础功能，付费可解锁更多匹配。
  • Source Reference： https://bumble.com/bff

9. Patook

  • 话题简介： 专为"找朋友"设计的交友 App，明确区分于约会 App，强调共同兴趣匹配。
  • 详细内容： Patook 基于兴趣标签与位置匹配附近想交朋友的人，界面简洁、无恋爱导向，适合想纯粹交朋友的人。免费基础功能，付费解锁高级筛选。
  • Source Reference： https://patook.com/

10. Friender

  • 话题简介： 基于"共同活动"的交友 App，通过报名同一活动自然结识新朋友。
  • 详细内容： Friender 让用户浏览附近的活动（运动、课程、聚会等），报名后与同场的人匹配聊天，适合想通过活动认识人的人。免费基础功能。
  • Source Reference： https://friender.com/

11. Slowly

  • 话题简介： "慢社交"笔友 App，以信件形式与全球用户建立深度友谊，再约线下见面。
  • 详细内容： Slowly 模拟真实信件投递时间（按距离计算），鼓励深度交流而非快速滑动匹配，适合想建立有质量的跨地域友谊的人。免费基础功能，付费解锁更多信件额度。
  • Source Reference： https://slowly.com/

12. Yubo

  • 话题简介： 面向年轻人的社交 App，通过直播、群聊与兴趣标签结识新朋友。
  • 详细内容： Yubo 提供实时视频群聊、兴趣社区与活动发现，适合 18–30 岁想快速认识同好的人。免费基础功能，付费解锁高级功能。
  • Source Reference： https://yubo.com/

13. Tandem

  • 话题简介： 语言交换 App，通过练习外语结识国际朋友，常发展为线下见面。
  • 详细内容： Tandem 匹配母语不同的语伴，支持文字、语音与视频通话，适合想练口语并认识外国朋友的人。免费基础功能，付费解锁高级功能。
  • Source Reference： https://tandem.net/

14. HelloTalk

  • 话题简介： 语言交换社区 App，覆盖 150+ 种语言，用户基数大。
  • 详细内容： HelloTalk 提供语伴匹配、纠错、语音消息与社区动态，适合想通过语言学习结识国际朋友的人。免费基础功能，付费解锁高级功能。
  • Source Reference： https://www.hellotalk.com/
