薪资资讯网站推荐清单（Glassdoor / Levels.fyi 同类）

生成时间：2026-09-20 · 共 30 个选项，按**推荐度（热度 + 数据质量 + 实用性）**从高到低排序。 每个条目包含：话题简介、详细内容、Source Reference（来源 URL）。 说明：排名综合了各网站在 2026 年多份对比评测中的出现频率、数据可信度、覆盖范围与免费可用性。

一、综合薪资 + 公司点评平台（最热门）

1. Glassdoor

  • 话题简介：全球最知名的薪资与公司点评平台，员工匿名提交薪资、面试经验与公司评价。
  • 详细内容：提供按职位、公司、地点的薪资估算工具与"是否被公平支付"计算器；数据量大但 2024 年雇主回复政策使部分点评偏正面，适合做初步参考而非精确谈判依据。
  • Source Reference：https://www.glassdoor.com/Salaries/index.htm

2. Levels.fyi

  • 话题简介：科技行业（尤其股权占比高的公司）总薪酬数据的标杆。
  • 详细内容：把总薪酬拆分为基本工资、股票、奖金，并按职级（如 L4/L5 软件工程师）展示分位数与职业成长曲线；对股票类薪酬最准确，是技术岗谈薪首选。
  • Source Reference：https://www.levels.fyi

3. Indeed

  • 话题简介：美国最大招聘平台之一，附带海量员工/雇主上报的薪资数据。
  • 详细内容：号称有超过 6 亿条薪资记录，可按技能、经验、公司查看平均薪资；数据量大、覆盖面广，适合快速了解某职位的市场中位数。
  • Source Reference：https://www.indeed.com/career/salaries

4. Comparably

  • 话题简介：以"公平薪酬"与职场文化洞察见长的薪资对比平台。
  • 详细内容：提供薪资数据 + 职场文化/补偿洞察，帮助判断自己在就业市场中的位置；常被列为 Glassdoor 的诚实替代方案之一。
  • Source Reference：https://www.comparably.com/salaries/home

5. Blind

  • 话题简介：面向科技从业者的匿名社区，含真实薪资讨论。
  • 详细内容：员工匿名分享薪酬、面试与公司内幕；数据"接地气"但样本偏科技圈，适合了解特定公司/职级的实际 offer 水平。
  • Source Reference：https://www.blind.com

二、专业薪资数据库（数据深度强）

6. Payscale

  • 话题简介：最大的薪资数据网站之一，以"补偿情景构建器"著称。
  • 详细内容：拥有海量薪资档案与调查参与者，可按职位、公司、地点、经验定制查询；提供免费的薪资报告与谈判建议，适合做详细补偿建模。
  • Source Reference：https://www.payscale.com/salary

7. Salary.com

  • 话题简介：以"独特薪资数据筛选器"和全球基准数据见长。
  • 详细内容：提供按职位、类别、行业的准确薪资数据与实时招聘洞察，支持全球薪酬基准；适合需要可辩护（defensible）薪酬决策的企业与求职者。
  • Source Reference：https://www.salary.com/research/salary

8. ZipRecruiter

  • 话题简介：以"通俗易懂的薪资研究报告"见长的美国薪资平台。
  • 详细内容：拥有数百万条薪资数据点，可按角色、地点、经验查看薪资；报告直观易读，适合快速了解某职位的薪资区间。
  • Source Reference：https://www.ziprecruiter.com/Salaries

9. SalaryExpert

  • 话题简介：全球薪酬数据平台，擅长为远程/分布式团队做基于地点的薪资带。
  • 详细内容：提供跨国薪酬数据，支持按国家、职位查询；适合需要为不同地区设定公平薪酬带的团队与求职者。
  • Source Reference：https://www.salaryexpert.com/solutions/global-salary-data

10. PayLab

  • 话题简介：全球薪资基准工具，覆盖多国多职位。
  • 详细内容：选择国家即可查看按职位的薪资、工资与福利；数据定期更新，适合跨国薪酬对比与远程岗位定价。
  • Source Reference：https://www.paylab.com

三、企业级 / 专业薪酬基准（HR 与咨询机构）

11. Radford McLagan（Aon）

  • 话题简介：Aon 旗下的全球薪酬数据库，企业级基准标杆。
  • 详细内容：用于薪酬基准、薪酬实践评估与人才分析；数据权威但通常面向企业/HR，个人求职者较少直接使用。
  • Source Reference：https://www.aon.com/en/capabilities/human-capital-analytics/radford-mclagan-compensation-database

12. Mercer（美世）

  • 话题简介：全球薪酬调查与"Global Pay Summary"报告提供商。
  • 详细内容：覆盖 140+ 市场，提供薪资涨幅、经济数据与全球薪酬规划报告；适合企业做年度薪酬预算与跨国对标。
  • Source Reference：https://www.imercer.com/global-salary-surveys-us

13. BLS（美国劳工统计局）

  • 话题简介：官方权威薪资数据来源，被多份评测列为"最佳整体薪资对比工具"。
  • 详细内容：提供 OES（职业就业统计）等官方数据，按职业、地区给出中位数与分位数；数据最权威、无商业偏差，适合做基准锚点。
  • Source Reference：https://www.bls.gov/oes/
