1. 🏆 Levels.fyi

推荐度：🔥🔥🔥🔥🔥 | 类别：科技薪酬数据（员工自报+部分验证）

话题简介： Levels.fyi 是目前科技行业最知名的薪酬透明平台，专注于大型科技公司（Google、Meta、Amazon、Apple 等）的总薪酬数据。它提供按公司、职级、地区细分的薪资范围热力图和图表，是科技从业者求职谈判和薪酬调研的首选工具。

详细内容：

  • 数据来源： 员工自报，部分通过工作邮箱和 offer letter 验证；未验证数据权重较低
  • 覆盖范围： 总薪酬（base salary + equity + bonus），按职级（L3-L8+）细分
  • 特色功能： 薪资热力图、公司间对比、实时数据更新、职级体系说明
  • 优势： 数据实时性强，科技行业覆盖最深，职级上下文详细
  • 局限： 偏向大型科技公司和风投支持的初创企业；非技术岗位和非美国地区数据较少
  • 适用场景： 科技行业求职谈判、薪酬对标、了解大厂薪酬结构

Source References:

  • Levels.fyi 官网
  • Ravio: 16 best free salary data sources in 2026

2. 🏆 Glassdoor

推荐度：🔥🔥🔥🔥🔥 | 类别：综合薪资+公司评价平台

话题简介： Glassdoor 是全球最大的雇主评价和求职市场之一，拥有海量员工自报薪资数据。它采用"give-to-get"模式——用户提交自己的薪资信息后才能查看他人的薪资范围。除了薪资数据，还提供公司评价、面试经验等综合职场信息。

详细内容：

  • 数据来源： 员工和前员工匿名提交（职位、薪资、地点等）
  • 覆盖范围： base salary + 偶尔的 bonus/额外补偿；equity 和 benefits 报告不一致
  • 特色功能： 公司评价、面试问题库、CEO 薪酬数据、行业薪资指数
  • 优势： 数据量大，覆盖岗位广，综合职场信息丰富
  • 局限： 数据未经验证；平均薪资基于历史所有提交（含过时数据）；无法按公司类型/规模筛选
  • 适用场景： 了解某公司整体薪酬水平、求职前调研、行业薪资趋势

Source References:

  • Glassdoor 官网
  • Glassdoor Salary Index (UK)
  • Ravio: Glassdoor salary benchmarking analysis

3. 🏆 Payscale

推荐度：🔥🔥🔥🔥 | 类别：个人薪资报告+行业薪酬数据

话题简介： Payscale 是一家薪酬软件和数据中心公司，拥有超过 6000 万员工自报薪资档案。其免费工具面向个人用户——完成在线薪资调查后获得个人市场价值报告，同时提供按职位、地点、经验细分的薪资页面。

详细内容：

  • 数据来源： 众包薪资调查（60M+ 员工档案）
  • 覆盖范围： 按职位/地点/经验的薪资范围；个人薪资报告
  • 特色功能： 个人市场价值评估、技能对薪资的影响分析、行业对比
  • 优势： 数据集庞大，岗位覆盖广，对个人用户友好
  • 局限： 员工自报数据无雇主验证；偏向美国市场；国际覆盖较薄
  • 适用场景： 个人薪资水平检查、了解某职位市场价值、求职前准备

Source References:

  • Payscale 官网

4. 🏆 Salary.com (CompAnalyst)

推荐度：🔥🔥🔥🔥 | 类别：结构化薪资范围+百分位数据

话题简介： Salary.com 是 CompAnalyst 旗下的消费者级薪资工具，提供结构化的薪资范围和百分位数据（中位数、25th、75th）。其付费产品 CompAnalyst 面向企业提供雇主级薪酬基准，有 14 天免费试用。

详细内容：

  • 数据来源： 雇主报告、薪资调查、第三方数据源
  • 覆盖范围： base salary 范围 + 百分位；equity/benefits 通常在付费产品中
  • 特色功能： 清晰的百分位框架、结构化岗位定义、薪资计算器
  • 优势： 比众包平台更结构化的岗位定义；清晰的百分位呈现
  • 局限： 免费数据较粗略，缺乏定制化；对快速变化的新兴岗位覆盖有限
  • 适用场景： 了解某职位的结构化薪资范围、HR 初步市场了解

Source References:

  • Salary.com 官网
  • CompAnalyst by Salary.com
  • Ravio: 16 best free salary data sources in 2026

5. 🏆 Indeed Salaries

推荐度：🔥🔥🔥🔥 | 类别：综合薪资估算平台

话题简介： Indeed 是全球最大的求职搜索引擎之一，其薪资数据来自三个渠道：披露薪资的岗位广告、员工自报提交、以及平台统计估算。用户可免费搜索按职位和地点细分的薪资范围。

详细内容：

  • 数据来源： 岗位广告 + 员工自报 + 统计估算（三源混合）
  • 覆盖范围： 估算 base salary 范围；时薪或年薪；高层级岗位/地点细分
  • 特色功能： 免费账户即可访问、广泛的岗位和地理覆盖
  • 优势： 易于访问，覆盖面广，适合了解市场水平
  • 局限： 不同公司计算薪酬方式不同导致数据方差大；数据来源权重不透明
  • 适用场景： 快速了解某职位/地点的市场薪资水平

Source References:

  • Indeed Salaries
  • Ravio: 16 best free salary data sources in 2026

6. 🏆 Blind

推荐度：🔥🔥🔥🔥 | 类别：匿名职场社区+薪资数据

话题简介： Blind 是一个匿名职场社交平台，用户以公司邮箱验证身份后可以在社区中匿名讨论薪资、面试经验、公司文化等。其薪资数据来自经过邮箱验证的员工自报，在科技行业有较高可信度。

详细内容：

  • 数据来源： 经工作邮箱验证的员工自报
  • 覆盖范围： base salary + bonus + equity（总薪酬）；按公司和职级细分
  • 特色功能： 匿名讨论、面试经验分享、公司文化评价、实时薪资讨论
  • 优势： 身份验证增加可信度；社区氛围活跃，信息实时性强
  • 局限： 偏向科技行业；数据量不如 Glassdoor/Levels.fyi 大；非结构化数据为主
  • 适用场景： 了解某公司内部薪酬文化、面试准备、同行交流

  • 特色功能： 实时反映招聘活动、广泛的美国岗位覆盖
  • 优势： 数据来自实时岗位广告，反映当前市场
  • 局限： 偏向美国市场；部分数字为平台估算而非雇主实际报价；无 equity/benefits 数据
  • 适用场景： 了解美国某职位/城市的招聘薪资水平

详细内容：

9. 🏆 Ravio

推荐度：🔥🔥🔥🔥 | 类别：科技薪酬基准平台（免费层）

话题简介： Ravio 是专业的薪酬数据提供商，通过 HRIS 集成获取实时总薪酬数据。它提供 3 个免费基准（无需信用卡），数据来自 1800+ 公司的 HR 系统，经数据科学家团队验证。特别适合科技公司的全球薪酬对标。

详细内容：

  • 数据来源： HRIS 集成（直接雇主数据），非自报
  • 覆盖范围： base salary + variable pay + equity + benefits（总薪酬）
  • 特色功能： 实时全球数据、高级筛选（地点/行业/规模/融资阶段）、欧洲覆盖强
  • 优势： 数据经验证，实时性强，总薪酬覆盖完整
  • 局限： 免费层仅 3 个基准；对非科技角色相关性较低
  • 适用场景： 科技公司薪酬对标、全球雇佣定价、验证市场水平

15. 🏆 OpenComp

推荐度：🔥🔥🔥 | 类别：科技薪酬数据平台（免费层）
