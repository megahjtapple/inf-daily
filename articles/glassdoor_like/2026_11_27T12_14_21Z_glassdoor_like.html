详细列表

1. Levels.fyi

话题简介： 科技行业薪酬透明度的标杆网站，以匿名员工自报数据为核心，覆盖全球主要科技公司。

详细内容：

  • 数据来源： 员工自愿匿名提交，包含基本工资、股票（RSU/Option）、奖金、签字费等完整总包（Total Compensation）
  • 覆盖范围： 全球 10,000+ 家公司，以美国科技巨头（FAANG、Meta、Google、Amazon、Apple、Microsoft）为核心
  • 特色功能： 按职级（L3-L7+）细分薪酬、面试难度评分、公司文化评价、股票价值实时计算
  • 免费程度： 基础数据免费查看，高级筛选和详细报告需付费（约 $29.99/月）
  • 数据质量： 被广泛认为是科技行业最准确的薪酬参考，数据更新频率高
  • 适用人群： 软件工程师、产品经理、数据科学家等科技岗位求职者

Source Reference: https://www.levels.fyi

2. Glassdoor

话题简介： 全球最大的综合薪资与雇主评价平台，覆盖几乎所有行业和地区。

详细内容：

  • 数据来源： 员工自报薪资 + 公司公开数据 + 第三方调查
  • 覆盖范围： 全球 190+ 个国家/地区，数百万家公司
  • 特色功能： 薪资估算工具（Salary Estimator）、公司评价、面试经验、CEO 支持率、工作生活平衡评分
  • 免费程度： 基础薪资数据免费，完整报告需注册
  • 数据质量： 数据量大但准确性参差不齐，部分数据可能过时
  • 适用人群： 所有行业求职者，尤其是非科技岗位

Source Reference: https://www.glassdoor.com/Salaries/index.htm

3. Indeed

话题简介： 全球最大招聘平台之一，薪资数据基于海量职位发布和员工自报。

详细内容：

  • 数据来源： 职位发布中的薪资范围 + 员工自报 + 市场趋势分析
  • 覆盖范围： 全球 190+ 个国家/地区
  • 特色功能： 实时薪资趋势、按地点/经验/行业细分、薪资计算器、公司评价
  • 免费程度： 完全免费
  • 数据质量： 数据量大，但部分职位薪资为"面议"或范围过宽
  • 适用人群： 所有行业求职者，尤其适合快速了解市场水平

Source Reference: https://www.indeed.com/salaries

4. Blind

话题简介： 科技和金融行业匿名社区，以真实员工自报薪酬数据著称。

详细内容：

  • 数据来源： 经过验证的员工（需工作邮箱验证）匿名提交
  • 覆盖范围： 以美国为主，覆盖科技、金融、咨询行业
  • 特色功能： 按公司/职级/地点查看薪酬、面试经验、公司文化讨论、股票价格追踪
  • 免费程度： 基础数据免费，高级功能需付费
  • 数据质量： 因邮箱验证机制，数据可信度较高
  • 适用人群： 科技和金融行业从业者

Source Reference: https://www.teamblind.com
