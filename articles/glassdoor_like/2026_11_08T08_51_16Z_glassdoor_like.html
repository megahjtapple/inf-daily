1. Glassdoor

热度： 🔥🔥🔥🔥🔥 类别： 综合薪资 + 公司评价

话题简介： Glassdoor 是全球最大的薪资和公司评价平台之一，提供超过 3 亿条薪资数据，覆盖 200+ 个国家和地区。用户可查看具体职位、公司、地点的薪资范围，并阅读匿名员工评价。

详细内容：

  • 提供按职位、公司、地点筛选的薪资数据
  • 包含基本工资、奖金、股票期权等完整薪酬信息
  • 公司评价系统（评分、CEO 支持率、工作生活平衡）
  • 面试经验分享（面试流程、难度、时长）
  • 支持 200+ 国家/地区，多语言界面
  • 免费使用，部分高级功能需付费
  • 数据来源于员工自愿提交，样本量大但可能存在偏差

2. Levels.fyi

热度： 🔥🔥🔥🔥🔥 类别： 科技行业薪酬（专注）

话题简介： Levels.fyi 是科技行业薪资数据的标杆平台，专注于软件工程师、产品经理、数据科学家等技术职位的薪酬信息。以匿名提交和详细拆解（基本工资、股票、奖金）著称，被广泛认为是科技行业薪资谈判的参考标准。

详细内容：

  • 专注科技行业：SWE、PM、DS、Design、Engineering Manager 等
  • 详细薪酬拆解：Base Salary + Stock (RSU/ISO) + Bonus + Sign-on
  • 按公司、级别（L4-L10+）、地点筛选
  • 匿名提交，数据可信度高
  • 提供薪资趋势图（同比变化）
  • 面试经验数据库（LeetCode 题目、系统设计题）
  • 免费使用，部分高级功能需付费
  • 数据主要来自美国科技行业，国际覆盖有限

Source References:

  • Levels.fyi
  • Levels.fyi - SWE Salaries
  • Levels.fyi - PM Salaries

3. Indeed

热度： 🔥🔥🔥🔥🔥 类别： 综合招聘 + 薪资数据

话题简介： Indeed 是全球最大的招聘平台之一，提供超过 3500 万条职位信息。其薪资工具允许用户查看特定职位、公司、地点的薪资范围，并基于大量职位数据提供薪资估算。

详细内容：

  • 全球最大招聘平台，职位数量最多
  • 薪资数据来源于职位发布和员工提交
  • 支持按职位、公司、地点筛选
  • 提供薪资范围（最低-最高）而非精确值
  • 覆盖 60+ 国家/地区
  • 免费使用
  • 数据量大但精度不如 Levels.fyi 或 PayScale

Source References:

  • Indeed Salaries
  • Indeed UK
  • Indeed Canada
  • Indeed Australia
  • Indeed India

4. PayScale

热度： 🔥🔥🔥🔥 类别： 薪资数据 + 报告

话题简介： PayScale（现更名为 CareerBench）是专业的薪资基准数据提供商，为个人和企业提供详细的薪资报告。其数据基于数百万条员工自报数据，按职位、地点、经验、教育背景等多维度分析。

详细内容：

  • 专业薪资基准数据，精度较高
  • 多维度筛选：职位、地点、经验、教育、行业
  • 提供个人薪资报告（付费）
  • 企业版用于薪酬策略制定
  • 数据覆盖 100+ 国家/地区
  • 免费查看基础数据，详细报告需付费
  • 被 HR 和招聘专业人士广泛使用

Source References:

  • PayScale Job Salaries

  • 免费使用，需验证邮箱
