3. 💳 ChatGPT Wallet 上线，AI Agent 可替用户付款购物

热度：🔥🔥🔥🔥🔥 | 类别：新产品

话题简介： OpenAI 本周推出 ChatGPT Wallet，允许其 "dots" AI Agent 代表用户完成挑选、下单与支付。这是 OpenAI 从"对话助手"迈向"可执行交易的 Agent 平台"的关键一步，被 CNBC 等多家媒体作为头条报道。

详细内容：

  • 核心能力：AI Agent 可在授权范围内替用户挑选商品、下单并完成付款，覆盖电商等消费场景。
  • 安全设计：OpenAI 官方称该钱包为"secure feature"，在用户批准（user approval）下完成购买，并沿用现有卡片保护机制。
  • 战略意义：把 ChatGPT 从"信息/内容工具"扩展为"交易闭环"，直接切入支付与电商入口，与 Stripe、Apple Pay 等形成潜在竞争。
  • 风险与争议：Agent 自主付款涉及资金安全、误购责任、退款与合规（KYC/AML）等问题，预计将引发监管与消费者保护讨论。
