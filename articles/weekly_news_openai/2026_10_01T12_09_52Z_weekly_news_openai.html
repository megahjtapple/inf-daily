1. OpenAI 发布 GPT-5.2 系列模型

类别： 新产品 热度： ★★★★★

话题简介： OpenAI 于 9 月底正式发布 GPT-5.2 系列模型，这是继 GPT-5 之后最重要的模型迭代。新模型在推理能力、多模态理解和长上下文处理方面均有显著提升，被视为当前最强大的通用 AI 模型。

详细内容： GPT-5.2 系列包含三个版本：GPT-5.2（标准版）、GPT-5.2 Pro（专业版）和 GPT-5.2 Mini（轻量版）。主要升级包括：

  • 推理能力： 在数学、逻辑和科学推理基准测试中，GPT-5.2 Pro 得分较 GPT-5 提升约 18%
  • 多模态理解： 支持更高分辨率图像输入（最高 4K），视频理解时长从 30 秒扩展至 5 分钟
  • 长上下文： 上下文窗口扩展至 200 万 token，可处理整本书籍或大型代码库
  • 工具调用： 新增并行工具调用能力，可同时执行多个 API 请求
  • 价格调整： 标准版输入价格降至 $1.50/百万 token，输出价格 $6.00/百万 token

该发布在 AI 社区引发广泛讨论，多家媒体将其与 Anthropic Claude 4 和 Google Gemini 2.5 进行对比评测。

9. OpenAI 发布开发者平台 API v4 重大更新

类别： 新产品 热度： ★★★☆☆

话题简介： OpenAI 对其开发者平台进行了自 ChatGPT 发布以来最大规模的 API 重构，推出 API v4。新架构在性能、灵活性和成本效率方面均有显著提升。

详细内容： API v4 的主要变更：

  • 统一接口： 将原有的 chat completions、embeddings、images、audio 等分散 API 统一为单一 openai.generate() 入口
  • 流式增强： 支持 token 级流式输出、中间推理步骤展示和工具调用实时反馈
  • 批量处理： 新增 Batch API v2，支持异步大批量任务（最高 100 万请求/批）
  • 模型路由： 开发者可配置自动模型路由策略（按成本/质量/延迟优化）
  • 本地缓存： 支持客户端侧 prompt caching，减少重复计算
  • SDK 更新： Python、JavaScript、Go、Rust SDK 全面重写，性能提升 3-5x
  • 向后兼容： v3 API 将维持至 2027 年 6 月

此次更新获得了开发者社区的积极反馈，Hacker News 上相关讨论超过 500 条评论。
