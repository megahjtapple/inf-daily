热度：🔥🔥🔥🔥🔥 | 类别：新产品

话题简介： 9月22日，OpenAI 正式发布 GPT-6 家族的另外两款模型——Sol 和 Luna，将 GPT-6 Astra 的能力下放到更低价位。Sol 定位日常开发工作（$2/$10 每百万 token），Luna 定位高速低成本场景（$0.10/$0.50 每百万 token）。API 价格较 GPT-5.6 直降 50%，直接对标并低于 Claude 定价。

  • 两款模型同时登陆 ChatGPT Work、Codex 和 API
  • 事实准确性和编码性能较前代提升，价格减半
  • 9月22日当天即被 GitHub Copilot、Microsoft Foundry 等第三方平台集成
  • Hacker News 社区反馈积极，认为性价比显著优于 Claude 同级模型
