1. GPT-5.2 正式发布

摘要： OpenAI 于 9 月 24 日正式发布 GPT-5.2，主打更强的多模态推理、代码生成与长上下文能力，被视为对 Anthropic Claude Opus 4.6 和 Google Gemini 3 Pro 的直接回应。

详细内容：

  • 新模型在 MMLU-Pro、HumanEval、SWE-bench 等基准上均刷新纪录。
  • 支持原生图像 + 文本 + 代码混合输入，上下文窗口扩展至 128K tokens。
  • 推理成本较 GPT-5.1 下降约 30%，API 定价同步下调。
  • 首批开放给 ChatGPT Plus/Pro 用户及 API 企业客户。
  • 社区反馈：代码生成质量显著提升，但在创意写作方面与 GPT-5.1 差异不大。

来源：

  • https://techcrunch.com/2026/09/24/openai-gpt-5-2-release

  • 分析师认为此轮融资将加速 OpenAI 与 Anthropic（估值约 3500 亿）的差距拉大。

3. Sora 视频生成 2.0 上线

摘要： OpenAI 于 9 月 25 日推出 Sora 2.0，支持最长 60 秒的连贯视频生成、多镜头叙事、实时风格迁移，并开放 API 访问。

详细内容：

  • 相比 Sora 1.x，2.0 在物理一致性（重力、碰撞、流体）上有显著改善。
  • 新增"导演模式"：用户可用自然语言描述分镜脚本，Sora 自动生成多镜头序列。
  • 支持 4K 输出，API 定价为 $0.10/秒（720p）。
  • 与 YouTube、TikTok 达成内容创作合作试点。
  • 争议：部分创作者担忧 AI 生成视频对影视行业的冲击，好莱坞工会发表声明呼吁加强版权保护。

5. o3-pro 推理模型发布

摘要： 9 月 26 日，OpenAI 推出 o3-pro——面向复杂推理场景（数学证明、科学建模、多步规划）的旗舰推理模型。

详细内容：

  • 在 ARC-AGI-2、GPQA Diamond、MATH 竞赛级题目上刷新 SOTA。
  • 引入"思维链可视化"功能，用户可查看模型的推理步骤。
  • 延迟较高（平均 8-15 秒/响应），定位为"深度思考"场景而非实时对话。
  • API 定价：$12/M input tokens, $60/M output tokens（约为 GPT-5.2 的 4 倍）。
  • 首批开放给 ChatGPT Pro 用户及研究合作机构。

详细内容：

  • 核心能力：自然语言定义 Agent 角色 → 自动规划任务分解 → 调用外部 API/数据库 → 生成报告。

  • 定价：按 Agent 运行时长计费，$2/hour（含基础工具调用）。
  • 与 Salesforce、SAP 达成集成合作。
