🏔️ 详细清单（按推荐度排序）

1. Snoqualmie Pass 滑雪 / 雪鞋徒步

  • 话题简介： 离西雅图最近的"雪山门户"，1 小时车程就能从雨城切换到粉雪世界，是华州人冬天最常说的周末去处。
  • 详细内容： Snoqualmie Pass 一带有 The Summit at Snoqualmie（初级/中级）、Snoqualmie Nordic（越野滑雪，可租装备）以及多条雪鞋徒步路线——Lower Gold Creek Basin（约 6.4 km，适合新手）、Kendall Lake Peaks（约 14.5 km，进阶）。1 月是雪况稳定的季节，白天日照短（日落约 16:45），建议上午出发。
  • 门票提示： ⚠️ 滑雪/雪鞋需购票；周末和节假日建议提前 1–2 周在官网（summitsnoqualmie.com / summitsatsnoqualmie.com）买，当天现场票常售罄或涨价。越野滑雪可现场租装备。
  • Source Reference： https://www.10adventures.com/seattle-winter-outdoors ；https://www.summitatsnoqualmie.com/

2. Stevens Pass 滑雪 + 夜滑

  • 话题简介： 35+ 条雪道、有夜滑和地形公园，是"想认真玩一天雪"的首选，1.5 小时车程。
  • 详细内容： Stevens Pass 适合各水平玩家，夜滑（night skiing）是它的招牌——白天上班、晚上来滑，是华州上班族冬天的经典安排。地形公园对进阶玩家友好。
  • 门票提示： ⚠️ 需购票；周末和夜滑场次建议提前 1–2 周在官网（stevenspass.com）买，夜滑名额少、容易满。
  • Source Reference： https://www.10adventures.com/seattle-winter-outdoors

3. The Summit at Snoqualmie（离市区最近）

  • 话题简介： 30–45 分钟就到，是"临时起意想去玩雪"最现实的选择，蓝道为主、适合入门。
  • 详细内容： 大部分雪道是中级（Blue），对新手和中级玩家友好，还有雪圈（tubing）项目。因为离市区近，很多人当天往返，不用住一晚。
  • 门票提示： ⚠️ 需购票；周末建议提前 1 周在官网（summitsatsnoqualmie.com）买，当天票常售罄。雪圈单独计费。
  • Source Reference： https://www.10adventures.com/seattle-winter-outdoors

4. Mt. Baker 滑雪（粉雪天堂）

  • 话题简介： 以"粉雪"闻名，雪量大、雪质好，是进阶玩家心中的圣地，约 3 小时车程。
  • 详细内容： Mt. Baker 每年降雪量很大，31 条雪道，新手到进阶都能找到乐趣。因为路程较远（近 3 小时），通常是一天甚至住一晚的行程，适合"认真玩一天粉雪"。
  • 门票提示： ⚠️ 需购票；旺季周末建议提前 1–2 周在官网（mtbaker.us）买，当天票常售罄。
  • Source Reference： https://www.10adventures.com/seattle-winter-outdoors

5. Crystal Mountain 滑雪 + 缆车雪鞋

  • 话题简介： 57 条雪道、有地形公园，进阶玩家最爱；还能坐缆车上山再走雪鞋，玩法多。
  • 详细内容： Crystal Mountain 偏向中级和进阶，57 条雪道加地形公园。特色是"缆车 + 雪鞋"组合——坐缆车到山顶，再在雪地里徒步探索，比纯滑雪更休闲。
  • 门票提示： ⚠️ 需购票；周末建议提前 1 周在官网（crystalmountainresort.com）买。
  • Source Reference： https://www.10adventures.com/seattle-winter-outdoors

  • 详细内容： 49 Degrees North 有 80+ 条雪道，地形偏难，适合进阶玩家。路程最远（4–5 小时），但雪质和地形是顶级。官网有特价日：Mega Monday（半价）、Twofer Tuesday（买一送一）。
  • 门票提示： ⚠️ 需购票；周末建议提前买；想省钱可盯官网特价日（周一半价、周二买一送一），在 ski49n.com 购买。

7. Olympic NP 雪鞋徒步（Hurricane Hill 等）

  • 话题简介： 2 小时车程到奥林匹克国家公园，雪鞋徒步路线从新手到进阶都有，免费、人少、风景绝美。
  • 详细内容： Olympic NP 提供多条雪鞋路线：Hurricane Hill（新手友好）、Eagle Point（中级）、Mount Townsend（进阶）。相比滑雪，雪鞋更安静、更"野"，适合喜欢自然的人。1 月是雪况稳定的季节。
  • 门票提示： 国家公园免费入园（1/19 更是全国免费日），只需付停车费；无需提前买票，但周末人多，建议早到抢车位。
  • Source Reference： https://www.10adventures.com/seattle-winter-outdoors
