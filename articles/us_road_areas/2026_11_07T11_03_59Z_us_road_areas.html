二、加州（California）— 西海岸

方位：美国最西端，太平洋沿岸。南北狭长，从北部的旧金山湾区到南部的洛杉矶、圣地亚哥。

1. 旧金山（San Francisco）

  • 特色出名：金门大桥（Golden Gate Bridge）、渔人码头（Fisherman's Wharf）、九曲花街（Painted Ladies / Lombard St）、恶魔岛（Alcatraz）。
  • 方位：加州北部，旧金山湾区。
  • 高速公路：I-80（横贯东西，连接湾区与内华达/拉斯维加斯方向）、I-280（南北向，穿过半岛）、US-101（沿海公路）。
  • 出口参考：金门大桥在 I-280 的 Exit 39（Golden Gate Bridge / US-101） 附近；渔人码头/市中心走 I-280 或 US-101 进城。

2. 洛杉矶（Los Angeles）

  • 特色出名：好莱坞（Hollywood Sign）、圣莫尼卡海滩（Santa Monica）、格里菲斯天文台（Griffith Observatory）、迪士尼乐园（Anaheim，附近）。
  • 方位：加州南部，太平洋沿岸。
  • 高速公路：I-5（南北主干，连接加州与俄勒冈/华盛顿）、I-10（东西向，通往亚利桑那/拉斯维加斯）、I-405 / I-110（市区环状）。
  • 出口参考：好莱坞标志在 I-10 的 Hollywood / Highland 一带；圣莫尼卡走 I-10 西端 Exit 1（Santa Monica Blvd）。

3. 一号公路（Pacific Coast Highway, US-101）

  • 特色出名：比克斯比大桥（Bixby Bridge）、大苏尔（Big Sur）、17-Mile Drive（蒙特雷半岛）。
  • 方位：加州中部沿海，旧金山与洛杉矶之间。
  • 高速公路：US-101 本身即沿海公路；I-5 为内陆平行快速线。
  • 出口参考：大苏尔段为 US-101 连续海岸线，无标准"出口号"概念，按里程牌（milepost）导航。

三、佛州（Florida）— 东南角

方位：美国东南端，东临大西洋、西临墨西哥湾，呈半岛伸入海中。

1. 奥兰多（Orlando）

  • 特色出名：迪士尼世界（Walt Disney World）、环球影城（Universal Studios）、海洋世界（SeaWorld）。
  • 方位：佛州中部内陆（不靠海）。
  • 高速公路：I-4（东西向，贯穿佛州中部）、I-75 / I-95（南北向，在奥兰多附近交汇）、FL-417（环状快速路）。
  • 出口参考：迪士尼世界在 I-4 的 Exit 40（Buena Vista / FL-535） 一带；环球影城走 I-4 Exit 41（Universal Blvd）。

2. 迈阿密（Miami）

  • 特色出名：南海滩（South Beach）、艺术装饰区（Art Deco / Ocean Drive）、小哈瓦那（Little Havana）。
  • 方位：佛州最南端，大西洋沿岸。
  • 高速公路：I-95（南北向，沿东海岸）、I-195（通往机场/市区）、US-1（沿海公路）。
  • 出口参考：南海滩走 I-95 转 I-195 / US-1；迈阿密市中心在 I-95 Exit 1（Downtown Miami）。

3. 坦帕（Tampa）

  • 特色出名：海滩、水族馆、体育场馆（海盗队/闪电队主场）。
  • 方位：佛州西海岸，墨西哥湾沿岸。
  • 高速公路：I-275（环状）、I-4 / I-75（东西向连接奥兰多）。
  • 出口参考：坦帕市中心在 I-275 Exit 1（Downtown Tampa）。

四、纽约（New York）— 东北沿海

方位：美国东北角，大西洋沿岸，哈德逊河入海口。

1. 曼哈顿（Manhattan, NYC）

  • 特色出名：自由女神像（Statue of Liberty）、时代广场（Times Square）、中央公园（Central Park）、帝国大厦/世贸中心（One WTC）。
  • 方位：纽约市核心，哈德逊河与东河之间的岛屿。
  • 高速公路：I-80 / I-95（东西向，穿过下城）、I-287（南北向，连接新泽西/长岛）、I-78（通往新泽西方向）。
  • 出口参考：时代广场/中城在 I-80 的 Exit 1（Lincoln Tunnel / 下城） 或走 I-95；自由女神像需乘渡轮（非高速直达）。

2. 布鲁克林（Brooklyn）

  • 特色出名：布鲁克林大桥（Brooklyn Bridge）、DUMBO、威廉斯堡（Williamsburg）。
  • 方位：曼哈顿东南，东河对岸。
  • 高速公路：I-278 / I-279（布鲁克林南北向）、I-64（通往新泽西）。
  • 出口参考：DUMBO 在 I-279 Exit 1（Brooklyn Bridge） 附近。

五、芝加哥（Chicago）— 中西部

方位：美国中西部，密歇根湖（五大湖之一）西南岸。

1. 芝加哥市区（Downtown / Loop）

  • 特色出名：威利斯大厦（Willis Tower / 原西尔斯大厦）、千禧公园"大豆子"（Cloud Gate）、海军码头（Navy Pier）、千层楼天际线。
  • 方位：密歇根湖西南角，市区呈网格状。
  • 高速公路：I-90 / I-94（东西向，横贯市区，即 Edens / Kennedy 高速）、I-88（南北向，连接伊利诺伊州北部）、I-55（南北向，通往圣路易斯方向）、I-294（环状）。
  • 出口参考：威利斯大厦/千禧公园在 I-90/94 的 Exit 1（Downtown / Lake Shore Dr） 一带；海军码头走 I-90 转 Lake Shore Dr。

2. 奥黑尔机场（O'Hare, ORD）

  • 特色出名：芝加哥最大国际机场。
  • 方位：市区西北约 25 公里。
  • 高速公路：I-90 / I-94（直接连接机场）、I-294（环状）。
  • 出口参考：奥黑尔机场在 I-90/94 Exit 1（O'Hare Airport）。

七、使用提示

  1. 出口号会变化：上表出口号为常见参考值，实际以实时地图为准（Google Maps / Waze / 州 DOT 官网）。
  2. 方向很重要：同一高速的"东行/西行""北行/南行"出口编号不同，导航时注意方向。
  3. 沿海 vs 内陆：加州、纽约靠大西洋/太平洋；佛州半岛三面环海；芝加哥靠密歇根湖（五大湖）。
  4. 本文件为常识性整理，非实时检索结果；如需精确到具体出口与里程，建议用地图工具逐点核对。
