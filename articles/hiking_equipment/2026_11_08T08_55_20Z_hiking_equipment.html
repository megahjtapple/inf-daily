2.2 一日徒步（Day Hike）必备清单

来源：CleverHiker — Ultimate Day Hiking Checklist & Essential Gear to Pack（Heather Eldridge）

出发前（TO DO）

  • 申请许可证 / 预约、打电话给护林站确认开放情况、确认停车通行证。
  • 查天气（NOAA / SpotWX / Mountain Forecast）。
  • 手机充满电、开启 SOS；下载 GPS App + 离线地图；把行程发给一位朋友。

工具 / 配件

  • 头灯、极简钱包、手机壳、急救包 + 处方药、防晒霜 + SPF 润唇膏。
  • 「便便包」（纸巾、免洗洗手液、小铲）、口袋刀 / 多功能钳。
  • 超轻椅 / 坐垫 / 吊床、登山杖。

导航

  • 地形图（topo map）+ 防水地图袋、指南针（如 Suunto M-3）、手表 / GPS、手机 GPS App。

服装（关键：快干，别穿纯棉）

  • 快干徒步裤 / 短裤、速干打底 / 防晒衣、雨壳 / 羽绒 / 抓绒 / 防风外套。
  • 徒步鞋 / 靴、高品质非棉袜（防起泡）、护腿（gaiters）、帽子、手套、太阳镜。

食物与水

  • 备用瓶 / 水袋、零食与正餐、餐具、空垃圾袋（带走垃圾）、电解质冲剂。

雨 / 雪

  • 雨衣 / 雨裤 / 手套、雨伞、保暖袜、防滑钉 / 雪鞋。

蚊虫 / 蜱虫

  • 衣物预涂 Permethrin、皮肤用 Picaridin 驱蚊、头网。

长线 / 偏远地区（额外）

  • 备用食物、哨子、Tenacious Tape 修补胶、打火机 / 引火物、滤水器（如 Aquamira）、可折叠容器、卫星通讯器 / PLB（如 Garmin inReach Mini 2）、急救毯。

小贴士： 一日徒步优先选 20–30L 轻量背包；分层快干穿搭；非棉袜防起泡。

3.3 注意事项（安全）

  • 防火与柴火：只用营地提供的木柴或就地捡拾，不要从远处搬运木柴（防松材甲虫等入侵物种传播）；遵守当地火规，风大 / 禁火期不生火。
  • 天气与失温：山区昼夜温差大，备保暖层；下雨备雨壳与防水袋。
  • 蜱虫 / 蚊虫：衣物预涂 Permethrin、皮肤用 Picaridin、戴头网；回营后检查全身。
  • 野生动物：食物密封（熊罐 / 悬挂），营地不留食物气味。
  • LNT（无痕山林）：带走所有垃圾，便便挖坑掩埋（距水源 60m 以上）。
  • 通讯与救援：偏远地区无信号，带卫星通讯器 / PLB；出发前把行程告知他人。

3.4 露营准备清单（汇总）

  • 住宿：帐篷 + 地布、睡袋（按季节温标）、防潮垫 / 充气垫、枕头。
  • 照明：头灯 + 备用电池、营地灯。
  • 炊具 / 水：炉头 + 气罐、锅具、餐具、水壶 / 滤水器、净水片。
  • 衣物：快干衣裤、保暖层、雨壳、非棉袜、帽子手套、徒步鞋。
  • 工具：登山杖、多功能钳、急救包、哨子、修补胶、打火机 / 引火物。
  • 防护：防晒霜 + SPF 唇膏、驱蚊（Permethrin / Picaridin）、头网。
  • 导航 / 电子：离线地图、指南针、手机 + 充电宝、卫星通讯器（偏远地区）。
  • 其他：垃圾袋（带走垃圾）、纸巾 / 免洗洗手液、备用食物与水。
