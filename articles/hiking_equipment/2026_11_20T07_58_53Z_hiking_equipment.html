二、露营怎么玩（How to Camp）

1. 入门流程（通用知识 + 来源）

  1. 选营地：华盛顿州可用 recreation.gov（国家公园/森林营地预订）、dnr.wa.gov（州公园/州立林）。
    • Recreation.gov — Camping, Cabins, RVs, Permits
    • Green Mountain and Tahuya State Forest (dnr.wa.gov)
  2. 定类型：车边露营（car camping，最轻松）→ 帐篷徒步露营（backpacking，轻装）→ RV/木屋。新手建议从 car camping 起步。
  3. 看天气与季节：Cascade 山区 11 月已入冬，部分高海拔步道封路、有雪；选低海拔营地并备保暖层。
  4. 预订 + 许可：热门营地（如 Mt. Baker-Snoqualmie、Olympic）需提前在 recreation.gov 订位。

2. 营地怎么搭（通用知识）

  • 选地：平整、排水好、远离「寡妇树」（枯死大树）、不在河滩洪泛线内。
  • 顺序：先铺地垫 → 立帐篷 → 挂天幕/防雨 → 设厨房区（与睡区分离）。
  • 防潮：地面垫 + 睡袋防潮垫（R 值越高越保暖），夜间地面吸热是失温主因之一。

3. 露营怎么玩 / 常见活动（通用知识）

  • 篝火（确认营地允许）、星空观测、溪边徒步、钓鱼、观鸟、夜间萤火虫/极光（高纬度冬季偶见）。
  • 西雅图周边热门：Mt. Baker-Snoqualmie NF、Olympic NP、North Cascades、Green Mountain / Tahuya State Forest。

  • [ ] 食物：比计划多 1 天余量
  • [ ] 饮水：水壶/水袋 + 过滤或净化片
  • [ ] 应急庇护：轻量天幕/求生毯

露营额外

  • [ ] 帐篷 + 地垫 + 防潮垫（R 值≥3）
  • [ ] 睡袋（按季节温标选）
  • [ ] 炉具 + 燃料 + 锅具
  • [ ] 熊罐 / 食物悬挂绳（山区必带）
  • [ ] 防虫喷雾、湿巾、个人洗漱
  • [ ] 垃圾袋（带走所有垃圾，Leave No Trace）
