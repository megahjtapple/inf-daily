1. Amazon 发布新一代 AI 芯片 Trainium3

类别： 新产品 / AI 基础设施 热度： ⭐⭐⭐⭐⭐

简介： Amazon 在 2026 年 9 月下旬正式发布了其第三代自研 AI 训练芯片 Trainium3，宣称在推理速度和能效比方面较上一代提升超过 40%。该芯片专为大规模 LLM 训练和推理设计，是 AWS 对抗 NVIDIA GPU 生态的核心武器。

详细内容：

  • Trainium3 采用 5nm 先进制程，单芯片算力达到 2.5 PFLOPS（FP8）
  • 支持原生 FP4/FP8 低精度推理，大幅降低大模型部署成本
  • 配套发布新一代网络互联技术「NeuronLink v3」，集群扩展能力提升至 100 万+ 芯片
  • AWS 表示 Trainium3 将在 2026 Q4 全面上线 Bedrock 和 SageMaker 平台
  • 分析师认为此举将进一步削弱 NVIDIA 在 AI 云市场的定价权
  • Amazon 同时宣布与多家超大规模企业签署 Trainium3 优先采购协议

2. AWS 推出 Agentic AI 平台「Amazon Bedrock AgentCore」

类别： 新产品 / AI 应用 热度： ⭐⭐⭐⭐⭐

简介： AWS 在 9 月发布了 Bedrock AgentCore 平台，为企业客户提供一站式构建、部署和管理 AI Agent 的基础设施。该平台整合了模型编排、工具调用、记忆管理和多 Agent 协作能力。

详细内容：

  • AgentCore 提供可视化 Agent 编排界面，支持拖拽式工作流构建
  • 内置「Agent Memory」服务，支持长期上下文记忆和跨会话状态管理
  • 支持多 Agent 协作模式（Multi-Agent Orchestration），可编排数十个 Agent 协同完成任务
  • 集成 Amazon Bedrock 所有可用模型（Claude、Llama、Titan 等）
  • 提供企业级安全隔离、审计日志和合规认证（SOC2、HIPAA）
  • 定价采用按 Agent 运行时长计费，起步价 $0.05/小时
  • AWS CTO 表示 AgentCore 是「AI 从对话走向行动」的关键基础设施
