一、期权入门教程

#1. 期权是什么：Call 与 Put 的核心区别 ⭐⭐⭐⭐⭐

【话题简介】 期权（Option）是一种合约，赋予买方在到期日前以约定价格买入或卖出标的资产的权利（而非义务）。最基础的分法是 看涨期权（Call） 和 看跌期权（Put）。

【详细内容】

  • Call（看涨期权）：买方预期标的上涨，有权以行权价（strike price）买入。适合看好后市。
  • Put（看跌期权）：买方预期标的下跌，有权以行权价卖出。适合看空或对冲下行风险。
  • 关键要素：行权价（Strike）、到期日（Expiry）、权利金 / 溢价（Premium）。
  • 期权按价值状态分为 实值（ITM）/ 平值（ATM）/ 虚值（OTM），直接影响价格与概率。
  • 新手建议：先用小额虚值期权理解"时间 + 波动率"双重风险，再考虑方向性策略。

#2. 时间衰减（Theta）：期权如何随时间"贬值" ⭐⭐⭐⭐⭐

【话题简介】 期权有时间价值，会随到期日临近而加速流失——这就是 时间衰减（Time Decay / Theta）。它是期权买方最大的隐性成本。

【详细内容】

  • 时间价值 = 期权价格 − 内在价值。到期日越近，时间价值归零越快。
  • 衰减曲线非线性：最后 30–45 天衰减最陡峭（"theta 加速"），因此临近到期的虚值期权极易归零。
  • 对买方：时间是敌人，应尽早建立头寸、避免持有到期前一周的虚值单。
  • 对卖方：时间是朋友，可收取时间价值（如备兑开仓 Covered Call、现金担保卖 Put）。
  • 实战含义：财报前买入期权，即使方向判断正确，若波动率回落（IV crush）仍可能亏损——"方向对但亏钱"是新手最常见陷阱。

#3. 何时决定买入 / 卖出期权：决策框架 ⭐⭐⭐⭐

【话题简介】 买卖时机的核心是判断「方向 + 波动率 + 时间」三者的组合，而非单纯押注涨跌。

【详细内容】

  • 买 Call：预期上涨 且 预期波动率上升（如财报前、重大利好前）。
  • 买 Put：预期下跌 或 作为持仓对冲（保护性 Put / Protective Put）。
  • 卖期权：预期价格横盘、波动率回落，赚取时间价值与权利金。
  • 关键信号——隐含波动率（IV）：IV 高企时买入期权"贵"，IV 低迷时买入"便宜"。财报后 IV 通常骤降（IV crush），是卖方有利、买方不利的窗口。
  • 决策清单：① 方向判断是否清晰？② 当前 IV 处于历史高位还是低位？③ 到期日是否留足时间缓冲？④ 最大亏损（权利金）是否可承受？

#4. 隐含波动率与"隐含波动区间"（Implied Move）解读 ⭐⭐⭐⭐

【话题简介】 期权市场通过价格隐含出"预期波动幅度"，即 implied move。它告诉你市场为某事件（如财报）定价了多少上下波动空间。

【详细内容】

  • implied move = 期权价格隐含的到期日预期涨跌幅（%），是双向的，不指示方向。
  • 本周财报季（9/8–9/11）部分标的隐含波动区间（TipRanks 基于平值跨式 straddle 计算）：
    • CAN（Canterbury）±61.11%、NNOX ±34.98%、ODD ±21.60%、FLWS ±20.91%、DBI ±19.01%、MCFT ±18.63%——小盘股隐含波动极大，期权"贵"且风险高。
    • ORCL（Oracle）±11.82%、ADBE（Adobe）±8.07%、CHWY（Chewy）±10.78%、M（Macy's）±8.37%——大盘股隐含波动相对温和。
  • 实战含义：财报前 implied move 越高，期权权利金越贵；若实际波动低于隐含值，买方即使方向对也可能亏损。

#5. 常见期权策略速览（从简单到进阶）⭐⭐⭐⭐

【话题简介】 除单腿买 Call / Put 外，组合策略可控制风险、降低成本。新手应理解每种策略的"最大亏损 / 最大盈利"边界。

【详细内容】

  • 备兑开仓（Covered Call）：持有正股 + 卖 Call，赚取权利金；代价是放弃上涨空间。适合横盘或温和看涨。
  • 现金担保卖 Put（Cash-Secured Put）：卖 Put 收取权利金；若跌破行权价则需接货。适合愿意在更低价格买入的标的。
  • 垂直价差（Vertical Spread / Debit-Credit Spread）：同时买卖不同行权价的期权，锁定最大盈亏，降低权利金成本。
  • 跨式 / 宽跨式（Straddle / Strangle）：财报前押注"大幅波动"（不分方向），隐含波动越高越贵。
  • 风险边界：买方最大亏损 = 权利金；卖方最大盈利 = 权利金，但裸卖 Put/Call 理论上亏损无上限。

  • Investopedia — Options Explained: Key Types and Risk Management Strategies: https://www.investopedia.com/terms/o/option.asp

#6. 期权风险清单：新手最容易踩的坑 ⭐⭐⭐

【话题简介】 期权是杠杆工具，亏损速度远快于正股。理解风险边界比预测方向更重要。

【详细内容】

  • 归零风险：虚值期权到期若未实值，权利金 100% 损失。
  • IV crush（波动率骤降）：财报后 IV 回落，即使股价上涨，Call 也可能下跌。
  • Theta 侵蚀：横盘市中买方持续失血。
  • 流动性风险：小盘股期权买卖价差大、滑点高，进出成本高。
  • 杠杆放大：10 倍杠杆意味着 10% 的反向波动即可能归零。
  • 建议：单笔权利金不超过总资金 2–5%；优先选择流动性好（成交量 / 未平仓量高）的标的。
