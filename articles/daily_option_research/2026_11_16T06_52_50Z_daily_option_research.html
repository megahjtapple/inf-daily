4. 期权快速上手教程：Call、Put 与核心概念

热度： 🔥🔥🔥🔥 类别： 教育/入门

话题简介： 期权是赋予持有者在特定日期前以特定价格买入（Call）或卖出（Put）标的资产的权利（而非义务）的合约。本条目汇总期权核心概念，适合新手快速建立框架。

详细内容：

  • Call Option（看涨期权）： 赋予持有者以行权价买入标的资产的权利。标的上涨时 Call 增值。买方最大亏损 = 支付的溢价；卖方风险近乎无限
  • Put Option（看跌期权）： 赋予持有者以行权价卖出标的资产的权利。标的下跌时 Put 增值。可用作"保险"保护持仓
  • 行权价（Strike Price）： 买卖标的的约定价格
  • 到期日（Expiration Date）： 合约有效期限，OTM 期权到期后价值归零
  • 溢价（Premium）： 购买期权的成本，由内在价值 + 时间价值组成
  • ATM/ITM/OTM： 平值（行权价=现价）、实值（有内在价值）、虚值（仅时间价值）
  • 美式 vs 欧式： 美式可在到期前任何时间行权；欧式只能在到期日行权。美国个股期权多为美式，指数期权多为欧式
  • 合约乘数： 每份合约通常代表100股标的资产
  • 核心用途： 投机（杠杆）、对冲（保护持仓）、收入（卖出期权收取溢价）

14. 期权 Greeks 详解：Delta、Theta、Gamma、Vega

热度： 🔥🔥🔥 类别： 教育/进阶

话题简介： Greeks 是衡量期权价格敏感度的核心指标。Delta（方向敏感度）、Theta（时间衰减）、Gamma（Delta变化率）、Vega（波动率敏感度）是四大基础 Greeks。

详细内容：

  • Delta (Δ)： 标的每变动$1，期权价格变动多少。Call Delta 范围 0–1，Put Delta 范围 -1–0。也可近似为到期 ITM 的概率
  • Theta (Θ)： 时间衰减率。每天经过，期权价值减少多少。ATM 期权 Theta 最高；临近到期时衰减加速。Long Call/Put 通常有负 Theta
  • Gamma (Γ)： Delta 的变化率。标的每变动$1，Delta 变化多少。ATM 期权 Gamma 最高；临近到期时 Gamma 增大
  • Vega (ν)： 波动率敏感度。IV 每变动1%，期权价格变动多少。ATM 且长期限期权 Vega 最大
  • Rho (ρ)： 利率敏感度。利率每变动1%，期权价格变动多少。对长期限 ATM 期权影响最大
  • 高阶 Greeks： Lambda、Epsilon、Vomma、Vera、Speed、Zomma、Color、Ultima（二阶/三阶导数）

15. 期权价差策略：Bull Call Spread、Iron Condor 等

热度： 🔥🔥 类别： 教育/策略

话题简介： 价差策略通过同时买入和卖出不同行权价或到期日的期权，创造特定的风险-收益轮廓。常见策略包括 Bull Call Spread、Bear Put Spread、Iron Condor、Butterfly Spread 等。

详细内容：

  • Bull Call Spread（牛市看涨价差）： 买入低行权价 Call + 卖出高行权价 Call。限制最大亏损和最大利润，适合温和看涨
  • Bear Put Spread（熊市看跌价差）： 买入高行权价 Put + 卖出低行权价 Put。适合温和看跌
  • Iron Condor（铁鹰）： 同时卖出 Bull Call Spread 和 Bear Put Spread。适合预期低波动率，收取双份溢价
  • Butterfly Spread（蝶式价差）： 买入1个低行权价 + 卖出2个中间行权价 + 买入1个高行权价。适合预期标的停留在窄幅区间
  • Credit Spread vs Debit Spread： 信用价差先收钱（净收入），借方价差先付钱（净支出）
  • Straddle/Strangle： 同时买入 Call 和 Put，适合预期大幅波动（方向不确定）

16. 美式 vs 欧式期权：行权规则区别

热度： 🔥🔥 类别： 教育/入门

话题简介： 美式期权可在到期前任何时间行权，欧式期权只能在到期日行权。美国个股期权多为美式，指数期权多为欧式。

详细内容：

  • 美式期权： 购买日至到期日之间任何时间均可行权。通常溢价更高（因为提前行权权利有价值）
  • 欧式期权： 只能在到期日当天行权。溢价通常低于同等条件的美式期权
  • 美国市场惯例： 个股期权 = 美式；指数期权（SPX、NDX）= 欧式
  • 实际影响： 美式期权的提前行权权利使其在深度 ITM 时可能被提前行权（尤其是有股息时）

17. 期权买方 vs 卖方：风险对比

热度： 🔥🔥 类别： 教育/风险

话题简介： 期权买方最大亏损 = 支付的溢价（有限）；期权卖方最大利润 = 收取的溢价（有限），但风险可能无限（Call 卖方）或很大（Put 卖方）。

详细内容：

  • Call 买方： 最大亏损 = 溢价。标的上涨时获利，理论上无限
  • Call 卖方： 最大利润 = 溢价。标的上涨时亏损，理论上无限
  • Put 买方： 最大亏损 = 溢价。标的下跌时获利，最大利润 = 行权价 - 溢价
  • Put 卖方： 最大利润 = 溢价。标的下跌时亏损，最大亏损 = 行权价 - 溢价
  • 核心原则： 买方风险有限、收益可能很大；卖方收益有限、风险可能很大
  • 保证金： 卖方通常需要缴纳保证金，买方不需要

18. 期权到期日与时间衰减（Theta）

热度： 🔥🔥 类别： 教育/进阶

话题简介： 期权有到期日，OTM 期权到期后价值归零。时间衰减（Theta）是期权买方的最大敌人——每天经过，期权价值都在减少。

详细内容：

  • 到期日类型： 每日、每周、每月（通常第三周五）、每季度
  • Theta 效应： ATM 期权 Theta 最高；ITM/OTM 期权 Theta 较低
  • 加速衰减： 临近到期时，时间衰减速度加快（尤其对 OTM 期权）
  • 买方策略： 选择足够远的到期日以避免快速衰减；或选择 ITM 期权（Theta 较低）
  • 卖方策略： 利用 Theta 收取溢价，在到期前平仓获利
  • 实际例子： Theta = -0.50 的期权，每天价值减少 $0.50/股（$50/合约）

19. 隐含波动率（IV）与期权定价

热度： 🔥🔥 类别： 教育/进阶

话题简介： 隐含波动率（IV）是市场对未来波动率的预期，直接影响期权价格。IV 越高，期权越贵；IV 越低，期权越便宜。

详细内容：

  • IV 定义： 由期权市场价格反推出的标的资产预期波动率
  • IV 与期权价格： IV 上升 → 期权价格上升（Vega 效应）；IV 下降 → 期权价格下降
  • IV 偏斜（Skew）： Put 的 IV 通常高于 Call（因为市场为下行风险支付更多保费）
  • 事件驱动 IV： 财报、Fed 会议、选举等事件前 IV 通常飙升，事件后回落（IV Crush）
  • 交易策略： 高 IV 时卖出期权收取溢价；低 IV 时买入期权等待波动率上升

21. 保护性 Put 策略（Married Put）

22. 收入策略：Covered Call（备兑看涨）

热度： 🔥🔥 类别： 教育/策略

话题简介： Covered Call = 持有股票 + 卖出同标的 Call。收取溢价增加收入，但限制上行空间。适合温和看涨或中性市场。

详细内容：

  • 构造： 持有100股股票 + 卖出1份 Call（行权价 > 当前股价）
  • 最大利润： (行权价 - 股票成本) × 100 + 收取的溢价
  • 最大亏损： 股票跌至零的损失 - 收取的溢价
  • 适用场景： 温和看涨或中性市场；希望增加持仓收入
  • 风险： 股票大涨时，Call 被行权，你以行权价卖出股票，错过进一步上涨

23. Straddle/Strangle：波动率策略

热度： 🔥 类别： 教育/策略

话题简介： Straddle = 同时买入同到期日、同行权价的 Call 和 Put。Strangle = 同时买入 OTM Call 和 OTM Put。两者都适合预期大幅波动但方向不确定的场景。

详细内容：

  • Long Straddle： 买入 ATM Call + ATM Put。成本较高，需要标的移动超过总溢价才盈利
  • Long Strangle： 买入 OTM Call + OTM Put。成本较低，需要标的移动更大才盈利
  • 适用场景： 财报前、Fed 会议前、重大事件前
  • 风险： 如果标的不怎么动，两份期权都衰减，亏损 = 总溢价
  • IV Crush 风险： 事件后 IV 通常下降，即使方向对了，IV 下降也可能导致亏损

24. Butterfly Spread：蝶式价差

热度： 🔥 类别： 教育/策略

话题简介： Butterfly Spread = 买入1个低行权价 + 卖出2个中间行权价 + 买入1个高行权价。适合预期标的停留在窄幅区间的场景，最大利润在中间行权价处。

详细内容：

  • 构造： 买入1 Call (K1) + 卖出2 Call (K2) + 买入1 Call (K3)，其中 K1 < K2 < K3
  • 最大利润： 在 K2 处，= (K2-K1) - 净支出
  • 最大亏损： 净支出（在 K1 以下或 K3 以上）
  • 适用场景： 预期标的价格将停留在某个狭窄区间；IV 较高时
  • 优势： 成本低（净支出小），风险有限

25. 期权 ETF vs 指数期权

  • 选择建议： 想要提前行权灵活性 → ETF 期权；想要现金结算简化 → 指数期权

28. Black-Scholes 定价模型

热度： 🔥 类别： 教育/进阶

话题简介： Black-Scholes 模型是期权定价的理论基础，通过标的价格、行权价、到期时间、无风险利率和波动率五个变量计算期权理论价格。

详细内容：

  • 五个输入变量： S（标的价格）、K（行权价）、T（到期时间）、r（无风险利率）、σ（波动率）
  • 假设： 标的价格服从对数正态分布；无交易成本；无股息；可以连续交易
  • 局限性： 实际市场不满足所有假设（跳跃、肥尾、离散交易）
  • 实际应用： 提供理论基准，实际价格围绕理论价格波动
  • 与 IV 的关系： 市场隐含的 IV 就是使 Black-Scholes 模型输出等于市场价格的 σ

29. 波动率偏斜（Volatility Skew）

热度： 🔥 类别： 教育/进阶

话题简介： 波动率偏斜指不同行权价期权的 IV 不同。通常 Put 的 IV 高于 Call（"Put Skew"），反映市场对下行风险的更高定价。

详细内容：

  • Put Skew： OTM Put 的 IV > ATM > OTM Call。市场为"保险"支付溢价
  • Smile/Skew 形状： 某些资产（如外汇）呈现"微笑"——两端 IV 都高
  • 交易含义： 卖出高 IV 的 Put + 买入低 IV 的 Call = 利用偏斜获利
  • 事件影响： 危机时 Skew 加剧（Put IV 飙升）；平静时 Skew 平坦

30. 合成期权策略（Synthetic Options）

热度： 🔥 类别： 教育/进阶

话题简介： 合成期权通过组合多个期权和/或期货，创造出与单一期权相同的风险-收益轮廓。例如：合成 Long Call = Long Forward + Long Put。

32. 期权与期货的区别

热度： 🔥 类别： 教育/入门

话题简介： 期权赋予权利（无义务），期货是义务。期权买方风险有限，期货双方都有履约义务。

详细内容：

  • 权利 vs 义务： 期权 = 权利（可不行权）；期货 = 义务（必须交割）
  • 风险： 期权买方最大亏损 = 溢价；期货双方都可能亏损无限
  • 保证金： 期权买方无需保证金；期货双方都需缴纳保证金
  • 灵活性： 期权可以提前行权（美式）；期货只能在到期日或平仓
  • 适用场景： 方向性投机 + 有限风险 → 期权；对冲 + 高流动性 → 期货

34. 期权到期日选择：每日、每周、每月、每季度

  • 每日期权（0DTE）： 极高杠杆，Theta 衰减极快。适合日内交易者

  • 每季度/LEAPS： 3个月以上。Theta 衰减慢，适合长期方向性观点
  • 选择原则： 事件驱动 → 选事件后到期；长期观点 → 选 LEAPS；收入策略 → 选1–3个月

35. ATM、ITM、OTM 选择指南

热度： 🔥 类别： 教育/策略

话题简介： ATM（平值）期权 Delta ≈ 0.5，Theta 最高；ITM（实值）有内在价值，Delta > 0.5；OTM（虚值）仅时间价值，Delta < 0.5。选择取决于策略目标。

详细内容：

  • ATM： 最大 Vega 和 Theta。适合波动率交易
  • ITM： 较低 Theta，较高 Delta。适合替代直接持股（LEAPS）
  • OTM： 最高杠杆，最低胜率。适合高确信度方向性交易
  • Delta 作为概率： 0.40 Delta Call ≈ 40% 概率到期 ITM
  • 选择建议： 保守 → ITM；平衡 → ATM；激进 → OTM

  • 注意事项： 这是近似值，不是精确概率。受 IV、时间、利率影响

37. Gamma 与到期日临近效应

热度： 🔥 类别： 教育/进阶

话题简介： Gamma 衡量 Delta 的变化速度。临近到期时，ATM 期权的 Gamma 急剧增大，意味着 Delta 可能因标的微小变动而剧烈变化。

详细内容：

  • 交易影响： 高 Gamma 意味着 Delta 不稳定，对冲需要更频繁调整
  • 策略含义： 避免在到期日前持有 ATM 期权（除非你期望大幅波动）

38. Vega 与波动率交易

热度： 🔥 类别： 教育/进阶

话题简介： Vega 衡量期权对 IV 变化的敏感度。正 Vega（买方）受益于 IV 上升；负 Vega（卖方）受益于 IV 下降。

详细内容：

  • 正 Vega： 买入期权。IV 上升 → 获利。适合预期波动率上升
  • 负 Vega： 卖出期权。IV 下降 → 获利。适合预期波动率下降
  • Vega 大小： ATM + 长期限 = 最大 Vega
  • IV Crush： 事件后 IV 通常下降，正 Vega 头寸亏损
  • 策略： 高 IV 时卖出（负 Vega）；低 IV 时买入（正 Vega）

39. Rho 与利率敏感性

热度： 🔥 类别： 教育/进阶

话题简介： Rho 衡量期权对无风险利率变化的敏感度。Call 的 Rho 为正（利率上升 → Call 增值），Put 的 Rho 为负。

  • 影响程度： 对长期限 ATM 期权影响最大；短期期权 Rho 很小
  • 实际意义： 在正常利率环境中，Rho 的影响远小于 Delta、Theta、Gamma、Vega

40. Delta-Gamma 中性对冲

话题简介： Delta-Gamma 中性对冲不仅使组合 Delta = 0，还使 Gamma = 0，从而在标的价格变动时保持 Delta 接近零。

41. 信用价差 vs 借方价差

热度： 🔥 类别： 教育/策略

话题简介： 信用价差（Credit Spread）先收钱（净收入），借方价差（Debit Spread）先付钱（净支出）。两者都限制最大亏损和最大利润。

详细内容：

  • Bull Call Credit Spread： 卖出低行权价 Call + 买入高行权价 Call。收取净溢价
  • Bull Call Debit Spread： 买入低行权价 Call + 卖出高行权价 Call。支付净支出
  • 选择建议： 温和看涨 + 想收钱 → Credit；较强看涨 + 愿意付钱 → Debit
  • 风险对比： Credit 最大亏损 = 收取的溢价；Debit 最大亏损 = 支付的净支出

42. Iron Condor：铁鹰策略

热度： 🔥 类别： 教育/策略

话题简介： Iron Condor = 同时卖出 Bull Call Spread 和 Bear Put Spread。收取双份溢价，适合预期低波动率、标的停留在窄幅区间的场景。

详细内容：

  • 构造： 卖出 OTM Put + 买入更低 Put + 卖出 OTM Call + 买入更高 Call

  • 适用场景： 低 IV 环境；财报后 IV Crush；横盘市场

话题简介： 日历价差 = 卖出近期期权 + 买入远期期权（同行权价）。利用近远月 Theta 差异获利，适合预期短期横盘、长期方向性的场景。

  • 最大亏损： 标的远离行权价时
  • 适用场景： 预期短期不动、长期上涨；IV 期限结构倒挂时
  • 优势： 风险有限；不需要方向性判断（短期）

44. 比率价差（Ratio Spread）

热度： 🔥 类别： 教育/策略

话题简介： 比率价差 = 买入和卖出不同数量的期权。例如 1:2 Ratio Call Spread = 买入1个低行权价 Call + 卖出2个高行权价 Call。

45. Strangle：宽跨式策略

热度： 🔥 类别： 教育/策略

话题简介： Long Strangle = 买入 OTM Call + 买入 OTM Put（同到期日）。成本低于 Straddle，但需要标的移动更大才盈利。

详细内容：

  • 构造： 买入 OTM Call (K1) + 买入 OTM Put (K2)，K1 > K2
  • 最大亏损： 总溢价（在 K2 和 K1 之间）
  • 盈利条件： 标的跌破 K2 - 总溢价 或 涨超 K1 + 总溢价
  • vs Straddle： Strangle 成本更低，但需要更大移动
  • 适用场景： 预期大幅波动但方向不确定；IV 较低时

46. Put-Call Parity：平价关系

热度： 🔥 类别： 教育/进阶

话题简介： Put-Call Parity 描述了 Call、Put、标的和期货之间的价格关系：C + PV(K) = P + S。违反此关系时存在套利机会。

详细内容：

  • 公式： C - P = S - PV(K)，其中 PV(K) = K × e^(-rT)
  • 含义： Call 和 Put 的价格差 = 标的价格与行权价现值的差
  • 套利： 如果市场违反平价关系，可以通过买入便宜方、卖出昂贵方获利
  • 应用： 用于定价合成期权；检测市场异常

47. 美式 vs 欧式行权规则详解

热度： 🔥 类别： 教育/入门

话题简介： 美式期权可在到期前任何交易日行权；欧式期权只能在到期日当天行权。这影响提前行权策略和定价。

详细内容：

  • 美式行权： 任何交易日收盘后提交行权通知。适合深度 ITM + 有股息的股票
  • 欧式行权： 只能在到期日（通常第三周五）行权。指数期权标准
  • 提前行权条件： 当 Call 的内在价值 > 继续持有的时间价值时（通常是有股息时）
  • 定价影响： 美式期权溢价 ≥ 欧式期权（因为多了提前行权权利）

48. 期权合约乘数：100股/份

话题简介： 标准期权合约代表100股标的资产。$0.37 的溢价 = $37 总成本（$0.37 × 100）。理解乘数是计算盈亏的基础。

  • 管理建议： 只卖出有充分理由的期权；设置止损；避免在事件前卖出

50. 期权税务处理基础

热度： 🔥 类别： 教育/入门

话题简介： 期权交易的税务处理取决于你是买方还是卖方、持有时间、是否行权。短期资本利得 vs 长期资本利得的税率不同。

详细内容：

  • 买方： 到期 ITM → 行权后按股票买卖计税；到期 OTM → 亏损 = 支付的溢价

  • 持有期： <1年 = 短期资本利得（按普通收入税率）；>1年 = 长期资本利得（较低税率）
  • 注意事项： 税务规则复杂，建议咨询税务顾问。不同国家/地区规则不同
