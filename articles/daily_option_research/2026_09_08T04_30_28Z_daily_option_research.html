一、期权入门教程

#1. 期权是什么：Call 与 Put 的核心区别 ⭐⭐⭐⭐⭐

【话题简介】 期权（Option）是一种合约，赋予买方在到期日前以约定价格买入或卖出标的资产的权利（而非义务）。最基础的分法是 看涨期权（Call） 和 看跌期权（Put）。

【详细内容】

  • Call（看涨期权）：买方预期标的上涨，有权以行权价（strike price）买入。适合看好后市。
  • Put（看跌期权）：买方预期标的下跌，有权以行权价卖出。适合看空或对冲下行风险。
  • 关键要素：行权价（Strike）、到期日（Expiry）、权利金 / 溢价（Premium）。
  • 期权按价值状态分为 实值（ITM）/ 平值（ATM）/ 虚值（OTM），直接影响价格与概率。
  • 新手建议：先用小额虚值期权理解"时间 + 波动率"双重风险，再考虑方向性策略。

#2. 时间衰减（Theta）：期权如何随时间"贬值" ⭐⭐⭐⭐⭐

【话题简介】 期权有时间价值，会随到期日临近而加速流失——这就是 时间衰减（Time Decay / Theta）。它是期权买方最大的隐性成本。

【详细内容】

  • 时间价值 = 期权价格 − 内在价值。到期日越近，时间价值归零越快。
  • 衰减曲线非线性：最后 30–45 天衰减最陡峭（"theta 加速"），因此临近到期的虚值期权极易归零。
  • 对买方：时间是敌人，应尽早建立头寸、避免持有到期前一周的虚值单。
  • 对卖方：时间是朋友，可收取时间价值（如备兑开仓 Covered Call、现金担保卖 Put）。
  • 实战含义：财报前买入期权，即使方向判断正确，若波动率回落（IV crush）仍可能亏损——"方向对但亏钱"是新手最常见陷阱。

#3. 何时决定买入 / 卖出期权：决策框架 ⭐⭐⭐⭐

【话题简介】 买卖时机的核心是判断「方向 + 波动率 + 时间」三者的组合，而非单纯押注涨跌。

【详细内容】

  • 买 Call：预期上涨 且 预期波动率上升（如财报前、重大利好前）。
  • 买 Put：预期下跌 或 作为持仓对冲（保护性 Put / Protective Put）。
  • 卖期权：预期价格横盘、波动率回落，赚取时间价值与权利金。
  • 关键信号——隐含波动率（IV）：IV 高企时买入期权"贵"，IV 低迷时买入"便宜"。财报后 IV 通常骤降（IV crush），是卖方有利、买方不利的窗口。
  • 决策清单：① 方向判断是否清晰？② 当前 IV 处于历史高位还是低位？③ 到期日是否留足时间缓冲？④ 最大亏损（权利金）是否可承受？

#4. 隐含波动率与"隐含波动区间"（Implied Move）解读 ⭐⭐⭐⭐

【话题简介】 期权市场通过价格隐含出"预期波动幅度"，即 implied move。它告诉你市场为某事件（如财报）定价了多少上下波动空间。

【详细内容】

  • implied move = 期权价格隐含的到期日预期涨跌幅（%），是双向的，不指示方向。
  • 例：Oracle 财报前 implied move 11.2%，现价 $157.62 → 隐含波动约 ±$17.65，即财报后区间约 $140–$175。
  • 高 implied move（如 >15%）意味着市场预期剧烈波动，适合做跨式 / 宽跨式（Straddle/Strangle）；低 implied move 则方向性策略更划算。
  • 注意：implied move 是"概率加权的中枢"，实际结果可能落在区间外（尾部风险）。

#5. Put/Call Ratio（看跌看涨比率）：市场情绪温度计 ⭐⭐⭐

【话题简介】 Put/Call Ratio 是衡量市场整体多空情绪的常用指标，可辅助判断期权市场的"拥挤度"。

【详细内容】

  • Put/Call Ratio = 当日 Put 成交量 / Call 成交量。
  • 比率偏高（>1）：市场偏防御 / 看空情绪浓，可能预示超卖反弹机会（逆向指标）。
  • 比率偏低（<0.7）：市场偏乐观 / 追多，需警惕回调风险。
  • 局限：单一指标噪音大，应结合 IV、成交量、资金流向综合判断；不同交易所口径差异大。
  • 实战：在财报周，Put/Call 的异动常反映机构对冲行为，比散户情绪更有参考价值。

#6. 期权策略速览：从方向性到波动率交易 ⭐⭐⭐

【话题简介】 除单纯买 Call/Put 外，组合策略可更精细地表达"方向 + 波动率 + 时间"观点。

【详细内容】

  • 方向性：买 Call / 买 Put；备兑开仓（Covered Call）增强持股收益。
  • 波动率中性：跨式（Straddle）、宽跨式（Strangle）——赌"大波动"，不赌方向。
  • 价差策略：牛市/熊市价差（Bull/Bear Spread）——限制风险、降低成本。
  • 保护性策略：保护性 Put（Protective Put）——为持仓买"保险"。
  • 新手进阶路径：先掌握单腿期权 → 再学价差 → 最后尝试跨式 / 蝶式等复杂结构。
