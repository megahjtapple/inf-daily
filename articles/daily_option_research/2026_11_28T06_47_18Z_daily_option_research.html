📚 四、期权入门教程

24. 期权基础：Call vs Put — 核心区别

热度：★★★★★（教育类）

话题简介： Call（看涨期权）赋予持有者在到期日前以约定价格买入标的资产的权利；Put（看跌期权）赋予卖出权利。

详细内容：

  • Call Option（看涨期权）：
    • 买入 Call = 预期股价上涨
    • 最大亏损 = 支付的权利金（premium）
    • 最大收益 = 理论上无限（股价可无限上涨）
    • 示例：以 $100 买入 NVDA call，到期时 NVDA 涨到 $120 → 盈利 $20 - 权利金
  • Put Option（看跌期权）：
    • 买入 Put = 预期股价下跌
    • 最大亏损 = 支付的权利金
    • 最大收益 = 标的价格跌至 0 时的权利金 + 行权价
    • 示例：以 $100 买入 NVDA put，到期时 NVDA 跌到 $80 → 盈利 $20 - 权利金
  • 关键区别：Call 做多方向，Put 做空/对冲方向

Source Reference: Investopedia - Options Explained: Key Types and Risk Management | Fidelity - What are options?

25. 期权时间衰减（Theta）— 为什么持有期权会"贬值"

热度：★★★★★（教育类）

话题简介： 期权有到期日，随着时间推移，期权的时间价值（time value）持续衰减，最终在到期日归零。

详细内容：

  • Theta（时间衰减）：
    • 期权价格 = 内在价值 + 时间价值
    • 时间价值随时间流逝而减少（Theta 为负值）
    • 衰减速度：最后 30 天最快（尤其是 ATM 期权）
    • 示例：买入 $10 的 NVDA call，若股价不动，30 天后可能只剩 $6-7
  • 对买方的影响：时间是敌人 — 即使方向正确，如果涨幅不够快，仍可能亏损
  • 对卖方的影响：时间是朋友 — 收取权利金后等待时间价值衰减
  • 实战建议：
    • 买方：选择 30-90 天到期（平衡时间衰减和杠杆）
    • 卖方：选择 30-45 天到期（Theta 衰减最快区间）
    • 避免买入最后 7 天的期权（Theta 衰减极快 + IV crush）

26. 什么时候买入/卖出期权？— 决策框架

热度：★★★★★（教育类）

话题简介： 期权交易的核心决策：何时入场、何时离场、选择什么到期日和行权价。

详细内容：

  • 买入时机：
    • 有明确催化剂（财报、产品发布、政策变化）
    • IV 处于低位（权利金便宜）
    • 技术面突破关键阻力/支撑
    • 避免在 IV 高位时买入（如财报前 — IV crush 风险）
  • 卖出时机：
    • 达到目标收益（通常 50%-100% 权利金）
    • 催化剂已兑现（利好出尽）
    • 时间价值衰减到不值得继续持有
    • 止损：亏损 50% 权利金时考虑离场
  • 到期日选择：
    • 短期博弈：7-14 天（高杠杆但 Theta 风险大）
    • 中期趋势：30-90 天（平衡）
    • 长期方向：6-12 个月（LEAPS，适合长期看好/看空）
  • 行权价选择：
    • ATM（平值）：最大 Delta，方向性最强
    • ITM（实值）：更高内在价值，更低 Theta 风险
    • OTM（虚值）：便宜但需要大幅移动才盈利

27. 期权策略按风险排序 — 从保守到激进

热度：★★★★☆（教育类）

话题简介： 不同期权策略的风险收益特征差异巨大，新手应从低风险策略开始。

详细内容：

  • 低风险（适合新手）：
    • Covered Call（备兑开仓）：持有股票 + 卖出 Call → 收取权利金，限制上行
    • Cash-Secured Put（现金担保卖 Put）：卖出 Put + 持有现金 → 收取权利金或低价接货
    • Collar（领口策略）：持有股票 + 买 Put + 卖 Call → 锁定区间
  • 中风险：
    • Bull Call Spread（牛市看涨价差）：买低行权价 Call + 卖高行权价 Call → 限制成本和收益
    • Bear Put Spread（熊市看跌价差）：买高行权价 Put + 卖低行权价 Put
    • Iron Condor（铁鹰）：卖 OTM Call + 卖 OTM Put + 买更 OTM 保护 → 收取权利金，适合震荡市
  • 高风险（适合进阶）：
    • Long Straddle/Strangle：同时买 Call + Put → 博弈大幅波动（方向不限）
    • Naked Call/Put：卖出无保护期权 → 理论上无限风险
    • LEAPS：长期期权（6-12 个月）→ 高杠杆但时间价值大

28. 期权 Greeks — Delta/Gamma/Theta/Vega 速查

热度：★★★★☆（教育类）

话题简介： Greeks 是衡量期权价格对 various 因素敏感度的指标，是期权交易的核心工具。

详细内容：

  • Delta（Δ）：标的价格变动 $1 时期权价格变动多少
    • Call Delta：0 到 +1（ATM ≈ 0.5）
    • Put Delta：-1 到 0（ATM ≈ -0.5）
    • 用途：估计期权到期时 ITM 的概率
  • Gamma（Γ）：Delta 随标的价格变动的速度
    • ATM 期权 Gamma 最大
    • 临近到期 Gamma 急剧增大
  • Theta（Θ）：时间流逝对期权价格的影响（通常为负）
    • 买方 Theta 为负（每天损失时间价值）
    • 卖方 Theta 为正（每天赚取时间价值）
    • 最后 30 天 Theta 衰减最快
  • Vega（ν）：IV 变动 1% 时期权价格变动多少
    • IV 上升 → 期权价格上涨（利好买方）
    • IV 下降 → 期权价格下跌（利好卖方）
    • 财报前后 IV crush 是 Vega 风险的主要来源

热度：★★★☆☆（教育类）

话题简介： 期权提供杠杆效应，但风险特征与股票完全不同。

    • 卖出期权：理论上无限风险（naked call）
  • 适合场景：
    • 方向性博弈：买入 Call/Put
    • 对冲持仓：买入 Put（保护股票组合）
    • 增强收益：卖出 Covered Call / Cash-Secured Put
    • 收取权利金：Iron Condor / Strangle
