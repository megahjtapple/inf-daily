二、期权教育（新手必读）

4. 期权新手入门：Call vs Put、时间价值、买卖时机 🔥🔥🔥🔥🔥

话题简介 期权是一种合约，赋予持有者在特定日期前以特定价格买入（Call）或卖出（Put）标的资产的权利（非义务）。本报告系统梳理期权核心概念。

详细内容

4.1 基本概念

术语 含义
Call（看涨期权） 权利：以行权价买入标的。预期上涨时买入。
Put（看跌期权） 权利：以行权价卖出标的。预期下跌时买入，或作为持仓保护。
行权价（Strike Price） 合约约定的买卖价格。
到期日（Expiration Date） 合约有效截止日。
权利金（Premium） 期权的价格，买方支付、卖方收取。
实值/虚值（ITM/OTM） Call：股价>行权价=ITM；Put：股价<行权价=ITM。
隐含波动率（IV） 市场对未来波动的预期，IV越高期权越贵。

4.2 期权价值如何随时间变化

  • 内在价值：标的价格与行权价的差额（ITM才有）。
  • 时间价值：权利金 - 内在价值。随到期日临近而衰减（Theta 损耗）。
  • 关键规律：
    • 时间价值在到期前最后30天衰减最快。
    • IV 上升 → 期权变贵；IV 下降 → 期权变便宜（Vega 效应）。
    • 标的价格变动 → Delta 效应。

4.3 何时买入/卖出期权

场景 策略
预期大幅上涨 买入 Call（或 Bull Call Spread 降低成本）
预期大幅下跌 买入 Put（或 Bear Put Spread）
持有股票想降低风险 买入 Put（Married Put）或卖出 Call（Covered Call）赚权利金
预期横盘/低波动 卖出 Straddle/Strangle 或 Iron Condor 赚 Theta
预期事件驱动大波动（财报） 买入 Straddle/Strangle（赌 IV 上升）

4.4 Put vs Call 核心区别

  • Call：看涨方向。买方最大亏损=权利金；卖方理论风险无限。
  • Put：看跌方向。买方最大亏损=权利金；卖方最大亏损=行权价-权利金。
  • 对冲用途：Put 是"保险"，保护已持有的股票不跌穿。
  • 投机用途：Call 杠杆做多，Put 杠杆做空。

Source Reference

  • https://www.investopedia.com/options-basics-tutorial-4583012
  • Investopedia：Options Basics Tutorial（Calls/Puts, Strike Price, Expiration, Premium, ITM/OTM, IV, Strategies, Greeks, Black-Scholes）

5. 期权希腊字母（Greeks）与定价模型 🔥🔥🔥

话题简介 Greeks 是衡量期权价格对各因素敏感度的指标：Delta（方向）、Gamma（加速度）、Theta（时间衰减）、Vega（波动率敏感度）。理解 Greeks 是管理期权风险的核心。

详细内容

Greek 含义 实务意义
Delta (Δ) 标的每变动$1，期权价格变动多少 Call Delta 0~1；Put Delta -1~0。Delta≈行权概率。
Gamma (Γ) Delta 的变化率 临近到期+ATM时Gamma最大，期权价格加速变化。
Theta (Θ) 每过一天，期权价值衰减多少 买方敌人、卖方朋友。最后30天衰减最快。
Vega (ν) IV每变动1%，期权价格变动多少 IV上升利好买方；IV下降利好卖方。

定价模型：

  • Black-Scholes：连续时间模型，假设对数正态分布、恒定波动率。
  • Binomial（二叉树）：离散时间，可处理美式期权提前行权。
  • 实务：市场用隐含波动率（IV）反推期权价格，而非直接预测标的价格。

Source Reference

  • https://www.investopedia.com/options-basics-tutorial-4583012
  • Investopedia：Greeks, Black-Scholes, Binomial model

6. 常见期权策略详解 🔥🔥🔥

话题简介 从简单到复杂，主流期权策略包括：备兑开仓（Covered Call）、保护性看跌（Married Put）、信用/借方价差、跨式/宽跨式、铁鹰、蝶式。每种策略的风险收益特征不同。

详细内容

策略 方向 风险 适用场景
Covered Call 中性偏多 有限（卖出价-成本） 持有股票+赚权利金，接受上行封顶
Married Put 保护 权利金成本 持有股票+买Put对冲下跌
Bull Call Spread 看多 净权利金 温和看涨，降低成本
Bear Put Spread 看空 净权利金 温和看跌，降低成本
Credit Spread 中性 净收入 预期价格留在区间内
Debit Spread 方向性 净支出 方向性观点+限风险
Straddle 波动率 双份权利金 预期大波动（财报/事件）
Strangle 波动率 较低（OTM） 预期大波动，成本更低
Iron Condor 低波动 有限 预期横盘，赚Theta
Butterfly 精准到期价 有限 预期到期价精确落在某点

当前市场适用建议（2026-10-08）：

  • Fed 鹰派 + 高利率 → 科技股下行风险大 → Married Put / Bear Put Spread 保护科技持仓。
  • VIX 15.72 偏低 → 波动率有上行空间 → 买入 Straddle（财报季）或 卖出 Iron Condor（若预期横盘）。
  • TLT IV 94th percentile → 债券期权太贵 → 避免买入TLT期权，考虑价差策略。

7. 期权波动率偏斜（Volatility Skew）解读 🔥🔥

话题简介 波动率偏斜指不同行权价期权的 IV 差异。通常 Put 的 IV > Call 的 IV（"微笑"或"偏斜"），反映市场对下跌风险的溢价。偏斜陡峭程度是市场恐慌/贪婪的指标。

详细内容

  • 正常状态：Put IV > Call IV（下行保护需求高）。
  • 偏斜陡峭：市场极度恐惧，Put 被大量买入（如2020年3月、2008年）。
  • 偏斜平坦：市场自满，下行保护不足（当前 VIX 15.72 可能属于此类）。
  • 实务应用：
    • 偏斜陡峭时 → Put 太贵，考虑用价差替代。
    • 偏斜平坦时 → Put 相对便宜，是好的对冲时机。
    • 财报前 IV 飙升（IV Crush 风险）→ 避免买入事件驱动期权。

Source Reference

  • https://www.investopedia.com/options-basics-tutorial-4583012
  • Investopedia：Volatility Skew

    • 卖方：财报前 Sell Straddle（赚 IV 溢价），但需严格止损。
  • 多周期展望：
    • 财报季通常伴随高波动，VIX 中枢上移。
