1. 期权快速上手教程

1.1 什么是期权？——Call 与 Put 的核心区别

热度：⭐⭐⭐⭐⭐ 类别： 期权基础

话题简介： 期权是一种金融合约，赋予持有者在特定日期前以特定价格买入或卖出标的资产的权利（而非义务）。理解 Call（看涨）与 Put（看跌）的区别是期权交易的第一步。

详细内容：

  • Call（看涨期权）： 赋予持有者以约定行权价买入标的资产的权利。当预期股价上涨时买入 Call。
  • Put（看跌期权）： 赋予持有者以约定行权价卖出标的资产的权利。当预期股价下跌或需要对冲下行风险时买入 Put。
  • 合约规模： 美国市场标准期权合约通常代表 100股 标的股票。权利金报价为每股价格，实际成本 = 权利金 × 100。
  • 定价构成： 期权价值 = 内在价值（intrinsic value）+ 时间价值（time value）。内在价值 = 当前市价与行权价的差额（若为正）；时间价值随到期日临近而衰减。
  • 三大交易目的： 对冲风险（hedging）、产生收入（income generation）、投机（speculation）。
特征 Call（看涨期权） Put（看跌期权）
赋予的权利 以行权价买入标的资产 以行权价卖出标的资产
典型用途 看涨投机 / 对冲空头 看跌投机 / 保护多头头寸
行权条件 市价 > 行权价时行权有利 市价 < 行权价时行权有利
盈利来源 标的价格上涨超过行权价+权利金 标的价格下跌低于行权价-权利金
买方最大损失 限于支付的权利金 限于支付的权利金
卖方最大风险 理论上无限（股价可无限上涨） 限于行权价-权利金（股价最低跌到0）

简单记忆： Call = "Call up the price"（看涨），Put = "Put down the price"（看跌）。

1.2 时间衰减（Theta）——期权是"消耗性资产"

热度：⭐⭐⭐⭐⭐ 类别： 期权基础

话题简介： 期权的时间价值随时间推移而不断减少，即使标的股价不变，期权价值也会下降。这是期权交易中最核心的风险因素之一。

详细内容：

  • Theta（θ） 衡量期权价值因时间流逝而变化的速率。对于买方而言，Theta 通常为负值——每天开盘时，期权都会"损失"一部分时间价值。
  • 衰减加速期： 时间衰减并非匀速。在到期日前30天，尤其是最后两周，衰减速度显著加快。因此，短期期权（LEAPS除外）对买方极为不利。
  • 内在价值 vs 时间价值： 深度实值期权（deep ITM）的时间价值占比小，受时间衰减影响较小；虚值期权（OTM）几乎全部由时间价值构成，衰减影响最大。
  • 策略含义：
    • 买方应尽量选择有足够时间让标的价格朝预期方向移动的到期日（通常30-90天以上）。
    • 卖方则受益于时间衰减——Theta 是卖方的"朋友"。
    • Calendar Spread（日历价差）策略正是利用不同到期日的 Theta 差异来获利。

1.3 什么时候应该买入和卖出期权？

热度：⭐⭐⭐⭐ 类别： 期权基础

话题简介： 买卖时机的选择取决于市场预期、风险偏好和策略目标。以下是不同场景下的决策框架。

详细内容：

场景 策略 预期
强烈看涨 买入 Call（Long Call） 股价大幅上涨超过行权价+权利金
温和看涨 买入 Call Spread（Bull Call Spread） 有限上涨，降低成本和风险
强烈看跌 买入 Put（Long Put） 股价大幅下跌低于行权价-权利金
温和看跌 买入 Put Spread（Bear Put Spread） 有限下跌，降低成本和风险
预期横盘/低波动 卖出 Straddle / Iron Condor 收取权利金，股价在区间内波动
预期高波动（方向不确定） 买入 Straddle / Strangle 事件驱动（财报、选举等）
持有股票+温和看涨 Covered Call（备兑开仓） 收取权利金增强收益，限制上行空间
持有股票+担心下跌 Protective Put（保护性看跌） 类似购买保险，限制下行损失

关键决策因素：

  1. 方向判断： 看涨买 Call，看跌买 Put。
  2. 波动率预期： 高 IV 时卖方占优（权利金贵），低 IV 时买方占优。
  3. 时间框架： 短期事件用短期期权，长期趋势用 LEAPS（长期期权）。
  4. 风险承受力： 买方最大损失 = 权利金；卖方（裸卖）理论上可能面临无限损失。

1.4 风险管理基础——Greeks 与策略组合

热度：⭐⭐⭐⭐ 类别： 期权基础

话题简介： 期权交易的风险管理依赖于对 Greeks（希腊字母）的理解和策略组合的设计。

详细内容：

  • Delta（Δ）： 标的价格变动1美元时期权价格的变化量。Call 的 Delta 在 0~+1 之间，Put 的 Delta 在 -1~0 之间。
  • Gamma（Γ）： Delta 随标的价格变化的速率。高 Gamma 意味着 Delta 变化快，风险更大。
  • Vega（κ）： 隐含波动率变动1%时期权价值的变化。买方受益于 IV 上升，卖方反之。
  • Theta（θ）： 时间衰减速率。对买方为负，对卖方为正。

常用风险管理策略：

  1. Covered Call（备兑开仓）： 持有股票 + 卖出 Call。限制上行收益但获得权利金收入，降低持仓成本。
  2. Protective Put（保护性看跌）： 持有股票 + 买入 Put。类似购买保险，设定最大损失。
  3. Vertical Spread（垂直价差）： 同时买卖不同行权价但相同到期日的期权。限制风险和收益。
  4. Calendar Spread（日历价差）： 同时买卖相同行权价但不同到期日的期权。利用 Theta 差异获利。
  5. Iron Condor（铁鹰式）： 组合 Put Spread + Call Spread。预期股价在区间内波动，收取双边权利金。

风险提示： 裸卖期权（naked options）风险极大——裸卖 Call 理论上损失无限，裸卖 Put 最大损失为行权价减去权利金。券商通常根据资产规模、收入和经验等级限制高风险策略的权限。
