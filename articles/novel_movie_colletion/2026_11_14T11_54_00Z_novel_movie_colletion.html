📝 使用说明与注意事项

✅ 合法免费资源推荐优先级

  1. 书籍/小说： Internet Archive → Project Gutenberg → Open Library → Standard Ebooks → ManyBooks
  2. 有声书： Librivox → Loyal Books → Hoopla（需图书馆卡）→ Kanopy（需图书馆卡）
  3. 美剧/电影： Tubi → Pluto TV → YouTube → Peacock（免费档）→ Plex
  4. 动画： Crunchyroll（免费档）→ Viki → AnimeLab → YouTube
  5. 中文小说： 起点中文网 → 晋江文学城 → 微信读书

⚠️ 法律风险提示

  • 灰色地带网站（Anna's Archive、Z-Library、LibGen）在多数国家/地区属于侵权下载，存在法律风险。
  • 建议优先使用合法免费资源（公版书、图书馆服务、免费流媒体平台）。
  • 如所在地区有公共图书馆数字服务（Hoopla、Kanopy），凭图书馆卡可免费借阅大量付费内容，是最优选择。
